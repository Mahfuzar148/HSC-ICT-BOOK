# অধ্যায় ৪ — ভাষা ও পরিভাষার রীতি

বাক্যের গঠন বাংলা থাকবে। প্রথম গুরুত্বপূর্ণ পরিচয়ে প্রয়োজনীয় ইংরেজি নাম বা সংক্ষিপ্ত রূপের পূর্ণরূপ দেওয়া হবে; পরের ব্যাখ্যায় একই বাংলা পরিভাষা ব্যবহার করা হবে। কোড, ফাইলের নাম, ঠিকানা, নমুনার দৃশ্যমান তথ্য ও প্রশ্নের প্রয়োজনীয় ইংরেজি বিকল্পকে অনুবাদ করা হবে না।

| ধারণা | ব্যাখ্যায় ব্যবহৃত রূপ |
|---|---|
| Web design | ওয়েব ডিজাইন; প্রয়োজনমতো ওয়েব নকশা |
| Web page / website / homepage | ওয়েবপেজ / ওয়েবসাইট / হোমপেজ |
| Browser / web server | ব্রাউজার / ওয়েব সার্ভার |
| Search engine / web portal | সার্চ ইঞ্জিন / ওয়েব পোর্টাল |
| Static / dynamic | স্থির / পরিবর্তনশীল; পরিচয়ে Static / Dynamic |
| Structure / layout / navigation | কাঠামো / বিন্যাস / পৃষ্ঠার সংযোগ |
| Linear / hierarchical / network / hybrid | সরলরৈখিক / বৃক্ষ বা স্তরভিত্তিক / জালিকা / মিশ্র |
| Tag / element / attribute / syntax | ট্যাগ / এলিমেন্ট / অ্যাট্রিবিউট / লেখার নিয়ম |
| Heading / paragraph | শিরোনাম / অনুচ্ছেদ |

| Nested table | ঘরের ভেতরে আরেকটি টেবিল |
| Form / control / submit / reset | ফর্ম / নিয়ন্ত্রণ / তথ্য পাঠানো / প্রাথমিক মান ফিরিয়ে আনা |
| Publishing / hosting | ওয়েবসাইট প্রকাশ / হোস্টিং |
| Output / example / exercise | ফল / উদাহরণ / অনুশীলন |
| MCQ / CQ | বহুনির্বাচনি প্রশ্ন / সৃজনশীল প্রশ্ন |

প্রাসঙ্গিক পরিচয়ে HTML, CSS, WWW, IP, URL, DNS, HTTP, HTTPS, TLS, FTP, SFTP, W3C ও WHATWG-এর পূর্ণরূপ ব্যাখ্যা করা হয়। পুরোনো নাম SSL এবং প্রদত্ত ঐতিহাসিক উদাহরণের GSM/CDMA প্রয়োজন অনুযায়ী চিহ্নিত। `src`, `href`, `alt`, `GET`, `POST` ও ট্যাগের নাম কোডের পরিচিতি হিসেবে অপরিবর্তিত থাকবে।

বড় শিরোনাম ও উপশিরোনাম গাঢ় নীলাভ সবুজ; ছোট উপশিরোনাম গাঢ় গোলাপি। সংজ্ঞা সংক্ষিপ্ত, উদাহরণ ও ভুল ধারণার ব্যাখ্যা আলাদা। সাধারণ কোডে সমান প্রস্থের অক্ষর ব্যবহার হয়; বাংলা লেখা থাকা কোডে বাংলা সমর্থিত ফন্ট লাগে। এই রীতিগুলো `latex/visual_style.tex`-এ অধ্যায় ৪-এর জন্য নির্ধারিত।
