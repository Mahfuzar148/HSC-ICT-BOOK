মূল বইয়ে অধ্যায়টি যুক্ত হয় `latex/chapter.tex` দিয়ে। অধ্যায়ের ফন্ট, শিরোনাম, বক্স ও পৃষ্ঠার বিন্যাস `latex` ফোল্ডারে রাখা হয়েছে। পূর্ণ বইয়ে অধ্যায় শেষ হলে আগের বিন্যাস ফিরে আসে।

শুধু এই অধ্যায় কম্পাইল করতে প্রকল্পের মূল ফোল্ডার থেকে চালাবে:

```powershell
lualatex -interaction=nonstopmode -halt-on-error -output-directory=build chapter04_only.tex
lualatex -interaction=nonstopmode -halt-on-error -output-directory=build chapter04_only.tex
```

তৈরি PDF: `build/chapter04_only.pdf`। পর্যালোচিত কপিটি প্রকল্পের মূল ফোল্ডারের `chapter04_only.pdf`-এও রাখা হয়। LuaLaTeX, প্রকল্পের প্রয়োজনীয় TeX প্যাকেজ ও Kalpurush ফন্ট লাগে।

পুরোনো পরীক্ষার পরিচিত HTML উপস্থাপনমূলক রীতি উদাহরণে রাখা হয়েছে; বর্তমান HTML ও CSS ব্যবহারের পার্থক্য ব্যাখ্যায় আছে। ছবি বা অন্য ফাইলের নাম দেওয়া কোড চালাতে সেই ফাইলগুলো নির্ধারিত স্থানে রাখতে হবে। ফর্মের HTML উদাহরণ নিয়ন্ত্রণ ও গঠন শেখায়; তথ্য সংরক্ষণের সার্ভার কোড আলাদা কাজ।
