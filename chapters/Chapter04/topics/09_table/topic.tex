\section{Table in HTML}

\begin{learningbox}
এই টপিক শেষে শিক্ষার্থী পারবে:
\begin{itemize}
\item HTML table কী এবং ওয়েবপেজে table কখন ব্যবহার করা হয় তা ব্যাখ্যা করতে।
\item \texttt{<table>}, \texttt{<tr>}, \texttt{<th>}, \texttt{<td>} ও \texttt{<caption>} tag-এর কাজ লিখতে।
\item table-এর row, column ও cell view দেখে শনাক্ত করতে।
\item \texttt{border}, \texttt{width}, \texttt{align}, \texttt{bgcolor}, \texttt{cellspacing} ও \texttt{cellpadding} attribute ব্যবহার করতে।
\item \texttt{rowspan} ও \texttt{colspan} ব্যবহার করে cell merge করতে।
\item table-এর ভিতরে text, formatting, link, image, list ও nested table ব্যবহার করতে।
\item চিত্র দেখে board-style HTML table code লিখতে।
\item পুরনো HSC-style attribute এবং modern CSS alternative-এর পার্থক্য বুঝতে।
\end{itemize}
\end{learningbox}

\subsection{ভূমিকা}

ওয়েবপেজে অনেক সময় তথ্য সারি ও কলাম আকারে দেখাতে হয়। যেমন--রেজাল্ট শিট, ক্লাস রুটিন, পণ্যের মূল্য তালিকা, শিক্ষার্থীর তথ্য, salary sheet, bill summary, admission list, college department report ইত্যাদি। এই ধরনের তথ্য সুন্দরভাবে সাজানোর জন্য HTML-এ \textbf{table} ব্যবহার করা হয়। HSC ICT Chapter 4-এ table একটি খুব গুরুত্বপূর্ণ practical topic, কারণ CQ ও practical question-এ প্রায়ই result table, marks sheet, image-সহ table, hyperlink-সহ table, rowspan-colspan table, nested table ইত্যাদি তৈরি করতে বলা হয়।

\begin{keypointbox}{মূল ধারণা}
HTML table শেখার মূল বিষয় হলো: \textbf{row}, \textbf{column}, \textbf{cell}, \textbf{cell merge} এবং \textbf{cell-এর ভিতরে অন্য HTML element ব্যবহার}। এগুলো ঠিকমতো বুঝলে যেকোনো চিত্র দেখে table code লেখা সহজ হয়।
\end{keypointbox}

\begin{boardbox}{কখন table ব্যবহার করবে}
যে তথ্য row ও column আকারে স্বাভাবিকভাবে সাজানো যায়, সেখানে table ব্যবহার করা উচিত। যেমন--result sheet, routine, price list, marks distribution, contact list, product catalog, admission schedule ইত্যাদি। কিন্তু শুধু page layout সাজানোর জন্য table ব্যবহার করা modern web design-এ ভালো practice নয়; layout-এর জন্য CSS layout ব্যবহার করা ভালো। HSC practical-এ তবে বইয়ের figure অনুযায়ী table code লিখতে হবে।
\end{boardbox}

\begin{keypointbox}{Table বোঝার সহজ ভাষা}
একটি table-কে খাতার ছকের মতো ভাবা যায়। প্রথমে ছকের সারি বা row গুনবে, তারপর প্রতিটি row-তে কয়টি ঘর আছে তা দেখবে। যে ঘরটি heading হিসেবে কাজ করে সেটি সাধারণত \texttt{<th>} দিয়ে লেখা হয়, আর সাধারণ তথ্যের ঘর \texttt{<td>} দিয়ে লেখা হয়। কোনো ঘর যদি পাশের ঘর দখল করে নেয়, সেটি \texttt{colspan}; কোনো ঘর যদি নিচের ঘর দখল করে নেয়, সেটি \texttt{rowspan}।
\end{keypointbox}

\subsection{HTML Table কী?}

\begin{definitionbox}{HTML Table}
HTML document-এ তথ্যকে সারি ও কলাম আকারে প্রদর্শনের জন্য যে কাঠামো ব্যবহার করা হয়, তাকে HTML Table বলে।
\end{definitionbox}

Table মূলত \textbf{tabular data} বা row-column আকারের তথ্য দেখানোর জন্য ব্যবহার করা হয়। একটি table বুঝতে তিনটি বিষয় মনে রাখা দরকার: row, column এবং cell।

\begin{center}

\hline
\textbf{অংশ} & \textbf{অর্থ} \\
\hline
Row & আড়াআড়ি সারি \\
\hline
Column & লম্বালম্বি কলাম \\
\hline
Cell & row ও column মিলিত হয়ে যে ঘর তৈরি হয় \\
\hline
\end{tabular}
\end{center}

\subsection{\texttt{<table>} Tag}

\begin{definitionbox}{\texttt{<table>} tag}
HTML document-এ table বা ছক তৈরি করার জন্য ব্যবহৃত container tag হলো \texttt{<table>} tag।
\end{definitionbox}

Table-এর সব row ও cell এই tag-এর ভিতরে লেখা হয়।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>HTML Table Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <tr>
      <td>Data</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\subsection{\texttt{<tr>} Tag}

\begin{definitionbox}{\texttt{<tr>} tag}
HTML table-এর একটি row বা সারি তৈরি করার জন্য \texttt{<tr>} tag ব্যবহার করা হয়।
\end{definitionbox}

প্রতিটি \texttt{<tr>} tag-এর ভিতরে এক বা একাধিক \texttt{<th>} অথবা \texttt{<td>} লেখা হয়।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Table Row Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <tr>
      <td>Data 1</td>
      <td>Data 2</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\subsection{\texttt{<th>} Tag}

\begin{definitionbox}{\texttt{<th>} tag}
HTML table-এর heading cell তৈরি করার জন্য ব্যবহৃত tag হলো \texttt{<th>} tag।
\end{definitionbox}

Browser সাধারণত \texttt{<th>} tag-এর text bold ও center aligned করে দেখায়।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Table Header Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <tr>
      <th>Name</th>
      <th>Roll</th>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\subsection{\texttt{<td>} Tag}

\begin{definitionbox}{\texttt{<td>} tag}
HTML table-এর data cell বা তথ্যের ঘর তৈরি করার জন্য ব্যবহৃত tag হলো \texttt{<td>} tag।
\end{definitionbox}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Table Data Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <tr>
      <td>Rafi</td>
      <td>101</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\subsection{Basic Table Syntax}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>HTML Table Example</title>
</head>
<body>
<table>
  <tr>
    <th>Heading 1</th>
    <th>Heading 2</th>
  </tr>
  <tr>
    <td>Data 1</td>
    <td>Data 2</td>
  </tr>

</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{keypointbox}{Structure মনে রাখো}
\texttt{<table>} পুরো table তৈরি করে, \texttt{<tr>} একটি row তৈরি করে, \texttt{<th>} heading cell তৈরি করে এবং \texttt{<td>} data cell তৈরি করে।
\end{keypointbox}

\subsection{Table Code লেখার Logical Structure}

HTML table লেখার সময় browser উপর থেকে নিচে row-by-row code পড়ে। তাই code লেখার সময় কোনো cell আগে বা পরে লিখলে visual output বদলে যেতে পারে। একটি row শুরু করতে \texttt{<tr>} লিখতে হয় এবং সেই row-এর যতগুলো cell আছে সেগুলো \texttt{<th>} অথবা \texttt{<td>} দিয়ে একই \texttt{<tr>} tag-এর ভিতরে লিখতে হয়।

\begin{keypointbox}{মনে রাখার নিয়ম}
Table-এর ভিতরে সরাসরি text লেখা উচিত নয়। Table-এর content সাধারণত cell-এর ভিতরে থাকে। তাই correct structure হলো:
\texttt{<table>} $\rightarrow$ \texttt{<tr>} $\rightarrow$ \texttt{<th>} বা \texttt{<td>} $\rightarrow$ content।
\end{keypointbox}

\begin{center}
\begin{tabular}{|p{0.24\textwidth}|p{0.58\textwidth}|}
\hline
\textbf{ধাপ} & \textbf{কাজ} \\
\hline
১ & \texttt{<table>} দিয়ে table শুরু করা \\
\hline
২ & প্রতিটি row-এর জন্য \texttt{<tr>} লেখা \\
\hline
৩ & heading হলে \texttt{<th>}, data হলে \texttt{<td>} লেখা \\
\hline
৪ & সব opened tag ঠিকভাবে close করা \\
\hline
\end{tabular}
\end{center}

\subsection{Simple Table Example}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Simple Table</title>
</head>
<body>
  <table border="1">
    <tr>
      <th>Roll</th>
      <th>Name</th>
      <th>GPA</th>
    </tr>
    <tr>
      <td>101</td>
      <td>Rafi</td>
      <td>5.00</td>
    </tr>
    <tr>
      <td>102</td>
      <td>Sakib</td>
      <td>4.75</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{examplebox}{Output ধারণা}
\begin{center}
\begin{tabular}{|c|c|c|}
\hline
\textbf{Roll} & \textbf{Name} & \textbf{GPA} \\
\hline
101 & Rafi & 5.00 \\
\hline
102 & Sakib & 4.75 \\
\hline
\end{tabular}
\end{center}
\end{examplebox}

\begin{boardbox}{কোড বিশ্লেষণ}
উপরের code-এ প্রথম \texttt{<tr>} হলো heading row। সেখানে Roll, Name, GPA--এই তিনটি heading cell আছে, তাই \texttt{<th>} ব্যবহার করা হয়েছে। পরের দুইটি row data row, তাই সেখানে \texttt{<td>} ব্যবহার করা হয়েছে। \texttt{border="1"} দেওয়ার কারণে table-এর রেখা দেখা যাচ্ছে।
\end{boardbox}

\subsection{Table Design করার আগে কী ভাববে?}

চিত্র দেখে বা question পড়ে table code লেখার আগে সরাসরি code শুরু না করে কয়েকটি বিষয় ঠিক করতে হয়। এতে ভুল কম হয় এবং \texttt{rowspan}/\texttt{colspan} সহজে বোঝা যায়।

\begin{enumerate}
\item Table-এর title বা caption আছে কি না দেখবে।
\item মোট কয়টি visible column আছে তা গুনবে।
\item মোট কয়টি row আছে তা গুনবে।
\item কোন cell heading আর কোন cell data তা আলাদা করবে।
\item কোনো cell একাধিক column জুড়ে আছে কি না দেখবে।
\item কোনো cell একাধিক row জুড়ে আছে কি না দেখবে।
\item cell-এর ভিতরে text, image, link, list বা nested table আছে কি না দেখবে।
\end{enumerate}

\begin{keypointbox}{পরীক্ষার কৌশল}
কোনো figure জটিল মনে হলে প্রথমে pencil দিয়ে row line ও column line আলাদা করে ভাববে। এরপর merged cell বাদ দিয়ে base grid ধরবে। Base grid বুঝলে \texttt{rowspan} ও \texttt{colspan} বসানো সহজ হয়।
\end{keypointbox}

\subsection{Table Attribute}

PDF-এ table তৈরি করার সময় কয়েকটি attribute বারবার ব্যবহার করা হয়েছে। HSC practical exam-এ এগুলো গুরুত্বপূর্ণ। Table-level attribute যেমন \texttt{border}, \texttt{width}, \texttt{align}, \texttt{cellspacing}, \texttt{cellpadding} পুরো table-এর appearance নিয়ন্ত্রণ করে। আবার cell-level attribute যেমন \texttt{align}, \texttt{valign}, \texttt{bgcolor}, \texttt{rowspan}, \texttt{colspan}, \texttt{width}, \texttt{height} নির্দিষ্ট \texttt{<td>} বা \texttt{<th>} cell-এর আচরণ নিয়ন্ত্রণ করে।

\begin{center}
\begin{tabular}{|p{0.20\textwidth}|p{0.42\textwidth}|p{0.25\textwidth}|}
\hline
\textbf{Attribute} & \textbf{কাজ} & \textbf{Example} \\
\hline
\texttt{border} & table ও cell-এর চারপাশে রেখা দেখায় & \texttt{border="1"} \\
\hline
\texttt{width} & table বা cell-এর প্রস্থ pixel/percentage-এ নির্ধারণ করে & \texttt{width="400"} \\
\hline
\texttt{align} & table বা cell-এর left/right/center position নির্ধারণ করে & \texttt{align="center"} \\
\hline
\texttt{cellspacing} & cell থেকে cell-এর মাঝের বাইরের gap নির্ধারণ করে & \texttt{cellspacing="0"} \\
\hline
\texttt{cellpadding} & cell content ও border-এর মাঝের ভিতরের gap নির্ধারণ করে & \texttt{cellpadding="5"} \\
\hline
\texttt{bgcolor} & table/cell-এর background color দেয় & \texttt{bgcolor="yellow"} \\
\hline
\end{tabular}
\end{center}

\begin{keypointbox}{PDF থেকে গুরুত্বপূর্ণ point}
\texttt{border} attribute না দিলে table-এর রেখা সবসময় দেখা যায় না। বইয়ের example-গুলোতে single-line border দেখাতে বেশিরভাগ সময় \texttt{border="1"}-এর সাথে \texttt{cellspacing="0"} ব্যবহার করা হয়েছে। \texttt{width="75\%"} দিলে table parent area-এর 75\% জায়গা নেয়, আর \texttt{width="400"} বা \texttt{width="400px"} দিলে fixed pixel width বোঝায়।
\end{keypointbox}

\conceptimagerow{chapters/Chapter04/topics/images/3d_table_attributes.png}{
\begin{keypointbox}{চিত্র ব্যাখ্যা}
চিত্রে \texttt{border}, \texttt{width}, \texttt{align}, \texttt{bgcolor}, \texttt{cellspacing} ও \texttt{cellpadding} attribute table-এর appearance কীভাবে বদলায় তা দেখানো হয়েছে।
\end{keypointbox}
}{table attribute-এর প্রভাব}


\subsection{\texttt{border} Attribute}

\begin{definitionbox}{\texttt{border} attribute}
HTML table-এর চারপাশে ও cell-এর চারপাশে border প্রদর্শনের জন্য \texttt{border} attribute ব্যবহার করা হয়।
\end{definitionbox}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>HTML Table Example</title>
</head>
<body>
<table border="1">
  <tr>
    <th>Subject</th>
    <th>Mark</th>
  </tr>
  <tr>
    <td>ICT</td>
    <td>95</td>
  </tr>
</table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{boardbox}{পরীক্ষায় মনে রাখবে}
HSC practical code-এ table-এর রেখা দেখাতে সাধারণত \texttt{border="1"} ব্যবহার করা হয়। Border না দিলে browser table-এর cell boundary সবসময় স্পষ্টভাবে দেখায় না। Border-এর মান 1, 2, 3 ইত্যাদি হলে রেখার thickness বাড়ে; তবে neat table-এর জন্য \texttt{border="1"} এবং \texttt{cellspacing="0"} সবচেয়ে বেশি ব্যবহৃত।
\end{boardbox}

\subsection{\texttt{width} Attribute}

Table বা cell-এর প্রস্থ নির্ধারণ করতে \texttt{width} attribute ব্যবহার করা যায়। Width pixel বা percentage আকারে দেওয়া যায়।

Pixel width fixed size দেয়, তাই \texttt{width="400"} দিলে table প্রায় 400 pixel জায়গা নেবে। Percentage width flexible; \texttt{width="75\%"} দিলে browser window বা parent container-এর 75\% জায়গা ব্যবহার করবে। Cell-এর \texttt{width} দিলে নির্দিষ্ট column তুলনামূলক বড় বা ছোট করা যায়।

  <title>HTML Table Example</title>
</head>

    <th>GPA</th>
  </tr>
  <tr>
    <td>Rafi</td>
    <td>5.00</td>
  </tr>
</table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{examplebox}{Percentage Width}

</head>

      <th>GPA</th>
    </tr>

      <td>5.00</td>

</body>

\end{verbatim}

\end{examplebox}

\subsection{\texttt{align} Attribute}

Table, row বা cell-এর content left, right বা center-এ রাখতে \texttt{align} attribute ব্যবহার করা হয়।

\texttt{<table align="center">} লিখলে পুরো table page-এর মাঝখানে চলে আসে। কিন্তু \texttt{<td align="center">} লিখলে শুধু ওই cell-এর content মাঝখানে থাকে। তাই table-এর position এবং cell-এর ভিতরের text alignment আলাদা বিষয়।

<!DOCTYPE html>
<html>
<head>
  <title>Align Example</title>
</head>

      <td align="center">ICT</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\textbf{Value} & \textbf{কাজ} \\
\hline
\texttt{left} & বামে রাখে \\
\hline
\texttt{center} & মাঝখানে রাখে \\
\hline
\texttt{right} & ডানে রাখে \\
\hline
\end{tabular}
\end{center}

\subsection{\texttt{valign} Attribute}

Cell-এর ভিতরের content vertical direction-এ কোথায় থাকবে তা নির্ধারণ করতে \texttt{valign} attribute ব্যবহার করা যায়।

কোনো cell-এর height বেশি হলে content উপরে, মাঝখানে বা নিচে রাখা দরকার হতে পারে। শুধু \texttt{<br>} দিয়ে content নিচে নামানো যায়, কিন্তু board-style পরিষ্কার code-এর জন্য \texttt{valign="top"}, \texttt{valign="middle"} বা \texttt{valign="bottom"} ব্যবহার করা ভালো।

\textbf{Value} & \textbf{কাজ} \\
\hline
\texttt{top} & cell-এর উপরে রাখে \\
\hline
\texttt{middle} & cell-এর মাঝখানে রাখে \\
\hline
\texttt{bottom} & cell-এর নিচে রাখে \\
\hline
\end{tabular}
\end{center}

\subsection{\texttt{cellspacing} Attribute}

\begin{definitionbox}{\texttt{cellspacing} attribute}
Table-এর এক cell-এর border থেকে পাশের cell-এর border পর্যন্ত ফাঁকা জায়গা নির্ধারণ করতে \texttt{cellspacing} attribute ব্যবহার করা হয়।
\end{definitionbox}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>HTML Table Example</title>
</head>
<body>
<table border="1" cellspacing="0">
  <tr>
    <th>Name</th>
    <th>Class</th>
  </tr>
  <tr>
    <td>Rafi</td>
    <td>XI</td>
  </tr>
</table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{keypointbox}{সহজ কথা}
Browser অনেক সময় default হিসেবে cell-এর মাঝে সামান্য gap রাখে। \texttt{cellspacing="0"} দিলে cell-এর মাঝখানের gap কমে যায় বা borderগুলো একসাথে লেগে থাকে। আবার \texttt{cellspacing="10"} দিলে দুই cell-এর border-এর মাঝে 10 pixel দূরত্ব তৈরি হয়।
\end{keypointbox}

\subsection{\texttt{cellpadding} Attribute}

\begin{definitionbox}{\texttt{cellpadding} attribute}
Table cell-এর content এবং cell border-এর মাঝখানের ভিতরের ফাঁকা জায়গা নির্ধারণ করতে \texttt{cellpadding} attribute ব্যবহার করা হয়।
\end{definitionbox}

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>HTML Table Example</title>
</head>
<body>
<table border="1" cellpadding="10">
  <tr>
    <th>Subject</th>
    <th>GPA</th>
  </tr>
  <tr>
    <td>Bangla</td>
    <td>5.00</td>
  </tr>
</table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\begin{boardbox}{MCQ point}
\texttt{cellpadding="5"} অর্থ cell content এবং cell border-এর মাঝখানে 5 pixel ভিতরের ফাঁকা জায়গা রাখা। অনেক browser-এ default cellpadding খুব কম থাকে; তাই text border-এর সাথে লেগে গেলে \texttt{cellpadding} বাড়ালে table পড়তে সহজ হয়।
\end{boardbox}

\subsection{Merged Cell বুঝে Code লেখার নিয়ম}

Merged cell হলো এমন cell, যা একাধিক row বা column-এর জায়গা নেয়। Table চিত্র দেখে code লেখার সময় merged cell ভুল হলে পুরো table layout নষ্ট হয়ে যায়। তাই \texttt{rowspan} ও \texttt{colspan} ব্যবহার করার আগে base column সংখ্যা ঠিক করা দরকার।

\begin{boardbox}{\texttt{colspan} কখন ব্যবহার করবে}
যদি কোনো cell বাম থেকে ডানে একাধিক column-এর জায়গা নেয়, তখন \texttt{colspan} ব্যবহার করবে। যেমন, একটি title যদি table-এর তিনটি column জুড়ে থাকে, তাহলে code হবে \texttt{<th colspan="3">Title</th>}।
\end{boardbox}

\begin{boardbox}{\texttt{rowspan} কখন ব্যবহার করবে}
যদি কোনো cell উপর থেকে নিচে একাধিক row-এর জায়গা নেয়, তখন \texttt{rowspan} ব্যবহার করবে। যেমন, একটি group name যদি দুইটি section row-এর জন্য common হয়, তাহলে code হবে \texttt{<td rowspan="2">Science</td>}।
\end{boardbox}

\begin{keypointbox}{Merged cell-এর কারণে cell count কমে যায়}
যে row-তে \texttt{colspan} বা \texttt{rowspan} ব্যবহার করা হয়, সেই row-তে আলাদা cell কম লিখতে হয়। কারণ merged cell নিজেই একাধিক cell-এর জায়গা দখল করে। এটাই beginners-দের সবচেয়ে সাধারণ ভুল।
\end{keypointbox}

\subsection{Empty Cell এবং \texttt{\&nbsp;}}

Table-এর কোনো cell খালি রাখতে চাইলে অনেক সময় browser cell-এর border ঠিকভাবে দেখাতে সমস্যা করতে পারে। তাই খালি cell-এ non-breaking space বা \texttt{\&nbsp;} ব্যবহার করা হয়।

খালি cell রাখা দরকার হলে শুধু blank space না দিয়ে \texttt{\&nbsp;} লেখা ভালো, কারণ এটি একটি invisible character হিসেবে কাজ করে। ফলে cell-এর height, width এবং border ঠিক থাকে। Board practical-এ empty cell দেখলে \texttt{<td>\&nbsp;</td>} লিখলে layout বেশি নির্ভরযোগ্য হয়। পুরনো বইয়ের example-এ খালি cell দেখাতে অনেক সময় \texttt{<br>} ব্যবহারও দেখা যায়, তবে পরীক্ষায় পরিষ্কারভাবে empty cell বোঝাতে \texttt{\&nbsp;} বেশি নির্ভরযোগ্য।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Empty Cell Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <tr>
      <th>Header 1</th>
      <th>Header 2</th>
    </tr>
    <tr>
      <td>Data</td>
      <td>&nbsp;</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

{চিত্রে empty cell দৃশ্যমান রাখতে \texttt{\&nbsp;} ব্যবহারের ধারণা দেখানো হয়েছে। খালি cell collapse বা অস্পষ্ট হলে non-breaking space ব্যবহার করা যায়।}
{খালি cell-এ \texttt{\&nbsp;} ব্যবহার}


\subsection{\texttt{<caption>} Tag}

\begin{definitionbox}{\texttt{<caption>} tag}
HTML table-এর শিরোনাম বা title প্রদর্শনের জন্য \texttt{<caption>} tag ব্যবহার করা হয়।
\end{definitionbox}

\texttt{<caption>} tag সবসময় \texttt{<table>} tag-এর ভিতরে এবং প্রথম row-এর আগে লেখা উচিত। এতে browser সাধারণত table-এর উপরে title দেখায়। Result sheet, routine, admission list বা product table-এর মতো table-এ caption দিলে table-এর উদ্দেশ্য দ্রুত বোঝা যায়। পুরনো HSC-style code-এ caption-এর position বোঝাতে \texttt{align="bottom"} ধরনের legacy attribute দেখা যেতে পারে, তবে modern HTML-এ caption position CSS দিয়ে নিয়ন্ত্রণ করা ভালো।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Caption Example</title>
</head>
<body>
  <table border="1" cellspacing="0" cellpadding="6">
    <caption>Student Information</caption>
    <tr>
      <th>Roll</th>
      <th>Name</th>
      <th>Result</th>
    </tr>
    <tr>
      <td>101</td>
      <td>Sakib</td>
      <td>A+</td>
    </tr>
  </table>
</body>
</html>
\end{verbatim}
\end{examplebox}

{table caption}


\subsection{\texttt{colgroup} Tag}

\begin{definitionbox}{\texttt{<colgroup>} tag}
Table-এর এক বা একাধিক column-এর জন্য একসাথে style বা property নির্ধারণ করতে \texttt{<colgroup>} tag ব্যবহার করা হয়।
\end{definitionbox}

\texttt{colgroup} ব্যবহার করলে কোনো নির্দিষ্ট column বা column group-কে আলাদা color/style দেওয়া যায়। এটি table-এর row শুরু হওয়ার আগে লেখা হয়, কারণ column style আগে ঠিক করে তারপর row data বসানো হয়।

একই ধরনের একাধিক column একসাথে style করতে \texttt{<col span="2">} ব্যবহার করা যায়। যেমন প্রথম দুই column এক color এবং পরের দুই column আরেক color করতে চাইলে \texttt{span} attribute helpful। প্রতিটি column আলাদা style চাইলে আলাদা আলাদা \texttt{<col>} tag লেখা হয়।

\begin{examplebox}{কোড}
\begin{verbatim}
<!DOCTYPE html>
<html>
<head>
  <title>Column Group Example</title>
</head>
<body>
<table border="1">
  <colgroup>
    <col style="background-color: yellow">
    <col style="background-color: lightgreen">
  </colgroup>
  <tr>
    <th>Title</th>
    <th>Author</th>
  </tr>
  <tr>
    <td>ICT HSC</td>
    <td>M. Hakim</td>
  </tr>
</table>
</body>
</html>
\end{verbatim}
\end{examplebox}

\subsection{Table-এর ভিতরে Formatting, Link, Image ও List}

Table cell-এর ভিতরে শুধু text নয়, HTML-এর অন্য element-ও রাখা যায়। PDF-এর table discussion-এ cell-এর ভিতরে text, image, photograph, list, form, horizontal line, hyperlink এবং আরেকটি table রাখার ধারণা আছে। তাই table ব্যবহার করে result sheet-এর সাথে photo, product list-এর সাথে buy link, course plan-এর সাথে ordered list বা nested information দেখানো সম্ভব।

\begin{keypointbox}{Cell-এর ভিতরে content রাখার নিয়ম}
Cell-এর ভিতরে content রাখতে হলে content অবশ্যই \texttt{<td>} বা \texttt{<th>} tag-এর opening ও closing tag-এর মাঝখানে লিখতে হবে। যেমন image বসাতে \texttt{<td><img src="photo.jpg"></td>} এবং link বসাতে \texttt{<td><a href="page.html">Open</a></td>} লিখতে হবে।
\end{keypointbox}

\subsection{Semantic ও Readability Note}

HSC book-style code-এ \texttt{border}, \texttt{cellpadding}, \texttt{cellspacing}, \texttt{align}, \texttt{bgcolor} attribute দেখা যায়। এগুলো practical exam-এর জন্য জানা দরকার। তবে modern HTML-এ table-এর visual style সাধারণত CSS দিয়ে করা হয়। Table-এর meaning পরিষ্কার রাখতে heading cell-এ \texttt{<th>} ব্যবহার করা উচিত এবং table-এর title থাকলে \texttt{<caption>} ব্যবহার করা উচিত।

\begin{boardbox}{ভালো table code-এর বৈশিষ্ট্য}
\begin{itemize}
\item Table data row-column আকারে logical হবে।
\item Heading cell-এ \texttt{<th>} ব্যবহার করা হবে।
\item Caption থাকলে \texttt{<caption>} table-এর শুরুতে লেখা হবে।
\item Image থাকলে \texttt{alt} attribute ব্যবহার করা হবে।
\item Link থাকলে meaningful text ব্যবহার করা হবে।
\item Tag indentation পরিষ্কার হলে code পড়া সহজ হবে।
\end{itemize}
\end{boardbox}

\subsection{চিত্র দেখে Table লেখার Final Checklist}

Board practical বা CQ-তে table-এর চিত্র দেওয়া থাকলে নিচের checklist ব্যবহার করলে ভুল কম হয়। এটি simple table, merged table, image/link/list-সহ table এবং nested table--সব ধরনের প্রশ্নে কাজে লাগে।

\begin{enumerate}
\item Table-এর নাম বা caption আছে কি না দেখবে।
\item Header row আছে কি না দেখবে।
\item Visible column সংখ্যা গুনবে।
\item Visible row সংখ্যা গুনবে।
\item Merged cell থাকলে আগে \texttt{rowspan} না \texttt{colspan} তা ঠিক করবে।
\item যে cell-এ image আছে সেখানে \texttt{<img>} এবং \texttt{alt} লিখবে।
\item যে cell-এ link আছে সেখানে \texttt{<a href="">} ব্যবহার করবে।
\item যে cell-এ list আছে সেখানে \texttt{<ol>} বা \texttt{<ul>} ব্যবহার করবে।
\item Nested table থাকলে inner table আলাদা indentation দিয়ে লিখবে।
\item শেষে সব \texttt{<table>}, \texttt{<tr>}, \texttt{<td>} tag close হয়েছে কি না মিলিয়ে দেখবে।
\end{enumerate}

\begin{keypointbox}{শেষ মুহূর্তের পরীক্ষা}
Code লেখা শেষ হলে প্রতিটি row আলাদা করে দেখবে: row-এর মোট column count figure-এর সাথে মিলছে কি না। \texttt{colspan="2"} মানে ওই cell দুই column-এর জায়গা নিয়েছে, তাই সেই row-তে একটি cell কম থাকবে। \texttt{rowspan="2"} মানে পরের row-তে ওই column-এর জন্য নতুন cell লিখতে হবে না।
\end{keypointbox}

\subsection{Board/Exam Focus}

\begin{boardbox}{বেশি গুরুত্বপূর্ণ}
\begin{itemize}
\item \texttt{<table>} tag table তৈরির জন্য ব্যবহৃত হয়।
\item \texttt{<tr>} row তৈরি করে।
\item \texttt{<th>} heading cell তৈরি করে।
\item \texttt{<td>} data cell তৈরি করে।
\item \texttt{<caption>} table-এর title দেয়।
\item \texttt{border} table border দেখায়।
\item \texttt{cellspacing} cell-এর মাঝের gap নির্ধারণ করে।
\item \texttt{cellpadding} cell-এর ভিতরের gap নির্ধারণ করে।
\item \texttt{rowspan} cell-কে vertical direction-এ merge করে।
\item \texttt{colspan} cell-কে horizontal direction-এ merge করে।
\item table-এর ভিতরে link, image, list এবং nested table ব্যবহার করা যায়।
\item চিত্র দেখে HTML table code লিখতে পারা খুব গুরুত্বপূর্ণ।
\end{itemize}
\end{boardbox}

\subsection{Exam-style Short Answer}

\begin{enumerate}
\item \textbf{HTML table কী?}\\
উত্তর: HTML document-এ তথ্যকে সারি ও কলাম আকারে প্রদর্শনের জন্য যে কাঠামো ব্যবহার করা হয়, তাকে HTML table বলে। Table তৈরির জন্য \texttt{<table>} tag ব্যবহার করা হয়।

\item \textbf{\texttt{<tr>} tag-এর কাজ কী?}\\
উত্তর: HTML table-এর একটি row বা সারি তৈরি করার জন্য \texttt{<tr>} tag ব্যবহার করা হয়।

\item \textbf{\texttt{<th>} ও \texttt{<td>} tag-এর পার্থক্য লেখ।}\\
উত্তর: \texttt{<th>} tag table-এর heading cell তৈরি করে এবং browser সাধারণত এর text bold ও center aligned করে দেখায়। অন্যদিকে \texttt{<td>} tag table-এর সাধারণ data cell তৈরি করে।

\item \textbf{\texttt{border} attribute-এর কাজ কী?}\\
উত্তর: HTML table-এর চারপাশে এবং cell-এর চারপাশে border বা রেখা প্রদর্শনের জন্য \texttt{border} attribute ব্যবহার করা হয়।

\item \textbf{\texttt{cellspacing} ও \texttt{cellpadding}-এর পার্থক্য লেখ।}\\
উত্তর: \texttt{cellspacing} cell থেকে cell-এর মাঝের gap নির্ধারণ করে। অন্যদিকে \texttt{cellpadding} cell-এর content এবং cell border-এর মাঝের ভিতরের gap নির্ধারণ করে।

\item \textbf{\texttt{rowspan} ও \texttt{colspan}-এর পার্থক্য লেখ।}\\
উত্তর: \texttt{rowspan} একটি cell-কে একাধিক row জুড়ে বিস্তৃত করে। \texttt{colspan} একটি cell-কে একাধিক column জুড়ে বিস্তৃত করে।

\item \textbf{Table-এর ভিতরে image বসানোর code লেখ।}\\
উত্তর: \texttt{<td><img src="photo.jpg" width="100" height="80" alt="Photo"></td>}

\item \textbf{Nested table কী?}\\
উত্তর: একটি table-এর কোনো cell-এর ভিতরে আরেকটি table তৈরি করলে তাকে nested table বলে।
\end{enumerate}

\subsubsection{ঘ. বিশ্লেষণ}

\texttt{border="1"} table ও cell-এর চারপাশে border দেখায়। \texttt{cellspacing="0"} cellগুলোর মাঝের gap দূর করে। \texttt{cellpadding="5"} cell-এর ভিতরে content ও border-এর মাঝে ৫ pixel space তৈরি করে, ফলে table পড়তে সহজ হয়। \texttt{colspan="3"} প্রথম heading cell-কে তিনটি column জুড়ে বিস্তৃত করে, তাই \texttt{Result Sheet} title পুরো table-এর উপর দেখা যায়।

\subsection{Common Mistake}

\begin{mistakebox}{সাধারণ ভুল}
\begin{itemize}
\item \texttt{<table>} tag close না করা।
\item \texttt{<tr>} ছাড়া সরাসরি \texttt{<td>} লেখা।
\item heading cell-এ \texttt{<td>} ব্যবহার করা, যেখানে \texttt{<th>} ভালো।
\item \texttt{<td>}-এর spelling ভুল করে \texttt{<tb>} লেখা।
\item \texttt{cellpadding} ও \texttt{cellspacing} গুলিয়ে ফেলা।
\item \texttt{rowspan} ও \texttt{colspan} উল্টো ব্যবহার করা।
\item border না দিলে table-এর রেখা দেখা যাবে না--এটা ভুলে যাওয়া।
\item table row ও column সংখ্যা figure-এর সাথে না মেলানো।
\item \texttt{<caption>} ভুল জায়গায় লেখা। Caption সাধারণত \texttt{<table>} tag-এর ভিতরে, প্রথম row-এর আগে লেখা হয়।
\item table-এর ভিতরে image/link/list লিখতে syntax ভুল করা।
\item image tag-এ \texttt{src} ভুল দেওয়া বা image file একই folder-এ না রাখা।
\item nested table-এর closing tag ঠিকমতো না দেওয়া।
\end{itemize}
\end{mistakebox}

\subsection{১ মিনিটে রিভিশন}

\begin{recapbox}
Table তৈরি হয় row ও column দিয়ে। \texttt{<table>} পুরো table তৈরি করে, \texttt{<tr>} table row তৈরি করে, \texttt{<th>} heading cell তৈরি করে এবং \texttt{<td>} data cell তৈরি করে। \texttt{border} table border দেখায়, \texttt{cellspacing} cell-এর মাঝের gap নিয়ন্ত্রণ করে এবং \texttt{cellpadding} cell-এর ভিতরের gap নিয়ন্ত্রণ করে। \texttt{<caption>} table-এর title দেয়। \texttt{rowspan} vertical merge এবং \texttt{colspan} horizontal merge করে। Table cell-এর ভিতরে text, link, image, list ও nested table রাখা যায়। HSC CQ-তে table চিত্র দেখে code লেখা খুব গুরুত্বপূর্ণ।
\end{recapbox}
