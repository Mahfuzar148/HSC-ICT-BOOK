\sectionheading{5.44 Python-এ Function}

একই ধরনের কাজ Program-এর বিভিন্ন স্থানে বারবার প্রয়োজন হলে একই Code
বারবার না লিখে সেই কাজকে একটি নির্দিষ্ট অংশে রাখা যায়।
এই পুনঃব্যবহারযোগ্য Code Block-কে \textbf{Function} বলা হয়।

%================================================
% Definition
%================================================

\booksubheading{Function কী?}

\begin{definitionbox}

নির্দিষ্ট কোনো কাজ সম্পন্ন করার জন্য তৈরি পুনঃব্যবহারযোগ্য
Code Block-কে \textbf{Function} বলে।

\end{definitionbox}

\begin{center}

\textbf{একবার Function তৈরি}
\(\longrightarrow\)
\textbf{প্রয়োজনমতো Call}
\(\longrightarrow\)
\textbf{একই কাজ পুনরায় সম্পন্ন}

\end{center}

%================================================
% Benefits
%================================================

\booksubheading{Function ব্যবহারের সুবিধা}

\begin{compacttwocolpoints}

\item একই Code বারবার লিখতে হয় না।

\item Code পুনঃব্যবহার করা যায়।

\item Program ছোট, গোছানো ও সহজবোধ্য হয়।

\item বড় Problem-কে ছোট ছোট অংশে ভাগ করা যায়।

\item Program পরিবর্তন, পরীক্ষা ও রক্ষণাবেক্ষণ সহজ হয়।

\end{compacttwocolpoints}

|Y|
}

\hline
\rowcolor{softBlue}

\textbf{বিষয়}
&
\textenglish{\ttfamily print()}
&

\\
\hline

প্রধান কাজ
&
Output Screen-এ প্রদর্শন করে।
&
Value Function-এর বাইরে ফেরত দেয়।
\\
\hline

Result সংরক্ষণ
&
শুধু Print করলে Return Value হিসেবে পাওয়া যায় না।
&
Variable-এ রাখা যায়।
\\
\hline

পরে Calculation
&
Printed Output সরাসরি Result হিসেবে ব্যবহার করা যায় না।
&
Return করা Value ব্যবহার করা যায়।
\\
\hline

Function শেষ
&
অবশ্যই Function শেষ করে না।
&
Execute হলে Function শেষ হয়।
\\
\hline

\end{tabularx}

\end{minipage}
\hfill
\begin{minipage}[t]{0.43\linewidth}
\outputheading

\end{center}

\]

\end{minipage}

\end{codeoutputbox}

\begin{rememberbox}

\textbf{\color{deepOrange}MCQ Trap:}

\begin{center}

\textenglish{\ttfamily print()}

\end{center}

\textenglish{\ttfamily print()}
Output দেখায়, আর
\textenglish{\ttfamily return}
Result ফেরত দেয়।

\end{rememberbox}

\booksubheading{Function ও Modular Programming}

Function ব্যবহার করে বড় Program-কে ছোট ছোট Logical অংশে ভাগ করা যায়।

\begin{center}

\textbf{Main Program}
\(\longrightarrow\)
\textbf{Input Function}
\(\longrightarrow\)
\textbf{Calculation Function}
\(\longrightarrow\)
\textbf{Output Function}

\end{center}

এতে প্রতিটি Function একটি নির্দিষ্ট কাজ করে এবং পুরো Program
আরও সংগঠিত হয়। Function তাই \textbf{Modular Programming}-এর
একটি গুরুত্বপূর্ণ ভিত্তি।

-কে একই মনে করা।

\textenglish{\ttfamily return}
