\sectionheading{5.42 Loop Pattern}

Loop ব্যবহার করে কোনো নির্দিষ্ট বিন্যাসে Character, Symbol বা Number
বারবার Print করাকে সাধারণভাবে \textbf{Loop Pattern} বলা হয়।
Pattern তৈরিতে সাধারণত \textbf{Nested Loop} বেশি ব্যবহৃত হয়।

%================================================
% Basic Idea
%================================================

\booksubheading{Pattern তৈরির মূল ধারণা}

Pattern-কে সাধারণত \textbf{Row} ও \textbf{Column} হিসেবে চিন্তা করা হয়।

\begin{rememberbox}

\begin{center}

\textbf{Outer Loop}
\(\longrightarrow\)
\textbf{Row নিয়ন্ত্রণ করে}

\qquad

\textbf{Inner Loop}
\(\longrightarrow\)
\textbf{প্রতি Row-এর Item / Column নিয়ন্ত্রণ করে}

\medskip

\textbf{Outer Loop = কতটি Row}
\qquad
\textbf{Inner Loop = প্রতি Row-তে কতটি Item}

\end{center}

\end{rememberbox}

\booksubheading{সাধারণ ভুল}

\begin{rememberbox}

\begin{itemize}

\item Outer Loop ও Inner Loop-এর কাজ গুলিয়ে ফেলা।

\item একই Row-তে Output রাখার জন্য
\textenglish{\ttfamily end}
ব্যবহার না করা।

\item Row পরিবর্তনের
\textenglish{\ttfamily print()}
ভুল Indentation-এ রাখা।

\item Increasing Pattern-এ Inner Loop-এর Range ভুল লেখা।

\item Decreasing Pattern-এর Item সংখ্যা ভুল হিসাব করা।

\item
\textenglish{\ttfamily i}
ও
\textenglish{\ttfamily j}
-এর কাজ গুলিয়ে ফেলা।

\item
\textenglish{\ttfamily range()}
-এর Stop Value Excluded—এটি ভুলে যাওয়া।

\item Nested
\textenglish{\ttfamily while}
Loop-এ Inner Counter পুনরায় Initialize না করা।

\item Star-এর জায়গায়
\textenglish{\ttfamily i}
বা
\textenglish{\ttfamily j}
ভুলভাবে Print করা।

\end{itemize}

\end{rememberbox}
