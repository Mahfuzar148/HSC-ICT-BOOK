\booksubheading{File কেন প্রয়োজন?}

\booksubheading{File ব্যবহারের প্রয়োজনীয়তা}

File ব্যবহার করা হয়—

\begin{compacttwocolpoints}

\item Result, Report বা Log সংরক্ষণ করতে।

\item অনেক Data দীর্ঘ সময় ধরে রাখতে।

\item Saved Data ভবিষ্যতে আবার Process করতে।

\end{compacttwocolpoints}

\booksubheading{Python-এ File Handling}

Python Program শুধু Runtime-এর Variable নিয়ে কাজ করে না; প্রয়োজন হলে
Storage-এ থাকা File-এ Data লিখতে, File থেকে Data পড়তে এবং নতুন Data
যোগ করতেও পারে। Program-এর মাধ্যমে File খোলা, Data পড়া/লেখা এবং
File বন্ধ করার পুরো প্রক্রিয়াকে \textbf{File Handling} বলা হয়।

\begin{definitionbox}
\textbf{\color{darkTeal}File Handling:}

Python Program-এর সাহায্যে কোনো File \textbf{Open করা, Data Read করা,
Data Write/Append করা এবং কাজ শেষে File Close করার প্রক্রিয়াকে}
\textbf{File Handling} বলা হয়।
\end{definitionbox}

\begin{center}
\textbf{Python Program}
\(\longrightarrow\)
\textbf{\textenglish{\ttfamily open()}}
\(\longrightarrow\)
\textbf{File Object}
\(\longrightarrow\)
\textbf{Read / Write / Append}
\(\longrightarrow\)
\textbf{Close}
\end{center}

\begin{rememberbox}
\textbf{\color{deepOrange}Python-এর সঙ্গে File-এর সম্পর্ক}

Python হলো Program লেখার Language; আর File হলো Data স্থায়ীভাবে রাখার
Storage মাধ্যম। Python Program \textenglish{\ttfamily open()} Function-এর
মাধ্যমে File-এর সঙ্গে সংযোগ তৈরি করে এবং সেই File Object ব্যবহার করে
Data পড়া বা লেখা হয়।
\end{rememberbox}

\booksubheading{\textenglish{\ttfamily open()} দিয়ে File খোলা}

Python-এ File ব্যবহার করার আগে সাধারণত \textenglish{\ttfamily open()}
Function দিয়ে File খোলা হয়।

\begin{center}
\textenglish{\ttfamily file = open("filename", "mode")}
\end{center}

এখানে—

\begin{itemize}
\item \textenglish{\ttfamily "filename"} হলো যে File নিয়ে কাজ করা হবে তার নাম বা Path।
\item \textenglish{\ttfamily "mode"} দিয়ে File-টি Read, Write নাকি Append করার জন্য খোলা হবে তা নির্ধারণ করা হয়।
\item \textenglish{\ttfamily open()} একটি \textbf{File Object} Return করে; এই Object-এর মাধ্যমে File-এর Data নিয়ে কাজ করা হয়।
\end{itemize}

\begin{codeoutputbox}{File Open ও Close করার মৌলিক গঠন}
\noindent
\begin{minipage}[t]{0.54\linewidth}
\vspace{0pt}
\codeheading
\begin{english}
\ttfamily
file = open("result.txt", "w")\\
file.write("ICT = 85")\\
file.close()
\end{english}
\end{minipage}
\hfill
\begin{minipage}[t]{0.42\linewidth}
\vspace{0pt}
\outputheading

\textenglish{\ttfamily result.txt} নামে File তৈরি/খোলা হবে এবং সেখানে

\begin{center}
\textenglish{\ttfamily ICT = 85}
\end{center}

লেখা হবে। শেষে \textenglish{\ttfamily close()} File বন্ধ করবে।
\end{minipage}
\end{codeoutputbox}

\booksubheading{File Mode}

File খোলার সময় Mode নির্বাচন খুব গুরুত্বপূর্ণ।

\begin{tabularx}{\linewidth}{|C{0.12\linewidth}|>{\bfseries\RaggedRight\arraybackslash}p{0.20\linewidth}|Y|}
\hline
\rowcolor{softBlue}
\textbf{Mode} & \textbf{কাজ} & \textbf{গুরুত্বপূর্ণ বিষয়}\\
\hline
\textenglish{\ttfamily r} & Read & File থেকে Data পড়া হয়; File না থাকলে Error হতে পারে।\\
\hline
\textenglish{\ttfamily w} & Write & নতুন করে Data লেখা হয়; File না থাকলে তৈরি হয়, থাকলে আগের Content মুছে নতুন Content লেখা হয়।\\
\hline
\textenglish{\ttfamily a} & Append & আগের Content ঠিক রেখে File-এর শেষে নতুন Data যোগ করা হয়; File না থাকলে তৈরি হতে পারে।\\
\hline
\textenglish{\ttfamily x} & Create & নতুন File তৈরি করে; একই নামের File আগে থেকেই থাকলে Error হয়।\\
\hline
\end{tabularx}

\begin{rememberbox}
\textbf{\color{deepOrange}MCQ Trap}

\begin{center}
\textenglish{\ttfamily r} = Read
\qquad
\textenglish{\ttfamily w} = Write/Overwrite
\qquad
\textenglish{\ttfamily a} = Append
\end{center}

বিশেষ করে \textenglish{\ttfamily w} Mode ব্যবহার করলে পুরোনো File-এর
আগের Content হারিয়ে যেতে পারে।
\end{rememberbox}

\textenglish{\ttfamily t} Text Mode এবং \textenglish{\ttfamily b} Binary
Mode বোঝাতে ব্যবহৃত হতে পারে। সাধারণ Text File-এর ক্ষেত্রে
\textenglish{\ttfamily t} হলো Default; তাই সাধারণভাবে শুধু
\textenglish{\ttfamily r}, \textenglish{\ttfamily w} বা
\textenglish{\ttfamily a} লিখলেই Text Mode বোঝায়।

\booksubheading{Python File Handling-এর সাধারণ ভুল}

\begin{rememberbox}
\begin{itemize}
\item \textenglish{\ttfamily w} এবং \textenglish{\ttfamily a} Mode-কে একই মনে করা।
\item File না থাকা সত্ত্বেও \textenglish{\ttfamily r} Mode-এ Open করলে কী হতে পারে তা না বোঝা।
\item \textenglish{\ttfamily open()} করার পর File Object-এর বদলে শুধু File Name নিয়েই কাজ করার চেষ্টা করা।
\item কাজ শেষে \textenglish{\ttfamily close()} না করা, যখন \textenglish{\ttfamily with} ব্যবহার করা হয়নি।
\item Number সরাসরি \textenglish{\ttfamily write()}-এ দিলে সমস্যা হতে পারে—প্রয়োজনে \textenglish{\ttfamily str()} ব্যবহার করতে হয়।
\item \textenglish{\ttfamily .py} Program File এবং \textenglish{\ttfamily .txt} Data File-কে একই মনে করা।
\end{itemize}
\end{rememberbox}

\booksubheading{সাধারণ ভুল}

\begin{rememberbox}

\begin{itemize}

\item Function Contract-কে শুধু Function-এর নাম মনে করা।

\item Scope-কে Variable-এর Value মনে করা।

\item Local Variable Function-এর বাইরে ব্যবহার করা যাবে মনে করা।

\item Local ও Global Variable একই মনে করা।

\item Function-এর ভিতরে একই Name-এ Assignment করলেই Global Variable
পরিবর্তিত হবে মনে করা।

\item Global Variable শুধু পড়ার জন্যও সবসময়
\textenglish{\ttfamily global}
লাগে মনে করা।

\item
\textenglish{\ttfamily global}
Keyword-এর কাজ ভুল বোঝা।

\item সব Data Global Variable-এ রাখা ভালো Design মনে করা।

\item Variable-এর Data Program বন্ধ হওয়ার পরও স্থায়ী থাকবে মনে করা।

\item Temporary Data ও Persistent Data-কে একই মনে করা।

\item Runtime Memory ও File-কে একই ধরনের Storage মনে করা।

\end{itemize}

\end{rememberbox}
