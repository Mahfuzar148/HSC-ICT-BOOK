\booksubheading{Function Contract}

একটি Function তৈরি করার সময় আগে নির্ধারণ করা হয়—

\begin{center}

\textbf{কী Input নেবে}
\(\longrightarrow\)
\textbf{কী Processing করবে}
\(\longrightarrow\)
\textbf{কী Output দেবে}

\end{center}

\begin{definitionbox}

\textbf{Function Contract:}
কোনো Function \textbf{কী Input গ্রহণ করবে, কী কাজ বা Processing করবে
এবং কী Output/Return Value প্রদান করবে}—এ সম্পর্কে নির্ধারিত নিয়ম বা
শর্তকে \textbf{Function Contract} বলা হয়।

\end{definitionbox}

\booksubheading{Function Contract কেন গুরুত্বপূর্ণ?}

\begin{compacttwocolpoints}

\item Function কী কাজ করবে তা পরিষ্কার হয়।

\item কী ধরনের Input দিতে হবে বোঝা যায়।

\item কী Result আশা করা যায় তা জানা যায়।

\item Function আলাদাভাবে Test করা সহজ হয়।

\item বড় Problem-কে ছোট Function-এ ভাগ করা সহজ হয়।

\end{compacttwocolpoints}

\booksubheading{Valid Input-এর বিষয়}

Function Design-এর সময় কোন Input গ্রহণযোগ্য তা-ও বিবেচনা করা প্রয়োজন।

\begin{codeoutputbox}{Input-এর শর্ত}

\noindent
\begin{minipage}[t]{0.52\linewidth}
\codeheading

\begin{english}
\ttfamily
def divide(a, b):\\
\hspace*{4mm}return a / b\\[0.5mm]
print(divide(10, 0))
\end{english}

\end{minipage}
\hfill
\begin{minipage}[t]{0.44\linewidth}
\outputheading

এখানে Error হবে।

কারণ Division-এর ক্ষেত্রে Divisor
\textenglish{\ttfamily 0}
হতে পারে না।

\medskip

অর্থাৎ Function-এর Contract-এর অংশ হিসেবে
Valid Input-এর শর্তও বিবেচনা করা দরকার।

\end{minipage}

\end{codeoutputbox}
