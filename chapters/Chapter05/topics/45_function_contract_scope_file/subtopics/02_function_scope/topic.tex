\booksubheading{Function Scope}

Program-এর সব Variable সব জায়গা থেকে ব্যবহার করা যায় না।

\begin{definitionbox}

\textbf{Scope:}
Program-এর যে নির্দিষ্ট অংশে কোনো Variable বা Name-কে
Access বা ব্যবহার করা যায়, সেই ব্যবহারযোগ্য সীমা বা অঞ্চলকে
তার \textbf{Scope} বলে।

\medskip

\textbf{Function Scope:}
একটি Function-এর সঙ্গে সম্পর্কিত Variable বা Name
কোন অংশে Access করা যাবে, সেই সীমাকে
\textbf{Function Scope} বলা হয়।

\end{definitionbox}
