\sectionheading{5.45 Computational Thinking — Function Contract, Scope ও File}

\begin{definitionbox}

\textbf{Computational Thinking:}
কোনো সমস্যা বিশ্লেষণ করে তাকে ছোট ও সহজ অংশে ভাগ করা এবং
যৌক্তিক ও ধাপে ধাপে এমনভাবে সমাধান পরিকল্পনা করাকে
\textbf{Computational Thinking} বলে, যাতে সেই সমাধান কম্পিউটারের
মাধ্যমে বাস্তবায়ন করা যায়।

\end{definitionbox}

এই অংশে Computational Thinking-এর আলোকে একটি Function
\textbf{কী Input নেবে, কী কাজ করবে, কী Result দেবে, Variable কোথায়
ব্যবহার করা যাবে এবং Program বন্ধ হওয়ার পরও Data কেন সংরক্ষণ করতে হয়}
—এসব বিষয় আলোচনা করা হবে।
