&
Compiler পুরো Program একসঙ্গে Translate করে; Interpreter সাধারণত Statement ধরে Translate/Execute করে। ফলে Translation ও Error handling-এর পদ্ধতি ভিন্ন।
\\
\hline

Algorithm আগে তৈরি করা হয় কেন?
&
Code লেখার আগে Problem-এর Logic পরিষ্কার হয় এবং ভুল কমে।
\\
\hline

Flowchart ব্যবহার করা হয় কেন?
&
Program Logic দৃশ্যমানভাবে বোঝা, বিশ্লেষণ এবং ব্যাখ্যা করা সহজ হয়।
\\
\hline

IPO Model কেন গুরুত্বপূর্ণ?
&
Problem-এর Input, Processing এবং Expected Output আলাদাভাবে শনাক্ত করতে সাহায্য করে।
\\
\hline

Dry Run কেন করা হয়?
&
Program Execute করার আগেই Logic ও Variable-এর পরিবর্তন যাচাই করা যায়।
\\
\hline

Python-এ Indentation গুরুত্বপূর্ণ কেন?
&
Indentation দ্বারা Python-এর Code Block নির্ধারিত হয়।
\\
\hline

\py{input()}-এর Result অনেক সময় Convert করতে হয় কেন?
&
\py{input()} সাধারণত String দেয়; Arithmetic করার জন্য প্রয়োজন অনুযায়ী \py{int()} বা \py{float()} দরকার হয়।
\\
\hline

\py{range(1, n+1)}-এ \py{n+1} কেন?
&
\py{range()}-এর Stop Value অন্তর্ভুক্ত হয় না; তাই \(n\) পর্যন্ত Value পেতে \py{n+1} দেওয়া হয়।
\\
\hline

Factorial-এর ক্ষেত্রে \py{fact = 1} নেওয়া হয় কেন?
&
Factorial-এ বারবার গুণ হয় এবং Multiplication-এর Neutral Initial Value হলো 1।
\\
\hline

Sum-এর ক্ষেত্রে \py{total = 0} নেওয়া হয় কেন?
&
Addition-এর Neutral Initial Value হলো 0।
\\
\hline

Function ব্যবহার করা ভালো কেন?
&
Code reuse, modularity, readability এবং maintenance সহজ হয়।
\\
\hline

\py{return} কেন গুরুত্বপূর্ণ?
&
Function-এর Result Caller-এর কাছে ফেরত দেয়; ফলে Result অন্য জায়গায় ব্যবহার করা যায়।
\\
\hline

Global Variable কম ব্যবহার করা ভালো কেন?
&
অপ্রয়োজনীয় Global Variable Program-এর বিভিন্ন অংশের মধ্যে Dependency বাড়াতে পারে।
\\
\hline

File কেন প্রয়োজন?
&
Program বন্ধ হওয়ার পরও Data সংরক্ষণ বা পরে আবার ব্যবহার করার প্রয়োজন হতে পারে।
\\
