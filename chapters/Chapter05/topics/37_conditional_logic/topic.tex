\sectionheading{5.37 Conditional Logic Statement}

Program-এ সব Statement সবসময় Execute করতে হয় না।
কোনো Condition সত্য বা মিথ্যা হওয়ার উপর নির্ভর করে
নির্দিষ্ট Code Block Execute করার জন্য
\textbf{Conditional Logic Statement} ব্যবহার করা হয়।

%================================================
% Definition
%================================================

\booksubheading{Conditional Statement কী?}

\begin{definitionbox}

কোনো Condition পরীক্ষা করে তার ফলাফল অনুযায়ী Program-এর
নির্দিষ্ট Statement বা Code Block Execute করার পদ্ধতিকে
\textbf{Conditional Statement} বলে।

\end{definitionbox}

\begin{center}

\textbf{Condition পরীক্ষা}
\(\longrightarrow\)
\textenglish{\ttfamily True / False}
\(\longrightarrow\)
\textbf{প্রয়োজনীয় Code Block Execute}

\end{center}

উদাহরণ—

\begin{codebox}
\begin{english}
\ttfamily
age = 18\\
if age >= 18:\\
\hspace*{4mm}print("Adult")
\end{english}
\end{codebox}

এখানে
\textenglish{\ttfamily age >= 18}
Condition সত্য হলে
\textenglish{\ttfamily Adult}
প্রদর্শিত হবে।

\booksubheading{১. \textenglish{\ttfamily if} Statement}

কোনো Condition
\textenglish{\ttfamily True}
হলে নির্দিষ্ট Code Block Execute করতে
\textenglish{\ttfamily if}
Statement ব্যবহার করা হয়।

\textbf{Syntax—}

\begin{codebox}
\begin{english}
\ttfamily
if condition:\\
\hspace*{4mm}statement
\end{english}
\end{codebox}

\begin{examplebox}{উদাহরণ}

\begin{codebox}
\begin{english}
\ttfamily
marks = 80\\
if marks >= 40:\\
\hspace*{4mm}print("Pass")
\end{english}
\end{codebox}

\textbf{Output:}
\textenglish{\ttfamily Pass}

\end{examplebox}

\begin{center}

\textbf{Condition True}
\(\longrightarrow\)
\textenglish{\ttfamily if}
Block Execute

\qquad

\textbf{Condition False}
\(\longrightarrow\)
Block Skip

\end{center}

\booksubheading{২. \textenglish{\ttfamily if ... else} Statement}

Condition True হলে একটি Block এবং False হলে অন্য Block
Execute করার জন্য
\textenglish{\ttfamily if ... else}
ব্যবহার করা হয়।

\textbf{Syntax—}

\begin{codebox}
\begin{english}
\ttfamily
if condition:\\
\hspace*{4mm}statement1\\
else:\\
\hspace*{4mm}statement2
\end{english}
\end{codebox}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{Pass–Fail}

\begin{sidecodebox}
\begin{english}
\ttfamily
marks = 35\\
if marks >= 40:\\
\hspace*{4mm}print("Pass")\\
else:\\
\hspace*{4mm}print("Fail")
\end{english}
\end{sidecodebox}

Output:
\textenglish{\ttfamily Fail}

\end{sideexamplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{Even–Odd}

\begin{sidecodebox}
\begin{english}
\ttfamily
n = int(input())\\
if n \% 2 == 0:\\
\hspace*{4mm}print("Even")\\
else:\\
\hspace*{4mm}print("Odd")
\end{english}
\end{sidecodebox}

\textenglish{\ttfamily n \% 2 == 0}
হলে Even, অন্যথায় Odd।

\end{sideexamplebox}

\end{minipage}

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

\begin{center}

\textenglish{\ttfamily n \% 2 == 0}
\(\longrightarrow\)
Even

\qquad

\textenglish{\ttfamily n \% 2 != 0}
\(\longrightarrow\)
Odd

\end{center}

\textenglish{\ttfamily if ... else}
-এ দুইটি Block-এর মধ্যে একটিমাত্র Execute হয়।

\end{rememberbox}

\booksubheading{৩. \textenglish{\ttfamily if ... elif ... else}}

একাধিক Condition পর্যায়ক্রমে পরীক্ষা করার জন্য
\textenglish{\ttfamily elif}
ব্যবহার করা হয়।

\begin{center}
\textenglish{\ttfamily elif}
=
\textbf{else if}
\end{center}

\textbf{Syntax—}

\begin{codebox}
\begin{english}
\ttfamily
if condition1:\\
\hspace*{4mm}statement1\\
elif condition2:\\
\hspace*{4mm}statement2\\
else:\\
\hspace*{4mm}statement3
\end{english}
\end{codebox}

\begin{examplebox}{Grade নির্ণয়}

\begin{codebox}
\begin{english}
\ttfamily
marks = 75\\
if marks >= 80:\\
\hspace*{4mm}print("A+")\\
elif marks >= 70:\\
\hspace*{4mm}print("A")\\
elif marks >= 60:\\
\hspace*{4mm}print("A-")\\
else:\\
\hspace*{4mm}print("Below A-")
\end{english}
\end{codebox}

\textbf{Output:}
\textenglish{\ttfamily A}

\end{examplebox}

\booksubheading{\textenglish{\ttfamily elif} কীভাবে কাজ করে?}

Python ওপর থেকে নিচে Condition পরীক্ষা করে।
যে Condition প্রথম
\textenglish{\ttfamily True}
হয়, তার Block Execute হয় এবং পরবর্তী
\textenglish{\ttfamily elif/else}
Blockগুলো আর Execute হয় না।

\begin{center}

\textbf{Condition 1?}
\(\longrightarrow\)
False
\(\longrightarrow\)
\textbf{Condition 2?}
\(\longrightarrow\)
False
\(\longrightarrow\)
\textbf{Condition 3?}
\(\longrightarrow\)
\textbf{else}

\end{center}

\begin{rememberbox}

\textbf{\color{deepOrange}গুরুত্বপূর্ণ}

একাধিক Condition True হলেও
\textbf{প্রথম True Condition-এর Block-ই Execute হয়}।

\end{rememberbox}

c = 15\\[0.5mm]
if a >= b and a >= c:\\
\hspace*{4mm}print("a is largest")\\
elif b >= a and b >= c:\\
