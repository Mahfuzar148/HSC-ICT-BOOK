\sectionheading{5.33 Python Variable}

Program-এ Data বা Value-কে একটি নাম দিয়ে সংরক্ষণ ও ব্যবহার
করার জন্য \textbf{Variable} ব্যবহৃত হয়।

Python-এ C/C++-এর মতো Variable তৈরির আগে আলাদাভাবে
Data Type ঘোষণা করতে হয় না।

%================================================
% Definition
%================================================

\booksubheading{Python Variable কী?}

\begin{definitionbox}

\textbf{\color{darkTeal}সংজ্ঞা}

Python Program-এ কোনো Value-কে একটি নির্দিষ্ট নামের মাধ্যমে
সংরক্ষণ ও ব্যবহার করার জন্য যে নাম ব্যবহার করা হয় তাকে
\textbf{Variable} বলে।

\end{definitionbox}

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
age = 18
\end{english}

\end{codebox}

এখানে—

\begin{center}

\textenglish{\ttfamily age}
\(\longrightarrow\)
\textbf{Variable Name}
\qquad
\textenglish{\ttfamily 18}
\(\longrightarrow\)
\textbf{Value}
\qquad
\textenglish{\ttfamily =}
\(\longrightarrow\)
\textbf{Assignment Operator}

\end{center}

%================================================
% Creating Variable
%================================================

\booksubheading{Python-এ Variable তৈরি}

Python-এ কোনো নামের সঙ্গে Value Assign করলেই Variable তৈরি হয়।

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
x = 10\\
name = "Rahim"
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily x}
এবং
\textenglish{\ttfamily name}
দুটি Variable।

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

Python-এ সাধারণভাবে—

\begin{codebox}

\begin{english}
\ttfamily
int x
\end{english}

\end{codebox}

এভাবে Variable Declare করতে হয় না।

বরং—

\begin{codebox}

\begin{english}
\ttfamily
x = 10
\end{english}

\end{codebox}

লিখলেই Variable তৈরি হয়।

\end{rememberbox}

%================================================
% Assignment
%================================================

\booksubheading{Assignment}

Python-এ
\textenglish{\ttfamily =}
চিহ্ন ব্যবহার করে Variable-এর সঙ্গে Value Assign করা হয়।

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
number = 50
\end{english}

\end{codebox}

Assignment-এর সাধারণ রূপ—

\begin{center}

\textbf{Variable}
\(\;=\;\)
\textbf{Value}

\end{center}

অর্থাৎ—

\begin{center}

\textbf{ডান পাশের Value}
\(\longrightarrow\)
\textbf{বাম পাশের Variable}

\end{center}

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
price = 500
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily 500}
Value-টি
\textenglish{\ttfamily price}
Variable-এর সঙ্গে Assign করা হয়েছে।

%================================================
% Using Variable
%================================================

\booksubheading{Variable-এর Value ব্যবহার}

Variable তৈরি করার পর Variable-এর নাম ব্যবহার করে তার
Value নিয়ে কাজ করা যায়।

\begin{examplebox}{উদাহরণ}

\begin{codebox}

\begin{english}
\ttfamily
age = 18\\
print(age)
\end{english}

\end{codebox}

\textbf{Output:}

\begin{codebox}

\begin{english}
\ttfamily
18
\end{english}

\end{codebox}

\end{examplebox}

%================================================
% Changing Value
%================================================

\booksubheading{Variable-এর Value পরিবর্তন}

একই Variable-এ পরে নতুন Value Assign করা যায়।

\begin{codebox}

\begin{english}
\ttfamily
x = 10\\
x = 20\\
print(x)
\end{english}

\end{codebox}

\textbf{Output:}

\begin{codebox}

\begin{english}
\ttfamily
20
\end{english}

\end{codebox}

শেষের Assignment-এ
\textenglish{\ttfamily x}
-এর নতুন Value হয়েছে
\textenglish{\ttfamily 20}।

\begin{center}

\textenglish{\ttfamily x = 10}
\(\longrightarrow\)
\textenglish{\ttfamily x = 20}
\(\longrightarrow\)
\textbf{বর্তমান Value = 20}

\end{center}

\booksubheading{Python Variable নামকরণের নিয়ম}

Variable-এর নাম লেখার ক্ষেত্রে কিছু নির্দিষ্ট নিয়ম মানতে হয়।

%------------------------------------------------
% Rule 1
%------------------------------------------------

\textbf{\color{darkTeal}১. Letter বা Underscore দিয়ে শুরু করা যায়}

\textbf{সঠিক—}

\begin{codebox}

\begin{english}
\ttfamily
name = "Rafi"\\
\_age = 18
\end{english}

\end{codebox}

\textbf{ভুল—}

\begin{codebox}

\begin{english}
\ttfamily
2name = "Rafi"
\end{english}

\end{codebox}

কারণ Variable Name Digit দিয়ে শুরু হতে পারে না।

%------------------------------------------------
% Rule 2
%------------------------------------------------

\textbf{\color{darkTeal}২. Letter, Digit ও Underscore ব্যবহার করা যায়}

সঠিক উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
student1 = "Rahim"\\
roll\_10 = 25\\
total\_marks = 450
\end{english}

\end{codebox}

Variable Name-এ Letter, Digit ও Underscore ব্যবহার করা যায়;
তবে Digit প্রথম Character হতে পারে না।

%------------------------------------------------
% Rule 3
%------------------------------------------------

\textbf{\color{darkTeal}৩. Space ব্যবহার করা যায় না}

\textbf{ভুল—}

\begin{codebox}

\begin{english}
\ttfamily
student name = "Rahim"
\end{english}

\end{codebox}

\textbf{সঠিক—}

\begin{codebox}

\begin{english}
\ttfamily
student\_name = "Rahim"
\end{english}

\end{codebox}

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

\begin{center}

\textbf{Space নয়}
\(\longrightarrow\)
\textbf{Underscore \textenglish{\ttfamily \_} ব্যবহার করা যায়}

\end{center}

\end{rememberbox}

%------------------------------------------------
% Rule 4
%------------------------------------------------

\textbf{\color{darkTeal}৪. Special Character ব্যবহার করা যায় না}

Variable Name-এ সাধারণভাবে নিচের ধরনের Special Character
ব্যবহার করা যায় না—

\begin{center}

\textenglish{\ttfamily @ \quad \# \quad \$ \quad \% \quad -}

\end{center}

\textbf{ভুল—}

\begin{codebox}

\begin{english}
\ttfamily
total-marks = 500\\
price\$ = 100
\end{english}

\end{codebox}

\textbf{সঠিক—}

\begin{codebox}

\begin{english}
\ttfamily
total\_marks = 500\\
price = 100
\end{english}

\end{codebox}

%------------------------------------------------
% Rule 5
%------------------------------------------------

\textbf{\color{darkTeal}৫. Python Keyword Variable Name হতে পারে না}

Python-এর Reserved Keyword Variable-এর নাম হিসেবে ব্যবহার
করা যায় না।

\textbf{ভুল—}

\begin{codebox}

\begin{english}
\ttfamily
if = 10\\
for = 20
\end{english}

\end{codebox}

কারণ
\textenglish{\ttfamily if}
ও
\textenglish{\ttfamily for}
Python Keyword।

\begin{rememberbox}

\textbf{\color{deepOrange}MCQ তথ্য}

\begin{center}

\textbf{Python Keyword}
\(\longrightarrow\)
\textbf{Variable Name হিসেবে ব্যবহার করা যায় না}

\end{center}

\end{rememberbox}

%------------------------------------------------
% Rule 6
%------------------------------------------------

\textbf{\color{darkTeal}৬. Python Variable Case Sensitive}

Python Variable Name Case Sensitive।

\begin{codebox}

\begin{english}
\ttfamily
age = 18\\
Age = 20\\
AGE = 25
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily age},
\textenglish{\ttfamily Age}
এবং
\textenglish{\ttfamily AGE}
তিনটি আলাদা Variable।

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

\begin{center}

\textenglish{\ttfamily name}
\(\neq\)
\textenglish{\ttfamily Name}
\(\neq\)
\textenglish{\ttfamily NAME}

\end{center}

\end{rememberbox}

student\_name = "Mina"\\

total\_price = 800
\end{english}

\end{codebox}

\begin{rememberbox}

\textbf{\color{deepOrange}সহজভাবে মনে রাখবে}

\booksubheading{Multiple Assignment}

Python-এ একই Statement-এ একাধিক Variable-এর সঙ্গে
একাধিক Value Assign করা যায়।

\begin{codebox}

\begin{english}
\ttfamily
a, b, c = 10, 20, 30
\end{english}

\end{codebox}

এখানে—

\begin{center}

\textenglish{\ttfamily a = 10}
\qquad
\textenglish{\ttfamily b = 20}
\qquad
\textenglish{\ttfamily c = 30}

\end{center}

\booksubheading{একই Value একাধিক Variable-এ Assign}

একাধিক Variable-এর সঙ্গে একই Value Assign করাও সম্ভব।

\begin{codebox}

\begin{english}
\ttfamily

\end{english}

\end{codebox}

এর ফলে—

\begin{center}

\textenglish{\ttfamily x = 100}
\qquad
\textenglish{\ttfamily y = 100}
\qquad
\textenglish{\ttfamily z = 100}

\end{center}

\booksubheading{Variable-এর Value অদলবদল}

Python-এ দুটি Variable-এর Value সহজে Swap করা যায়।

\begin{codebox}

\begin{english}
\ttfamily
a = 10\\
b = 20\\[1mm]
a, b = b, a
\end{english}

\end{codebox}

এরপর—

\begin{center}

\textenglish{\ttfamily a = 20}
\qquad
\textenglish{\ttfamily b = 10}

\end{center}

\begin{rememberbox}

\textbf{\color{deepOrange}Python Shortcut}

দুটি Variable-এর Value Swap—

\begin{center}

\textenglish{\ttfamily a, b = b, a}

\end{center}

\end{rememberbox}

\booksubheading{Variable Delete করা}

প্রয়োজনে
\textenglish{\ttfamily del}

\begin{codebox}

\end{english}

\end{codebox}

এরপর
\textenglish{\ttfamily x}
নামটি ব্যবহার করতে গেলে Error হতে পারে।

\begin{rememberbox}

\textbf{\color{deepOrange}MCQ তথ্য}

\begin{center}

\textenglish{\ttfamily del}
\(\longrightarrow\)
\textbf{Variable-এর binding মুছে দিতে ব্যবহৃত হয়}

\end{center}

\end{rememberbox}

\booksubheading{সাধারণ ভুল}

\begin{compacttwocolpoints}

\item Variable Name Digit দিয়ে শুরু করা।

\item Variable Name-এর মধ্যে Space ব্যবহার করা।

\item
\textenglish{\ttfamily -},
\textenglish{\ttfamily @},
\textenglish{\ttfamily \#}
ইত্যাদি Special Character ব্যবহার করা।

\item Python Keyword-কে Variable Name হিসেবে ব্যবহার করা।

\item
\textenglish{\ttfamily age}
ও
\textenglish{\ttfamily Age}
-কে একই Variable মনে করা।

\item
\textenglish{\ttfamily =}
-কে Mathematical Equality মনে করা।

\item Value Assign করার আগে Variable ব্যবহার করার চেষ্টা করা।

\item অর্থহীন বা অস্পষ্ট Variable Name ব্যবহার করা।

\end{compacttwocolpoints}
