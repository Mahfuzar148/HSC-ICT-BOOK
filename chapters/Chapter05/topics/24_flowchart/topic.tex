\sectionheading{5.24 ফ্লোচার্ট (Flowchart)}

কোনো Problem-এর Algorithm তৈরি করার পর ধাপগুলোকে শুধু লিখিতভাবে
না রেখে \textbf{নির্দিষ্ট প্রতীক ও প্রবাহরেখার সাহায্যে চিত্রে প্রকাশ}
করা যায়।

এতে কোন কাজের পর কোন কাজ হবে, কোথায় Decision নিতে হবে এবং
কাজের প্রবাহ কোন দিকে যাবে—তা এক নজরে বোঝা যায়।

%================================================
% Definition
%================================================

\booksubheading{Flowchart কাকে বলে?}

\begin{definitionbox}

\textbf{\color{darkTeal}সংজ্ঞা}

কোনো নির্দিষ্ট Problem সমাধানের প্রয়োজনীয় ধাপগুলোকে
\textbf{প্রচলিত প্রতীক (Symbol) ও প্রবাহরেখা (Flow line)-এর মাধ্যমে
চিত্রাকারে প্রকাশ করাকে Flowchart} বলে।

\end{definitionbox}

\textbf{সহজভাবে মনে রাখবে—}

\begin{center}

\textbf{Algorithm-এর ধাপ}
\(\longrightarrow\)
\textbf{Symbol দিয়ে চিত্র}
\(\longrightarrow\)
\textbf{Flowchart}

\end{center}

অর্থাৎ Algorithm ধাপগুলো লিখে দেয়, আর Flowchart সেই ধাপগুলোর
\textbf{চিত্রভিত্তিক প্রবাহ} দেখায়।

%================================================
% Importance
%================================================

\booksubheading{Flowchart কেন প্রয়োজন?}

Flowchart তৈরি করলে—

\begin{compacttwocolpoints}

\item Problem-এর Solution সহজে বোঝা যায়।

\item Program-এর কাজের ধারাবাহিকতা এক নজরে দেখা যায়।

\item Program লেখার আগে Logic যাচাই করা যায়।

\item ভুল বা অসংগতি শনাক্ত করা সহজ হয়।

\item Flowchart দেখে Program Code লেখা তুলনামূলক সহজ হয়।

\item Program ব্যাখ্যা, পরিবর্তন ও রক্ষণাবেক্ষণে সুবিধা হয়।

\end{compacttwocolpoints}

%================================================
% Types
%================================================

\booksubheading{Flowchart-এর প্রকারভেদ}

Flowchart প্রধানত দুই ধরনের—

\begin{enumerate}

\item
\textbf{Program Flowchart:}
কোনো নির্দিষ্ট Program-এর ধাপ, Calculation, Condition,
Decision ও Output-এর প্রবাহ চিত্রের মাধ্যমে প্রকাশ করে।

\item
\textbf{System Flowchart:}
কোনো সম্পূর্ণ System-এর Input, Processing, Storage ও Output-এর
পারস্পরিক সম্পর্ক ও তথ্যপ্রবাহ চিত্রের মাধ্যমে প্রকাশ করে।

\end{enumerate}

\booksubheading{Flowchart আঁকার সাধারণ নিয়ম}

Flowchart আঁকার সময়—

\begin{enumerate}

\item
প্রথমে \textbf{Start} এবং সর্বশেষে
\textbf{End/Stop} ব্যবহার করতে হয়।

\item
প্রতিটি কাজের জন্য নির্ধারিত উপযুক্ত Symbol ব্যবহার করতে হয়।

\item
Flow line বা Arrow দিয়ে কাজের প্রবাহের দিক দেখাতে হয়।

\item
সাধারণত Flow উপর থেকে নিচে অথবা বাম থেকে ডানে দেখানো হয়।

\item
Decision-এর শাখায় প্রয়োজন অনুযায়ী
\textbf{Yes/No} বা \textbf{True/False} লিখতে হয়।

\item
Flow line-এর অপ্রয়োজনীয় ছেদ এড়িয়ে চলতে হয়।

\item
প্রয়োজন হলে বিচ্ছিন্ন অংশ যুক্ত করতে
\textbf{Connector} ব্যবহার করতে হয়।

\item
Flowchart পরিষ্কার, সংক্ষিপ্ত ও যৌক্তিক হওয়া উচিত।

\end{enumerate}

\booksubheading{একটি ভালো Flowchart-এর বৈশিষ্ট্য}

একটি ভালো Flowchart—

\begin{compacttwocolpoints}

\item সহজ ও বোধগম্য হবে।

\item ধাপগুলো সঠিক ও যৌক্তিক ক্রমে থাকবে।

\item প্রতিটি কাজের জন্য সঠিক Symbol ব্যবহার করবে।

\item Flow-এর দিক স্পষ্ট থাকবে।

\item Decision-এর Branch পরিষ্কার থাকবে।

\item অপ্রয়োজনীয় Line crossing এড়িয়ে চলবে।

\item অপ্রয়োজনীয় Step থাকবে না।

\item Problem-এর সঠিক Solution প্রকাশ করবে।

\end{compacttwocolpoints}

\booksubheading{Flowchart আঁকার সময় সাধারণ ভুল}

\begin{compacttwocolpoints}

\item Start বা End symbol বাদ দেওয়া।

\item Input/Output-এর জন্য Rectangle ব্যবহার করা।

\item Process বা Decision-এর জন্য ভুল Symbol ব্যবহার করা।

\item Decision-এর Yes/No Branch না দেখানো।

\item Arrow-এর Direction না দেওয়া।

\item Flow line অপ্রয়োজনে Cross করা।

\item প্রয়োজন হলেও Connector ব্যবহার না করা।

\item Flowchart অপ্রয়োজনীয়ভাবে জটিল করা।

\end{compacttwocolpoints}

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

\begin{itemize}

\item
\textbf{Flowchart} হলো Problem সমাধানের ধাপগুলোর
\textbf{চিত্রভিত্তিক প্রকাশ}।

\item
\textbf{Oval}
\(\rightarrow\)
Start/End।

\item
\textbf{Parallelogram}
\(\rightarrow\)
Input/Output।

\item
\textbf{Rectangle}
\(\rightarrow\)
Process।

\item
\textbf{Diamond}
\(\rightarrow\)
Decision।

\item
\textbf{Arrow}
\(\rightarrow\)
Flow-এর দিক।

\item
\textbf{Connector}
\(\rightarrow\)
বিচ্ছিন্ন অংশ যুক্ত করে।

\item
Flowchart-এর মৌলিক গঠন—
\textbf{Sequence, Selection, Repetition/Loop ও Jump}।

\item
Decision থেকে সাধারণত
\textbf{Yes/No}
বা
\textbf{True/False}
Branch বের হয়।

\item
Flowchart-এর ধাপগুলো
\textbf{পরিষ্কার, সংক্ষিপ্ত ও যৌক্তিক} হওয়া উচিত।

\item
দ্রুত মনে রাখবে—

\begin{center}

\textbf{Problem বুঝি}
\(\longrightarrow\)
\textbf{Algorithm লিখি}
\(\longrightarrow\)
\textbf{Flowchart আঁকি}
\(\longrightarrow\)
\textbf{Code করি}

\end{center}

\end{itemize}

\end{rememberbox}
