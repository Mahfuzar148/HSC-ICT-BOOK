\py{x} ও \py{y} দুটিই String, তাই \py{+} এখানে যোগ না করে String Concatenation করে। ফলে \py{"5" + "2"} থেকে \py{"52"} পাওয়া যায়।

\textbf{Trap:} দেখতে Number হলেও Quote-এর ভিতরে থাকলে তা String।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} \py{int()} দিয়ে Conversion করলে Output কী হবে, একটি String ও একটি Integer সরাসরি \py{+} করলে কী Error হবে—এগুলো থেকেও প্রশ্ন আসতে পারে।
\end{explainbox}

\begin{explainbox}{Topic-wise ২০৮ — উত্তর: ক}
\py{range(5, 0, -2)}-এ Start = 5, Stop = 0 এবং Step = -2। তাই Value হবে \py{5, 3, 1}; Stop Value 0 অন্তর্ভুক্ত হয় না।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} Negative Step-এ Loop count, শেষ Value, Stop পরিবর্তন করলে Output—এই angle-গুলো গুরুত্বপূর্ণ।
\end{explainbox}

\begin{explainbox}{Topic-wise ২১২ — উত্তর: ঘ}
Outer Loop 2 বার এবং Inner Loop প্রতি Outer Iteration-এ 3 বার চলে। তাই \py{print("*")} মোট \(2 \times 3 = 6\) বার Execute হয়।

\textbf{Trap:} Nested Loop-এ Iteration count সাধারণত গুণ করতে হয়।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} Row–Column Pattern, মোট Output count, Inner range পরিবর্তন করলে মোট Iteration—এসব আসতে পারে।
\end{explainbox}

\begin{explainbox}{Topic-wise ২১৫ — উত্তর: খ}
Set Duplicate Element আলাদা করে রাখে না। তাই \py{\{1,2,2,3\}} কার্যত \py{\{1,2,3\}} হয় এবং Length = 3।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} List থেকে Set বানালে কতটি Unique Value থাকবে, Membership Test, Empty Set-এর Syntax—এসব থেকেও প্রশ্ন হতে পারে।
\end{explainbox}

\begin{explainbox}{Topic-wise ২১৯ — উত্তর: গ}
Function-এর ভিতরের \py{x = 20} একটি Local Variable; বাইরে থাকা \py{x = 10} Global Variable। Local Assignment বাইরের Global \py{x} পরিবর্তন করে না। তাই Output হবে 20, তারপর 10।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} \py{global x} ব্যবহার করলে Output কী হবে, Function-এর ভিতরে শুধু Global Variable Read করলে \py{global} দরকার কি না—এসব গুরুত্বপূর্ণ।
\end{explainbox}

\begin{explainbox}{Board-style ৬১ — উত্তর: গ}
\py{x} হলো String এবং \py{y} হলো Integer। Python-এ String ও Integer-কে সরাসরি \py{+} করা যায় না, তাই TypeError হবে।

\textbf{Trap:} \py{"10"} এবং \py{10} এক Data Type নয়।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} \py{int(x) + y}, \py{x + str(y)}, অথবা \py{input()}-এর Result নিয়ে একই ধরনের Output/Error প্রশ্ন আসতে পারে।
\end{explainbox}

\begin{explainbox}{Board-style ৬৪ — উত্তর: গ}
\py{i} শুরুতে 1 এবং Loop-এর ভিতরে \py{i}-এর Value পরিবর্তন করা হয়নি। তাই \py{i <= 5} সবসময় True থেকে যেতে পারে এবং Infinite Loop হতে পারে।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} সঠিক Update কোথায় বসবে, \py{i += 1} যোগ করলে কয়বার Loop চলবে, Condition পরিবর্তন করলে কী হবে—এসব angle থেকে প্রশ্ন আসতে পারে।
\end{explainbox}

\begin{explainbox}{Board-style ৬৫ — উত্তর: গ}
Outer Loop 3 বার এবং Inner Loop 2 বার চলে। তাই \py{count += 1} মোট \(3 \times 2 = 6\) বার Execute হয়।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} Nested Loop-এর Final count, Pattern-এর Row/Column, একটি Loop-এর range পরিবর্তন করলে Total Iteration—এসব আসতে পারে।
\end{explainbox}

\begin{explainbox}{Board-style ৬৮ — উত্তর: ক}
Dictionary-তে \py{in} Operator সাধারণত Key-এর Membership পরীক্ষা করে। এখানে \py{"a"} একটি Key, তাই Result \py{True}।

\textbf{Trap:} \py{10 in d} লিখলে Value দেখে True হবে—এমন ধরে নেওয়া ঠিক নয়।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} Key access, \py{keys()}, \py{values()}, Dictionary update বা Membership নিয়ে প্রশ্ন আসতে পারে।
\end{explainbox}

\begin{explainbox}{Board-style ৭২ — উত্তর: খ}
\py{show()} Function প্রথমে \py{Hi} Print করে। কিন্তু Function-এ কোনো \py{return} নেই, তাই এটি স্বয়ংক্রিয়ভাবে \py{None} Return করে। ফলে পরে \py{print(x)} থেকে \py{None} দেখা যায়।

\textbf{Trap:} \py{print()} এবং \py{return} একই কাজ করে না।

\textbf{এ Concept থেকে আর কীভাবে প্রশ্ন আসতে পারে?} Function-এ \py{return "Hi"} দিলে কী হবে, \py{print()} বাদ দিলে Result কী হবে, Return Value Variable-এ রাখলে কী পাওয়া যাবে—এসব থেকেও প্রশ্ন হতে পারে।
\end{explainbox}
