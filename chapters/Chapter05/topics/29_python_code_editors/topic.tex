\sectionheading{5.29 Python-এ Code লেখার মাধ্যম}

Python Program বিভিন্ন ধরনের Environment বা Tool ব্যবহার করে

কাজের ধরন অনুযায়ী কখনো সরাসরি Instruction লিখে সঙ্গে সঙ্গে
Result দেখা যায়, আবার কখনো Program File তৈরি করে Code
Save ও Run করা হয়।

\booksubheading{১. Interactive Mode / Python Shell}

Interactive Mode-এ Python Shell-এর Prompt-এ সরাসরি
Instruction লিখে Enter চাপলে সাধারণত সঙ্গে সঙ্গে Result দেখা যায়।

Python Shell-এর Prompt হলো—

\begin{codebox}

\begin{english}
\ttfamily
>>>
\end{english}

\end{codebox}

\begin{examplebox}{উদাহরণ}

\begin{codebox}

\begin{english}
\ttfamily
>>> 10 + 5\\
15
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily 10 + 5}
লিখে Enter চাপার সঙ্গে সঙ্গে
\textenglish{\ttfamily 15}
Result পাওয়া গেছে।

\end{examplebox}

\textbf{Interactive Mode-এর বৈশিষ্ট্য—}

\begin{itemize}

\item একবারে ছোট Instruction পরীক্ষা করা যায়।

\item Result সঙ্গে সঙ্গে দেখা যায়।

\item ছোট Calculation ও Code Test-এর জন্য সুবিধাজনক।

\item প্রতিবার Program File তৈরি করা প্রয়োজন হয় না।

\item বড় Program লেখার জন্য তুলনামূলক কম সুবিধাজনক।

\end{itemize}

\begin{rememberbox}

\textbf{\color{deepOrange}সহজভাবে মনে রাখবে}

\begin{center}

\textbf{Command লিখি}
\(\longrightarrow\)
\textbf{Enter চাপি}
\(\longrightarrow\)
\textbf{সঙ্গে সঙ্গে Result}

\end{center}

\end{rememberbox}

\booksubheading{২. Script Mode / Editor}

Script Mode-এ একাধিক Python Statement একটি Program File-এ
লেখা হয়।

File-টি
\textbf{\textenglish{\ttfamily .py}}
Extension-এ Save করে পরে পুরো Program একসঙ্গে Execute করা যায়।

\begin{examplebox}{উদাহরণ}

\begin{codebox}

\begin{english}
\ttfamily
a = 10\\
b = 20\\
sum = a + b\\
print(sum)
\end{english}

\end{codebox}

Program File-এর নাম হতে পারে—

\begin{codebox}

\begin{english}
\ttfamily
sum.py
\end{english}

\end{codebox}

\end{examplebox}

\textbf{Script Mode-এর বৈশিষ্ট্য—}

\begin{itemize}

\item একাধিক Statement নিয়ে Program লেখা যায়।

\item Code Program File হিসেবে Save করা যায়।

\item প্রয়োজন হলে পরে Code Edit করা যায়।

\item একই Program বারবার Run করা যায়।

\item বড় ও সংরক্ষণযোগ্য Program তৈরির জন্য উপযোগী।

\end{itemize}

\begin{rememberbox}

\textbf{\color{deepOrange}সহজভাবে মনে রাখবে}

\begin{center}

\textbf{Code লিখি}
\(\longrightarrow\)
\textbf{\textenglish{\ttfamily .py} File Save করি}
\(\longrightarrow\)
\textbf{Run করি}
\(\longrightarrow\)
\textbf{Output পাই}

\end{center}

\end{rememberbox}
