\sectionheading{5.36 Python Operator}

Program-এ Data বা Value-এর উপর Calculation, Comparison,
Logical Test ইত্যাদি কাজ সম্পন্ন করার জন্য
\textbf{Operator} ব্যবহৃত হয়।

%================================================
% Definition
%================================================

\booksubheading{Operator কী?}

\begin{definitionbox}

এক বা একাধিক Value বা Variable-এর উপর নির্দিষ্ট Operation
সম্পন্ন করতে ব্যবহৃত Symbol বা Keyword-কে
\textbf{Operator} বলে।

\end{definitionbox}

উদাহরণ—

\begin{codebox}
\begin{english}
\ttfamily
a = 10\\
b = 5\\
c = a + b
\end{english}
\end{codebox}

\begin{center}

\textenglish{\ttfamily a, b}
\(\longrightarrow\)
\textbf{Operand}
\qquad
\textenglish{\ttfamily +}
\(\longrightarrow\)
\textbf{Operator}
\qquad
\textenglish{\ttfamily a + b}
\(\longrightarrow\)
\textbf{Expression}

\end{center}

\begin{rememberbox}
\begin{center}
\textbf{Operand}
\(\longrightarrow\)
\textbf{Operator দ্বারা Operation}
\(\longrightarrow\)
\textbf{Result}
\end{center}
\end{rememberbox}

\booksubheading{Associativity}

একই Precedence-এর একাধিক Operator থাকলে কোন দিক থেকে
Operation সম্পন্ন হবে তা \textbf{Associativity} দ্বারা বোঝানো হয়।

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{সাধারণত Left to Right}

\begin{sidecodebox}
\begin{english}
\ttfamily
20 - 5 - 3
\end{english}
\end{sidecodebox}

অর্থাৎ—

\begin{center}
\textenglish{\ttfamily (20 - 5) - 3 = 12}
\end{center}

\end{sideexamplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{\textenglish{\ttfamily **} Right to Left}

\begin{sidecodebox}
\begin{english}
\ttfamily
2 ** 3 ** 2
\end{english}
\end{sidecodebox}

অর্থাৎ—

\begin{center}

\textenglish{\ttfamily 2 ** (3 ** 2)}
\(\longrightarrow\)
\textenglish{\ttfamily 2 ** 9}
\(\longrightarrow\)
\textenglish{\ttfamily 512}

\end{center}

\end{sideexamplebox}

\end{minipage}

\begin{rememberbox}

\textbf{\color{deepOrange}MCQ Trap:}
Exponentiation
\textenglish{\ttfamily **}
হলো \textbf{Right Associative}।

\end{rememberbox}
