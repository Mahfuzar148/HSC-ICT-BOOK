\sectionheading{5.43 Data Structure — তথ্যের সুশৃঙ্খল বিন্যাস}

একটি Program-এ অনেকগুলো সম্পর্কিত Data আলাদা আলাদা Variable-এ রাখলে
সেগুলো পরিচালনা করা কঠিন হয়। একাধিক Data-কে নির্দিষ্ট নিয়মে
সুশৃঙ্খলভাবে সংরক্ষণ ও ব্যবহার করতে \textbf{Data Structure} ব্যবহৃত হয়।

%================================================
% Definition
%================================================

\booksubheading{Data Structure কী?}

\begin{definitionbox}

Data-কে এমনভাবে সংগঠিত ও সংরক্ষণ করার পদ্ধতি, যাতে প্রয়োজন অনুযায়ী
সহজে Access, Update ও Process করা যায়, তাকে
\textbf{Data Structure} বলে।

\end{definitionbox}

\begin{center}

\textbf{Data}
\(\longrightarrow\)
\textbf{সুশৃঙ্খলভাবে সংরক্ষণ}
\(\longrightarrow\)
\textbf{সহজে Access ও Process}

\end{center}

\booksubheading{১. List}

একাধিক Item একটি Variable-এর মধ্যে ধারাবাহিকভাবে সংরক্ষণ করতে
\textbf{List} ব্যবহার করা হয়।

\begin{codeoutputbox}{List তৈরি}

\noindent
\begin{minipage}[t]{0.53\linewidth}
\codeheading

\begin{english}
\ttfamily
numbers = [10, 20, 30, 40]\\
print(numbers)
\end{english}

\end{minipage}
\hfill
\begin{minipage}[t]{0.43\linewidth}
\outputheading

\textbf{Output:}

\begin{center}
\textenglish{\ttfamily [10, 20, 30, 40]}
\end{center}

একটি List-এর মধ্যে একাধিক Item রাখা হয়েছে।

\end{minipage}

\end{codeoutputbox}

List-এর গুরুত্বপূর্ণ বৈশিষ্ট্য—

\begin{itemize}

\item Ordered।

\item Mutable বা পরিবর্তনযোগ্য।

\item Duplicate Item থাকতে পারে।

\item Index ব্যবহার করে Item Access করা যায়।

\item বিভিন্ন Data Type-এর Item রাখা যায়।

\end{itemize}

\booksubheading{২. Tuple}

List-এর মতো Tuple-এও একাধিক Item রাখা যায়। তবে Tuple-এর Item
তৈরির পরে সাধারণভাবে পরিবর্তন করা যায় না।

\begin{codeoutputbox}{Tuple তৈরি ও Access}

\noindent
\begin{minipage}[t]{0.53\linewidth}
\codeheading

\begin{english}
\ttfamily

\end{english}

\end{minipage}
\hfill
\begin{minipage}[t]{0.43\linewidth}
\outputheading

\begin{center}
\textenglish{\ttfamily 20}
\end{center}

Tuple Ordered এবং Index ব্যবহার করে Item Access করা যায়।

কিন্তু এটি \textbf{Immutable}।

\end{minipage}

\end{codeoutputbox}

Tuple-এর গুরুত্বপূর্ণ বৈশিষ্ট্য—

\begin{itemize}

\item Ordered।

\item Immutable বা অপরিবর্তনযোগ্য।

\item Duplicate Item থাকতে পারে।

\item Index ব্যবহার করা যায়।

\end{itemize}

\begin{rememberbox}

\begin{center}

\textbf{List = Mutable}
\qquad
\textbf{Tuple = Immutable}

\end{center}

\end{rememberbox}

\booksubheading{৩. Set}

Unique Item-এর Collection সংরক্ষণ করতে \textbf{Set} ব্যবহার করা হয়।

Set-এর গুরুত্বপূর্ণ বৈশিষ্ট্য—

\begin{compacttwocolpoints}

\item Duplicate Item রাখে না।

\item Indexing সমর্থন করে না।

\item Item-এর নির্দিষ্ট Positional Order-এর উপর নির্ভর করা উচিত নয়।

\item Mutable।

\item Membership Testing-এ উপযোগী।

\end{compacttwocolpoints}

\booksubheading{সাধারণ ভুল}

\begin{rememberbox}

\begin{itemize}

\item
\textenglish{\ttfamily \{\}}
-কে Empty Set মনে করা।

\item Set-এ Index ব্যবহার করার চেষ্টা করা।

\item Tuple-এর Item পরিবর্তনের চেষ্টা করা।

\item List ও Tuple-এর Mutable/Immutable বৈশিষ্ট্য গুলিয়ে ফেলা।

\item Dictionary-তে Index দিয়ে Value Access করার চেষ্টা করা।

\item Dictionary-এর উপর সরাসরি Loop চালালে Value পাওয়া যাবে মনে করা।

\item Single Item Tuple-এ Comma না দেওয়া।

\item List Slicing-এ Stop Index Included মনে করা।

\item Set-এর Item সবসময় একই Position/Order-এ থাকবে ধরে নেওয়া।

\end{itemize}
