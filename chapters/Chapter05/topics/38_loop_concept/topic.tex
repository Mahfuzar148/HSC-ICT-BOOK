\sectionheading{5.38 Loop — ধারণা ও প্রয়োজনীয়তা}

Program-এ অনেক সময় একই কাজ বারবার করতে হয়।
একই Statement বারবার আলাদাভাবে না লিখে নির্দিষ্ট নিয়মে
পুনরাবৃত্তি করার জন্য \textbf{Loop} ব্যবহার করা হয়।

%================================================
% Definition
%================================================

\booksubheading{Loop কী?}

\begin{definitionbox}

কোনো নির্দিষ্ট Condition বা Sequence-এর ভিত্তিতে একই Statement
বা Code Block বারবার Execute করার প্রক্রিয়াকে
\textbf{Loop} বা \textbf{Iteration} বলে।

\end{definitionbox}

\begin{center}

\textbf{একই কাজ}
\(\longrightarrow\)
\textbf{বারবার}
\(\longrightarrow\)
\textbf{Loop}

\end{center}

% Without loop vs loop
%================================================

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{Loop ছাড়া}

১ থেকে ৫ পর্যন্ত সংখ্যা Print করতে—

\ttfamily
print(1)\\
print(2)\\
print(3)\\
print(4)\\

\end{sideexamplebox}

\begin{center}
\textenglish{\ttfamily 1 \quad 2 \quad 3 \quad 4 \quad 5}
\end{center}

কম Code-এ একই কাজ করা যায়।

\end{sideexamplebox}

\end{minipage}

\booksubheading{Loop কেন প্রয়োজন?}

Loop ব্যবহারের প্রধান প্রয়োজন—

\begin{compacttwocolpoints}

\item একই কাজ বারবার করার জন্য।

\item একই Code বহুবার লেখা এড়াতে।

\item Program ছোট, পরিষ্কার ও সহজ রাখতে।

\item Code-এর Repetition কমাতে।

\item List, String বা অন্যান্য Collection-এর Item Process করতে।

\item Counting, Summation, Searching ইত্যাদি কাজে।

\item নির্দিষ্ট Condition পূরণ হওয়া পর্যন্ত কাজ চালিয়ে যেতে।

\end{compacttwocolpoints}

\begin{rememberbox}

\begin{center}

\textbf{Loop}
\(\longrightarrow\)
\textbf{Repetition কমায়}
\(\longrightarrow\)
\textbf{Code ছোট ও সহজ হয়}

\end{center}

\end{rememberbox}

\booksubheading{Iteration ও Loop Body}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{Iteration}

Loop-এর প্রতিবার Code Block Execute হওয়াকে
\textbf{Iteration} বলে।

যদি কোনো Loop ৫ বার Execute হয়, তাহলে সেখানে
\textbf{৫টি Iteration} হয়েছে।

\medskip

\textbf{MCQ তথ্য:}

\begin{center}
\textbf{Loop Body-এর একবার Execution}
\(\longrightarrow\)
\textbf{এক Iteration}
\end{center}

\end{sideexamplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{sideexamplebox}{Loop Body}

Loop-এর যে Statement বা Code Block বারবার Execute হয় তাকে
\textbf{Loop Body} বলে।

\begin{sidecodebox}
\begin{english}
\ttfamily
for i in range(3):\\
\hspace*{4mm}print("ICT")
\end{english}
\end{sidecodebox}

এখানে
\textenglish{\ttfamily print("ICT")}
হলো Loop Body এবং এটি ৩ বার Execute হবে।

\end{sideexamplebox}

\end{minipage}

\booksubheading{Loop-এর সাধারণ কার্যধারা}

সাধারণভাবে Loop-এর Logic—

\begin{center}

\textbf{Start}
\(\longrightarrow\)
\textbf{Condition / Next Item}
\(\longrightarrow\)
\textbf{Loop Body}

\medskip

\textbf{Loop Body}
\(\longrightarrow\)
\textbf{Update / Next Item}
\(\longrightarrow\)
\textbf{আবার পরীক্ষা}
\(\longrightarrow\)
\textbf{Stop}

\end{center}

Loop-এর ধরন অনুযায়ী বাস্তব গঠন কিছুটা ভিন্ন হতে পারে।

\end{center}

\booksubheading{Loop Condition}

Loop কখন চলবে এবং কখন শেষ হবে তা নির্ধারণে Condition গুরুত্বপূর্ণ।

\begin{codebox}
\begin{english}
\ttfamily
while i <= 5:
\end{english}
\end{codebox}

\begin{center}

\textbf{Condition True}
\(\longrightarrow\)
\textbf{Loop Body Execute}

\qquad

\textbf{Condition False}
\(\longrightarrow\)
\textbf{Loop শেষ}

\end{center}

\begin{rememberbox}

\begin{center}

\textenglish{\ttfamily True}
\(\longrightarrow\)
\textbf{আবার Loop}

\qquad

\textenglish{\ttfamily False}
\(\longrightarrow\)
\textbf{Loop থেকে বের হও}

\end{center}

\end{rememberbox}

\end{examplebox}

অংশে বিশেষভাবে কাজে লাগবে।
