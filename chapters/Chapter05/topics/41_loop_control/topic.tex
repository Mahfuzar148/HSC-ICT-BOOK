\sectionheading{5.41 Loop Control Statement}

Loop সাধারণত নির্ধারিত নিয়মে এক Iteration থেকে পরবর্তী Iteration-এ যায়।
কিন্তু প্রয়োজন অনুযায়ী Loop মাঝপথে বন্ধ করা, বর্তমান Iteration বাদ দেওয়া
বা কোনো কাজ না করে Placeholder রাখার জন্য
\textbf{Loop Control Statement} ব্যবহার করা হয়।

%================================================
% Definition
%================================================

\booksubheading{Loop Control Statement কী?}

\begin{definitionbox}

Loop-এর স্বাভাবিক Execution Flow নিয়ন্ত্রণ বা পরিবর্তনের জন্য
ব্যবহৃত Statement-কে \textbf{Loop Control Statement} বলে।

\end{definitionbox}

Python-এ গুরুত্বপূর্ণ Loop Control Statement—

\begin{tabularx}
{\linewidth}
{
|>{\bfseries\centering\arraybackslash}p{0.24\linewidth}
|Y|
}

\hline
\rowcolor{softBlue}

\textbf{Statement}
&
\textbf{প্রধান কাজ}
\\
\hline

\textenglish{\ttfamily break}
&
Loop সম্পূর্ণ বন্ধ করে।
\\
\hline

\textenglish{\ttfamily continue}
&
বর্তমান Iteration-এর বাকি অংশ Skip করে পরবর্তী Iteration-এ যায়।
\\
\hline

\textenglish{\ttfamily pass}
&
কোনো কাজ না করে Normal Execution চালিয়ে যেতে দেয়।
\\
\hline

\end{tabularx}

\booksubheading{১. \textenglish{\ttfamily break} Statement}

Loop চলাকালে নির্দিষ্ট Condition পূরণ হলে Loop-কে
\textbf{সঙ্গে সঙ্গে বন্ধ} করার জন্য
\textenglish{\ttfamily break}
ব্যবহার করা হয়।

\begin{center}

\textbf{Condition পূরণ}
\(\longrightarrow\)
\textenglish{\ttfamily break}
\(\longrightarrow\)
\textbf{Loop থেকে বের হও}

\end{center}

\booksubheading{২. \textenglish{\ttfamily continue} Statement}

বর্তমান Iteration-এর বাকি Statementগুলো Skip করে সরাসরি

\textenglish{\ttfamily continue}
ব্যবহার করা হয়।

\begin{center}

\textbf{Condition পূরণ}
\(\longrightarrow\)
\textenglish{\ttfamily continue}
\(\longrightarrow\)
\textbf{Current Iteration Skip}
\(\longrightarrow\)
\textbf{Next Iteration}

\end{center}

\booksubheading{৩. \textenglish{\ttfamily pass} Statement}

Syntax অনুযায়ী Statement প্রয়োজন, কিন্তু বর্তমানে কোনো কাজ করতে না চাইলে
\textenglish{\ttfamily pass}

\textenglish{\ttfamily pass}
কোনো Operation সম্পন্ন করে না।

\begin{codeoutputbox}{\textenglish{\ttfamily pass} Example}

\noindent
\begin{minipage}[t]{0.53\linewidth}
\codeheading

\begin{english}
\ttfamily

\hspace*{4mm}if i == 2:\\
\hspace*{8mm}pass\\
\hspace*{4mm}print(i)
\end{english}

\end{minipage}

\textenglish{\ttfamily i == 2}
হলেও
\textenglish{\ttfamily print(i)}
স্বাভাবিকভাবে Execute হয়েছে।

\end{minipage}

\booksubheading{\textenglish{\ttfamily pass} কেন ব্যবহার করা হয়?}

Python-এ Empty Code Block রাখা যায় না। কোনো Block-এর Code পরে লেখা হবে
এমন অবস্থায় Temporary Placeholder হিসেবে
\textenglish{\ttfamily pass}
ব্যবহার করা যায়।

\begin{minipage}[t]{0.46\linewidth}
\outputheading

\begin{center}

\textbf{Do Nothing Statement}
\end{center}

এটি Loop বন্ধ করে না এবং Current Iteration-ও Skip করে না।

\end{minipage}

\end{codeoutputbox}

\booksubheading{Loop Control-এর সহজ Flow}

\begin{rememberbox}

\begin{center}

\textbf{\textenglish{\ttfamily break}:}
Loop
\(\longrightarrow\)
Condition
\(\longrightarrow\)
\textenglish{\ttfamily break}
\(\longrightarrow\)
\textbf{Loop-এর বাইরে}

\medskip

\textbf{\textenglish{\ttfamily continue}:}
Loop
\(\longrightarrow\)
Condition
\(\longrightarrow\)
\textenglish{\ttfamily continue}
\(\longrightarrow\)
\textbf{Next Iteration}

\medskip

\textbf{\textenglish{\ttfamily pass}:}
Loop
\(\longrightarrow\)
\textenglish{\ttfamily pass}
\(\longrightarrow\)
\textbf{কোনো কাজ নয়}
\(\longrightarrow\)
\textbf{Normal Execution}

\end{center}

\end{rememberbox}

\booksubheading{সাধারণ ভুল}

\begin{rememberbox}

\begin{itemize}

\item
\textenglish{\ttfamily break}
ও
\textenglish{\ttfamily continue}
-কে একই মনে করা।

\item
\textenglish{\ttfamily continue}
Loop সম্পূর্ণ বন্ধ করে—এমন ধারণা করা।

\item
\textenglish{\ttfamily pass}
কে
\textenglish{\ttfamily continue}
মনে করা।

\item
\textenglish{\ttfamily while}
Loop-এ
\textenglish{\ttfamily continue}
-এর কারণে Counter Update Skip করা।

\item Nested Loop-এর Inner
\textenglish{\ttfamily break}
দিয়ে সব Loop বন্ধ হবে মনে করা।

\item
\textenglish{\ttfamily break}
হওয়ার পরও Loop-এর
\textenglish{\ttfamily else}
Execute হবে মনে করা।

\item
\textenglish{\ttfamily pass}
ব্যবহার করলে Current Iteration Skip হবে মনে করা।

\item
\textenglish{\ttfamily break},
\textenglish{\ttfamily continue}
বা
\textenglish{\ttfamily pass}
-এর Indentation ভুল করা।

\end{itemize}

\end{rememberbox}
