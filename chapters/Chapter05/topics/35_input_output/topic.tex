\sectionheading{5.35 Input ও Output}

Program-এর কাজ সম্পন্ন করতে অনেক সময় ব্যবহারকারীর কাছ থেকে
Data গ্রহণ করতে হয় এবং Process শেষে Result প্রদর্শন করতে হয়।

\begin{center}
\textbf{Input}
\(\longrightarrow\)
\textbf{Processing}
\(\longrightarrow\)
\textbf{Output}
\end{center}

%================================================
% Input
%================================================

\booksubheading{Input কী?}

\begin{definitionbox}
Program-এ বাইরে থেকে প্রয়োজনীয় Data গ্রহণ করার প্রক্রিয়াকে
\textbf{Input} বলে।
\end{definitionbox}

Python-এ Keyboard থেকে Input নেওয়ার জন্য সাধারণত
\textenglish{\ttfamily input()}
Function ব্যবহার করা হয়।

\textbf{সাধারণ Syntax—}

\begin{codebox}
\begin{english}
\ttfamily
variable = input("Message")
\end{english}
\end{codebox}

% Input example + behavior side-by-side
%================================================

\noindent
\begin{minipage}[t]{0.49\linewidth}
\begin{examplebox}{\textenglish{\ttfamily input()}-এর উদাহরণ}

\begin{codebox}
\begin{english}
\ttfamily
name = input("Enter your name: ")\\
print(name)
\end{english}
\end{codebox}

Input:
\begin{codebox}
\begin{english}

Mina

\end{examplebox}

\begin{minipage}[t]{0.49\linewidth}

Parentheses-এর ভিতরের Message Screen-এ দেখায় এবং Program
User-এর Input-এর জন্য অপেক্ষা করে।

\medskip

\begin{center}
\textenglish{\ttfamily input()}
\(\longrightarrow\)
\textbf{Data গ্রহণ}
\end{center}

Input করা Value Variable-এ সংরক্ষণ করা যায়।

\end{examplebox}
\end{minipage}

\booksubheading{\textenglish{\ttfamily input()}-এর Return Type}

Python-এর একটি গুরুত্বপূর্ণ নিয়ম হলো—
\textenglish{\ttfamily input()}
দিয়ে গ্রহণ করা Data সাধারণত
\textenglish{\ttfamily str}
Type হিসেবে পাওয়া যায়।

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{codebox}
\begin{english}
\ttfamily
age = input("Enter age: ")\\
print(type(age))
\end{english}
\end{codebox}

User Input:

\begin{codebox}
\begin{english}
\ttfamily
18
\end{english}
\end{codebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

Output:

\begin{codebox}
\begin{english}
\ttfamily
<class 'str'>
\end{english}
\end{codebox}

অর্থাৎ—

\begin{center}
\textenglish{\ttfamily 18}
\(\longrightarrow\)
\textenglish{\ttfamily input()}
\(\longrightarrow\)
\textenglish{\ttfamily "18"}
\end{center}

\end{minipage}

\begin{rememberbox}
\textbf{\color{deepOrange}MCQ Trap:}
User
\textenglish{\ttfamily 18}
লিখলেও
\textenglish{\ttfamily input()}
সাধারণত সেটিকে
\textenglish{\ttfamily "18"}
অর্থাৎ String হিসেবে দেয়।
\end{rememberbox}

\booksubheading{Numeric Input নেওয়া}

Number নিয়ে Calculation করতে হলে
\textenglish{\ttfamily input()}
থেকে পাওয়া String-কে প্রয়োজনীয় Numeric Type-এ Convert করতে হয়।

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{Integer Input}

\begin{codebox}
\begin{english}
\ttfamily
age = int(input("Enter age: "))
\end{english}
\end{codebox}

কার্যধারা—

\begin{center}
\textenglish{\ttfamily input()}
\(\longrightarrow\)
String
\(\longrightarrow\)
\textenglish{\ttfamily int()}
\(\longrightarrow\)
Integer
\end{center}

উদাহরণ—

\begin{codebox}
\begin{english}
\ttfamily
a = int(input("Enter number: "))\\
print(a + 5)
\end{english}
\end{codebox}

Input: \textenglish{\ttfamily 10}

Output: \textenglish{\ttfamily 15}

\end{examplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{Floating-point Input}

\begin{codebox}
\begin{english}
\ttfamily
price = float(input("Enter price: "))
\end{english}
\end{codebox}

কার্যধারা—

\begin{center}
\textenglish{\ttfamily input()}
\(\longrightarrow\)
String
\(\longrightarrow\)
\textenglish{\ttfamily float()}
\(\longrightarrow\)
Float
\end{center}

উদাহরণ—

\begin{codebox}
\begin{english}
\ttfamily
x = float(input("Enter number: "))\\
print(x)
\end{english}
\end{codebox}

Input: \textenglish{\ttfamily 12.5}

Output: \textenglish{\ttfamily 12.5}

\end{examplebox}

\end{minipage}

\begin{rememberbox}

\textbf{\color{deepOrange}দ্রুত মনে রাখবে}

\begin{center}

\textbf{Text Input}
\(\longrightarrow\)
\textenglish{\ttfamily input()}
\qquad
\textbf{Integer}
\(\longrightarrow\)
\textenglish{\ttfamily int(input())}
\qquad
\textbf{Float}
\(\longrightarrow\)
\textenglish{\ttfamily float(input())}

\end{center}

\end{rememberbox}

\booksubheading{Output কী?}

\begin{definitionbox}
Program-এর Process করা Data, Message বা Result ব্যবহারকারীর
সামনে প্রদর্শনের প্রক্রিয়াকে \textbf{Output} বলে।
\end{definitionbox}

Python-এ Output প্রদর্শনের জন্য সাধারণত
\textenglish{\ttfamily print()}
Function ব্যবহার করা হয়।

\textbf{সাধারণ Syntax—}

\begin{codebox}
\begin{english}
\ttfamily
print(value)
\end{english}
\end{codebox}

\booksubheading{সাধারণ ভুল}

\begin{compacttwocolpoints}

\item
\textenglish{\ttfamily input()}
থেকে পাওয়া Numeric-looking Value-কে সরাসরি Number মনে করা।

\item Calculation-এর আগে প্রয়োজনীয়
\textenglish{\ttfamily int()}
বা
\textenglish{\ttfamily float()}
Conversion না করা।

\item
\textenglish{\ttfamily print("a")}
ও
\textenglish{\ttfamily print(a)}
-কে একই মনে করা।

\item
\textenglish{\ttfamily sep}
ও
\textenglish{\ttfamily end}
-এর কাজ গুলিয়ে ফেলা।

\item
\textenglish{\ttfamily \textbackslash n}
ও
\textenglish{\ttfamily \textbackslash t}
-এর কাজ গুলিয়ে ফেলা।

\item Input Prompt-এর Message-কে User-এর Input Value-এর অংশ মনে করা।

\item Text লেখার Quotation Mark ভুলে যাওয়া।

\end{compacttwocolpoints}
