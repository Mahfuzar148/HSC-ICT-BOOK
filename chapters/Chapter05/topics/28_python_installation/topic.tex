\sectionheading{5.28 Python Installation ও Setup}

Python-এ Program লেখা ও Execute করার আগে Computer-এ
\textbf{Python Interpreter} Install করতে হয়।

Installation সম্পন্ন হওয়ার পর Python Shell, IDLE অথবা
প্রয়োজনীয় Code Editor/IDE ব্যবহার করে Python Program
লেখা ও চালানো যায়।

%================================================
% Definition
%================================================

\booksubheading{Python Installation কী?}

\begin{definitionbox}

\textbf{\color{darkTeal}সংজ্ঞা}

Computer-এ Python Interpreter এবং প্রয়োজনীয় Supporting Tool
স্থাপন করে Python Program লেখা ও চালানোর উপযোগী পরিবেশ
তৈরি করার প্রক্রিয়াকে \textbf{Python Installation ও Setup} বলা হয়।

\end{definitionbox}

\textbf{সহজভাবে মনে রাখবে—}

\begin{center}

\textbf{Download}
\(\longrightarrow\)
\textbf{Install}
\(\longrightarrow\)
\textbf{PATH Setup}
\(\longrightarrow\)
\textbf{Verify}
\(\longrightarrow\)
\textbf{Run}

\end{center}

% Installation Steps
%================================================

\booksubheading{Python Install করার সাধারণ ধাপ}

Windows Computer-এ Python Install করার সাধারণ প্রক্রিয়া—

\begin{enumerate}

\item
Python-এর Official Website থেকে Python 3-এর Installer
Download করতে হবে।

\item
Download করা Installer চালু করতে হবে।

\item
Installation-এর শুরুতে
\textbf{Add python.exe to PATH}
Option থাকলে সেটি নির্বাচন করতে হবে।

\item
এরপর \textbf{Install Now} নির্বাচন করে Installation শুরু করতে হবে।

\item
Installation সম্পন্ন হওয়ার পর Command Prompt বা Terminal
চালু করতে হবে।

\item
Python সঠিকভাবে Install হয়েছে কি না Version দেখে যাচাই করতে হবে।

\item
এরপর IDLE, Python Shell অথবা প্রয়োজনীয় Editor ব্যবহার করে
Program লেখা শুরু করা যাবে।

\end{enumerate}

\booksubheading{Add python.exe to PATH কেন গুরুত্বপূর্ণ?}

Installation-এর সময় গুরুত্বপূর্ণ একটি Option হলো—

\begin{center}

\textbf{Add python.exe to PATH}

\end{center}

এটি নির্বাচন করলে Operating System Command Prompt বা Terminal
থেকে Python Program চালানোর জন্য Python Interpreter-এর
Location সহজে খুঁজে পায়।

\begin{center}

\textbf{Python PATH-এ যুক্ত}
\(\longrightarrow\)
\textbf{Terminal থেকে Python চালানো সহজ}

\end{center}

\begin{rememberbox}

\textbf{\color{deepOrange}সতর্কতা}

PATH সঠিকভাবে Set না থাকলে Command Prompt-এ
Python Command ব্যবহার করার সময় Error দেখা দিতে পারে।

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
python is not recognized ...
\end{english}

\end{codebox}

প্রয়োজনে পরে Environment Variable-এর PATH-এ Python-এর
Location যোগ করেও এটি ঠিক করা যায়।

\end{rememberbox}

% Verify Installation

\booksubheading{Python Installation যাচাই করা}

Python Install হওয়ার পর Command Prompt বা Terminal খুলে
নিচের Command ব্যবহার করা যায়—

\begin{codebox}

\begin{english}
\ttfamily
python --version
\end{english}

\end{codebox}

Windows-এর অনেক Setup-এ নিচের Command-ও ব্যবহার করা যায়—

\begin{codebox}

\begin{english}
\ttfamily
py --version
\end{english}

\end{codebox}

Python সঠিকভাবে Install থাকলে Installed Version দেখা যাবে।

উদাহরণ—

\begin{codebox}

\begin{english}
\ttfamily
Python 3.x.x
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily 3.x.x}
দ্বারা Python 3-এর Installed Version বোঝানো হয়েছে।

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

Version সঠিকভাবে দেখা যাচ্ছে
\(\longrightarrow\)
Python Installation সফলভাবে হয়েছে।

\end{rememberbox}

\booksubheading{Python Shell চালু করা}

Command Prompt বা Terminal-এ লিখতে পারি—

\begin{codebox}

\begin{english}
\ttfamily
python
\end{english}

\end{codebox}

অথবা উপযুক্ত Windows Setup-এ—

\begin{codebox}

\begin{english}
\ttfamily
py
\end{english}

\end{codebox}

এরপর Python Interactive Shell-এর Prompt দেখা যেতে পারে—

\begin{codebox}

\begin{english}
\ttfamily
>>>
\end{english}

\end{codebox}

এই Prompt-এ সরাসরি Python Instruction লেখা যায়।

\begin{examplebox}{উদাহরণ}

\begin{codebox}

\begin{english}
\ttfamily
>>> 5 + 3\\
8
\end{english}

\end{codebox}

এখানে
\textenglish{\ttfamily 5 + 3}
লেখার পর সঙ্গে সঙ্গে
\textenglish{\ttfamily 8}
Result পাওয়া গেছে।

\end{examplebox}

\begin{rememberbox}

\textbf{\color{deepOrange}MCQ তথ্য}

\textenglish{\ttfamily >>>}
\(\longrightarrow\)
Python Interactive Shell-এর Prompt

\end{rememberbox}

\booksubheading{IDLE চালু করা}

Python-এর Standard Installation-এর সঙ্গে সাধারণত
\textbf{IDLE} ব্যবহার করার সুবিধা পাওয়া যায়।

Windows-এ Start Menu থেকে IDLE খুঁজে চালু করা যায়।

IDLE-এর মাধ্যমে—

\begin{compacttwocolpoints}

\item Python Shell ব্যবহার করা যায়।

\item নতুন Python Program লেখা যায়।

\item Program File Save করা যায়।

\item Program Run করা যায়।

\item Error Message দেখা যায়।

\end{compacttwocolpoints}

\begin{rememberbox}

\textbf{\color{deepOrange}মনে রাখবে}

\textbf{IDLE}
=
Integrated Development and Learning Environment

\end{rememberbox}

\end{examplebox}

\booksubheading{সাধারণ ভুল}

\begin{compacttwocolpoints}

\item Python Install না করেই Local Computer-এ Program
Execute করার চেষ্টা করা।

\item
\textbf{Add python.exe to PATH}
Option উপেক্ষা করা।

\item Python Installation হয়েছে কি না Version Check না করা।

\item Python Source File ভুল Extension-এ Save করা।

\item Python 2 ও Python 3-এর Syntax মিশিয়ে ব্যবহার করা।

\item Python, IDLE এবং Code Editor-কে একই Software মনে করা।

\item
\textenglish{\ttfamily >>>}
-কে Program-এর অংশ মনে করে File-এর মধ্যে লিখে দেওয়া।

\end{compacttwocolpoints}
