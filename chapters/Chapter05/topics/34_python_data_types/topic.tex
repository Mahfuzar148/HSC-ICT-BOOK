\sectionheading{5.34 Python Data Type}

Program-এ ব্যবহৃত কোনো Value কী ধরনের এবং সেই Value-এর
উপর কী ধরনের Operation করা যাবে—তা
\textbf{Data Type} দ্বারা বোঝানো হয়।

\end{english}
\end{codebox}

Output:
\textenglish{\ttfamily \textless class 'str'\textgreater}

\end{examplebox}

\end{minipage}

\booksubheading{Numeric Data Type}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{১. Integer — \textenglish{\ttfamily int}}

পূর্ণসংখ্যার জন্য
\textenglish{\ttfamily int}
ব্যবহৃত হয়।

\begin{codebox}
\begin{english}
\ttfamily
a = 10\\
b = -25\\
c = 0
\end{english}
\end{codebox}

এগুলো সব
\textenglish{\ttfamily int}।

\begin{codebox}
\begin{english}
\ttfamily
print(type(a))
\end{english}
\end{codebox}

Output:
\textenglish{\ttfamily \textless class 'int'\textgreater}

\medskip

\textbf{Size/Range:}

Python
\textenglish{\ttfamily int}
সাধারণ fixed 32-bit Range-এ সীমাবদ্ধ নয়।

\begin{codebox}
\begin{english}
\ttfamily
x = 999999999999999999999999999999
\end{english}
\end{codebox}

এটিও
\textenglish{\ttfamily int}
হতে পারে।

\textbf{ব্যবহারিক সীমা}
\(\longrightarrow\)
Available Memory।

\end{examplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{২. Floating-point — \textenglish{\ttfamily float}}

দশমিক বা Floating-point সংখ্যার জন্য
\textenglish{\ttfamily float}
ব্যবহৃত হয়।

\begin{codebox}
\begin{english}
\ttfamily
x = 10.5\\
y = -3.75\\
z = 2.0
\end{english}
\end{codebox}

এগুলো সব
\textenglish{\ttfamily float}।

\begin{codebox}
\begin{english}
\ttfamily
print(type(x))
\end{english}
\end{codebox}

Output:
\textenglish{\ttfamily \textless class 'float'\textgreater}

\medskip

\textbf{Size/Range:}

সাধারণ CPython-এ
\textenglish{\ttfamily float}
সাধারণত 64-bit double-precision floating-point representation।

প্রায় সর্বোচ্চ magnitude:
\[
\pm 1.8\times10^{308}
\]

খুব ছোট Positive Normal Value:
\[
2.2\times10^{-308}
\]

\end{examplebox}

\end{minipage}

\begin{rememberbox}
\textbf{\color{deepOrange}সতর্কতা:}
Python
\textenglish{\ttfamily int}
-এর fixed 4-byte/32-bit range নেই।
আর
\textenglish{\ttfamily float}
-এর 64-bit বলতে floating-point representation বোঝানো হয়,
পুরো Python Object-এর Memory Size নয়।
\end{rememberbox}

\begin{examplebox}{৩. Complex — \textenglish{\ttfamily complex}}

\medskip

\textbf{MCQ:}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{৪. Boolean — \textenglish{\ttfamily bool}}

\medskip

\textbf{মনে রাখবে—}

\begin{center}

\(\longrightarrow\)
\textenglish{\ttfamily True, False}
\end{center}

\textenglish{\ttfamily True}
ও
\textenglish{\ttfamily False}
-এর প্রথম Letter Capital।

\end{examplebox}

\end{minipage}

\booksubheading{Text ও বিশেষ Data Type}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{৫. String — \textenglish{\ttfamily str}}

Text বা Character-এর ধারাবাহিকতার জন্য
\textenglish{\ttfamily str}
ব্যবহৃত হয়।

\begin{codebox}
\begin{english}
\ttfamily
name = "Rahim"\\

\end{english}
\end{codebox}

String-এ Single Quote বা Double Quote ব্যবহার করা যায়।

\begin{center}
\textenglish{\ttfamily 'Mina'}
\qquad অথবা \qquad
\textenglish{\ttfamily "Mina"}
\end{center}

\textbf{Size:}
Fixed Size নেই; Character-এর সংখ্যা ও Internal Representation
অনুযায়ী Memory Usage পরিবর্তিত হয়।

\end{examplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{১০. NoneType}

কোনো অর্থপূর্ণ Value বর্তমানে নির্ধারিত নেই—এমন বিশেষ অবস্থা
প্রকাশ করতে
\textenglish{\ttfamily None}
ব্যবহৃত হয়।

\begin{codebox}
\begin{english}
\ttfamily
x = None\\
print(type(x))
\end{english}
\end{codebox}

Output:
\textenglish{\ttfamily \textless class 'NoneType'\textgreater}

\medskip

\begin{center}
\textenglish{\ttfamily None}
\(\neq\)
\textenglish{\ttfamily 0}
\qquad
\textenglish{\ttfamily None}
\(\neq\)
\textenglish{\ttfamily False}

\medskip

\textenglish{\ttfamily None}
\(\neq\)
\textenglish{\ttfamily ""}
\end{center}

\textenglish{\ttfamily None}
একটি আলাদা বিশেষ Value।

\end{examplebox}

\end{minipage}

\booksubheading{Sequence Data Type}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{৬. List — \textenglish{\ttfamily list}}

একাধিক Value একটি Collection-এ রাখার জন্য List ব্যবহার করা যায়।

\begin{codebox}
\begin{english}
\ttfamily
numbers = [10, 20, 30]\\
data = [10, "Rahim", 5.5, True]
\end{english}
\end{codebox}

\textbf{বৈশিষ্ট্য—}

\begin{itemize}
\item Ordered
\item Mutable বা পরিবর্তনযোগ্য
\item Duplicate Value থাকতে পারে
\end{itemize}

\begin{codebox}
\begin{english}
\ttfamily
numbers[0] = 100
\end{english}
\end{codebox}

অর্থাৎ List-এর Element পরিবর্তন করা যায়।

\end{examplebox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{৭. Tuple — \textenglish{\ttfamily tuple}}

Tuple-এও একাধিক Value রাখা যায়।

\begin{codebox}
\begin{english}
\ttfamily
numbers = (10, 20, 30)
\end{english}
\end{codebox}

\textbf{বৈশিষ্ট্য—}

\begin{itemize}
\item Ordered
\item Immutable বা অপরিবর্তনযোগ্য
\item Duplicate Value থাকতে পারে
\end{itemize}

\medskip

\begin{center}
\textbf{List}
\(\longrightarrow\)
Mutable
\qquad
\textbf{Tuple}
\(\longrightarrow\)
Immutable
\end{center}

\end{examplebox}

\end{minipage}

\booksubheading{Set ও Mapping Data Type}

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{examplebox}{৮. Set — \textenglish{\ttfamily set}}

একাধিক \textbf{Unique Value}-এর Collection তৈরিতে

ব্যবহৃত হয়।

\begin{center}
\textenglish{\ttfamily \{10, 20, 30\}}

\end{examplebox}

\end{center}

\booksubheading{Mutable ও Immutable Data Type}

Data তৈরি হওয়ার পর তার Content পরিবর্তন করা যায় কি না—
তার ভিত্তিতে Data Type-কে Mutable ও Immutable হিসেবে বোঝা যায়।

\noindent
\begin{minipage}[t]{0.49\linewidth}

\begin{definitionbox}

\textbf{\color{darkTeal}Mutable}

Object তৈরি হওয়ার পর তার Content পরিবর্তন করা যায়।

\begin{center}
\textenglish{\ttfamily list}
\qquad
\textenglish{\ttfamily set}
\qquad
\textenglish{\ttfamily dict}
\end{center}

\end{definitionbox}

\end{minipage}
\hfill
\begin{minipage}[t]{0.49\linewidth}

\begin{definitionbox}

\textbf{\color{darkTeal}Immutable}

Object তৈরি হওয়ার পর তার নিজস্ব Value/Content পরিবর্তন করা যায় না।

\begin{center}
\textenglish{\ttfamily int, float, complex, bool, str, tuple, NoneType}
\end{center}

\end{definitionbox}

\end{minipage}

\begin{rememberbox}
\begin{center}

\textbf{List, Set, Dictionary}
\(\longrightarrow\)
\textbf{Mutable}

\qquad

\textbf{Number, String, Tuple}
\(\longrightarrow\)
\textbf{Immutable}

\end{center}
\end{rememberbox}

\booksubheading{সাধারণ ভুল}

\begin{compacttwocolpoints}

\item
Python
\textenglish{\ttfamily int}
-কে সবসময় 4 Byte মনে করা।

\item
Python
\textenglish{\ttfamily int}
-এর Fixed 32-bit Range আছে মনে করা।

\item
\textenglish{\ttfamily "10"}
ও
\textenglish{\ttfamily 10}
-কে একই Data Type মনে করা।

\item
\textenglish{\ttfamily 3 + 4j}
-এর
\textenglish{\ttfamily j}
-কে সাধারণ Variable মনে করা।

\item
\textenglish{\ttfamily True}
-এর পরিবর্তে
\textenglish{\ttfamily true}
লেখা।

\item List ও Tuple-কে একই ধরনের পরিবর্তনযোগ্য Collection মনে করা।

\item Set-এ Duplicate Element আলাদাভাবে থাকবে মনে করা।

\item Dictionary-কে শুধু Value-এর Collection মনে করা।

\item
\textenglish{\ttfamily None}
-কে
\textenglish{\ttfamily 0}
মনে করা।

\item Mutable ও Immutable-এর পার্থক্য না বোঝা।

\end{compacttwocolpoints}
