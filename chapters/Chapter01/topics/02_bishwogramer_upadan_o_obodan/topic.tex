\section{বিশ্বগ্রামের উপাদান ও ICT-এর অবদান}

\topichead{শিখনফল}
এই টপিক শেষে শিক্ষার্থী বিশ্বগ্রাম কার্যকর হওয়ার জন্য প্রয়োজনীয় উপাদান—Hardware, Software, Connectivity, Data/Information ও Capacity/Skill—ব্যাখ্যা করতে পারবে। পাশাপাশি যোগাযোগ, Internet, e-mail, teleconferencing, video conferencing, education, e-learning, e-book, healthcare, telemedicine, business, e-commerce, employment, freelancing, outsourcing, agriculture, research ও e-governance-এ ICT-এর অবদান বিশ্লেষণ করতে পারবে।

\important{আগের টপিকে বিশ্বগ্রামের ধারণা, সংজ্ঞা ও basic প্রভাব আলোচনা করা হয়েছে। এখানে একই সংজ্ঞা repeat করা হয়নি; বরং বিশ্বগ্রাম বাস্তবে কীভাবে কাজ করে এবং ICT বিভিন্ন ক্ষেত্রে কীভাবে অবদান রাখে তা বিস্তারিতভাবে দেওয়া হয়েছে।}

\subsection{বিশ্বগ্রামের উপাদান}

বিশ্বগ্রাম কোনো একক যন্ত্র, software বা শুধু Internet-এর নাম নয়। এটি একটি ICT-নির্ভর সমন্বিত ব্যবস্থা, যেখানে physical device, software, network connection, data এবং মানুষের digital skill একসঙ্গে কাজ করে। একজন শিক্ষার্থী online class করবে, একজন রোগী telemedicine service নেবে, একজন ব্যবসায়ী e-commerce platform ব্যবহার করবে, একজন freelancer বিদেশি client-এর কাজ করবে—এসব কাজের জন্য শুধু Internet থাকলেই হয় না; device, app/software, connection, data security এবং ব্যবহার দক্ষতা দরকার হয়।

\begin{rightimageblock}{\chaponeimg/global_village_components.png}{বিশ্বগ্রামের প্রধান উপাদান}
বিশ্বগ্রামের প্রধান উপাদান পাঁচটি: \term{Hardware}, \term{Software}, \term{Connectivity}, \term{Data/Information} এবং \term{Capacity/Skill}। Hardware user-কে digital service access করার device দেয়, software কাজ পরিচালনা করে, connectivity user ও service-কে network-এর মাধ্যমে যুক্ত করে, data/information digital content হিসেবে ব্যবহৃত হয় এবং capacity মানুষকে ICT সঠিকভাবে ব্যবহার করার দক্ষতা দেয়।
\end{rightimageblock}

Connectivity & Internet, mobile network, Wi-Fi, broadband, optical fiber, satellite link, data center connection ইত্যাদি। Connectivity না থাকলে device ও software থাকলেও বিশ্বগ্রামের সুবিধা পাওয়া যায় না। \\

\subsection{Hardware: বিশ্বগ্রামের দৃশ্যমান ভিত্তি}

\definition{Hardware}{ICT ব্যবস্থায় ব্যবহৃত দৃশ্যমান ও স্পর্শযোগ্য physical device বা যন্ত্রাংশকে Hardware বলা হয়।}

Hardware হলো বিশ্বগ্রামের visible infrastructure। একজন user smartphone বা computer দিয়ে online service access করে; server website, e-mail, cloud file ও database চালু রাখে; router ও modem network connection তৈরি করে; camera ও microphone video class, video meeting ও telemedicine-এ ব্যবহার হয়। Hardware ছাড়া software চালানো যায় না এবং digital service ব্যবহার করা সম্ভব হয় না।

\subtopichead{বিশ্বগ্রামে Hardware-এর ভূমিকা}
\begin{compactpoints}
\item \term{User device}: computer, laptop, tablet ও smartphone দিয়ে user online class, e-mail, website, e-commerce ও telemedicine ব্যবহার করে।
\item \term{Network device}: router, modem, switch, access point ও gateway data transmission ও connectivity তৈরি করে।
\item \term{Server}: website, database, cloud storage, e-mail service ও online application host করে।
\item \term{Input-output device}: keyboard, mouse, scanner, camera, microphone, monitor, printer ইত্যাদি data input/output করে।
\item \term{Storage device}: hard disk, SSD, memory card, cloud backup server data সংরক্ষণে সাহায্য করে।
\item \term{Special device}: biometric scanner, medical sensor, GPS device, CCTV camera, IoT sensor—বিশেষ ICT service পরিচালনায় ব্যবহৃত হয়।
\end{compactpoints}

\exampleline{Online class করতে student-এর smartphone/laptop, teacher-এর computer, camera, microphone, server এবং router—সবগুলো hardware গুরুত্বপূর্ণ।}

\subsection{Software: Hardware-কে কার্যকর করার মাধ্যম}

\definition{Software}{Computer বা digital device-কে নির্দিষ্ট কাজ করানোর জন্য তৈরি instruction, program বা application-এর সমষ্টিকে Software বলা হয়।}

Software hardware-কে ব্যবহারযোগ্য করে। Browser ছাড়া website দেখা যায় না, e-mail app ছাড়া e-mail পাঠানো কঠিন, video conferencing software ছাড়া online meeting করা যায় না, LMS ছাড়া online class ও assignment management কঠিন, database software ছাড়া student record বা patient record manage করা যায় না। তাই বিশ্বগ্রামে software user, hardware এবং online service-এর মধ্যে bridge হিসেবে কাজ করে।

\subtopichead{বিশ্বগ্রামে Software-এর ভূমিকা}
\begin{compactpoints}
\item \term{Operating system}: computer ও smartphone পরিচালনার basic environment দেয়।
\item \term{Browser}: website, search engine, online library ও web application access করতে সাহায্য করে।
\item \term{Communication software}: e-mail, chat, audio call, video call ও group meeting সম্ভব করে।
\item \term{LMS}: online class, recorded lecture, quiz, assignment, attendance ও feedback manage করে।
\item \term{Database software}: school, hospital, bank, business ও government record সংরক্ষণ করে।
\item \term{Security software}: virus, malware, unauthorized access, data loss ও cyber attack থেকে system রক্ষা করে।
\item \term{Business software}: inventory, accounting, order management, CRM ও digital payment system চালায়।
\end{compactpoints}

\subsection{Connectivity: বিশ্বগ্রামের প্রাণ}

\definition{Connectivity}{এক device, user, organization, database বা digital service-কে অন্য device, user বা service-এর সঙ্গে network-এর মাধ্যমে যুক্ত করার সক্ষমতাকে Connectivity বলা হয়।}

Connectivity ছাড়া বিশ্বগ্রাম কার্যকর হয় না। Hardware ও software থাকলেও যদি network connection না থাকে, তাহলে user online class, e-mail, video call, cloud storage, telemedicine, e-commerce, digital payment বা e-governance service ব্যবহার করতে পারবে না। Connectivity data, message, audio, video, document ও transaction এক স্থান থেকে অন্য স্থানে পাঠায়।

\begin{rightimageblock}{\chaponeimg/global_village_ict_connection.png}{ICT connectivity}
Connectivity সাধারণত Internet, Wi-Fi, broadband, mobile network, optical fiber, satellite link ও data center connection-এর মাধ্যমে তৈরি হয়। একটি school, hospital, business, government office বা individual user যখন digital platform-এর সঙ্গে যুক্ত হয়, তখন সে বিশ্বগ্রামের অংশ হয়ে যায়।
\end{rightimageblock}

\subtopichead{Connectivity-এর গুরুত্ব}
\begin{compactpoints}
\item দূরবর্তী মানুষ ও প্রতিষ্ঠানকে real-time communication-এর সুযোগ দেয়।
\item online class, video conference, telemedicine ও remote work চালু রাখে।
\item cloud storage, online document sharing ও collaborative work সম্ভব করে।
\item e-commerce, online banking, mobile banking ও digital payment কার্যকর করে।
\item emergency notice, disaster warning ও health information দ্রুত মানুষের কাছে পৌঁছায়।
\item government service, admission, result, job application ও certificate online-এ পাওয়া যায়।
\end{compactpoints}

\examfocus{Connectivity প্রশ্নে শুধু “Internet connection” লিখবে না। Internet, mobile network, Wi-Fi, optical fiber, satellite link এবং digital service connection—এই broader ধারণা লিখবে।}

\subsection{Data/Information: বিশ্বগ্রামের মূল digital সম্পদ}

\definition{Data/Information}{Text, number, image, audio, video, document, transaction record, medical report, student record বা যেকোনো digital উপাত্তকে data বলা হয়; processing-এর পর data meaningful information হয়ে service ও decision-making-এ ব্যবহৃত হয়।}

বিশ্বগ্রামে data হলো প্রধান resource। শিক্ষা, চিকিৎসা, ব্যাংকিং, ব্যবসা, কৃষি, গবেষণা ও প্রশাসনের প্রায় সব কাজ data-based. যেমন, student result, patient history, e-commerce order, bank transaction, crop advisory, weather update, national ID record, passport application—সবই digital data-এর উপর নির্ভর করে। Data সঠিক হলে service ভালো হয়; data ভুল হলে decision ভুল হতে পারে।

\subtopichead{বিশ্বগ্রামে Data-এর ব্যবহার}
\begin{compactpoints}
\item \term{শিক্ষা}: student profile, attendance, result, assignment, quiz score ও learning progress।
\item \term{চিকিৎসা}: prescription, test report, patient history, appointment ও health monitoring data।
\item \term{ব্যবসা}: product list, order, customer review, payment, delivery ও inventory record।
\item \term{ব্যাংকিং}: account information, transaction, mobile banking ও digital payment record।
\item \term{প্রশাসন}: birth registration, NID, passport, tax, application, certificate ও citizen service record।
\item \term{গবেষণা}: observation, measurement, survey data, simulation result ও analysis report।
\end{compactpoints}

\warningline{Data নিরাপদভাবে সংরক্ষণ ও ব্যবহার না করলে privacy leak, identity theft, misinformation, fraud ও cybercrime ঘটতে পারে। তাই password, backup, encryption, access control ও cyber awareness জরুরি।}

\subsection{Capacity/Skill: ব্যবহারকারীর সক্ষমতা}

\definition{Capacity/Skill}{ICT device, software, network ও online service সঠিক, নিরাপদ ও কার্যকরভাবে ব্যবহার করার জ্ঞান, দক্ষতা ও সক্ষমতাকে Capacity বা ICT skill বলা হয়।}

বিশ্বগ্রামের সুবিধা পেতে শুধু device ও internet যথেষ্ট নয়। মানুষকে ICT ব্যবহার করতে জানতে হবে। একজন student যদি online class link open করতে না পারে, একজন farmer যদি mobile app থেকে weather update বুঝতে না পারে, একজন patient যদি report scan করে doctor-কে পাঠাতে না পারে, বা একজন job seeker যদি online application করতে না পারে—তাহলে technology থাকলেও সুবিধা পাওয়া যাবে না। তাই digital literacy, cyber awareness, language skill ও problem-solving skill খুব গুরুত্বপূর্ণ।

\subtopichead{Capacity/Skill কেন জরুরি?}
\begin{compactpoints}
\item online service ব্যবহার করতে digital literacy দরকার।
\item e-mail, document upload, online form fill-up ও payment করতে basic ICT skill দরকার।
\item cyber awareness না থাকলে phishing, fake link, password theft ও online fraud-এর ঝুঁকি বাড়ে।
\item English ও communication skill global collaboration ও freelancing-এ সহায়তা করে।
\item information search ও source verification skill না থাকলে misinformation ছড়াতে পারে।
\item problem-solving skill না থাকলে digital workplace বা online job market-এ টিকে থাকা কঠিন।
\end{compactpoints}

\subsection{উপাদানগুলোর পারস্পরিক সম্পর্ক}

\subsection{ICT-এর অবদান}

ICT মানুষের জীবনকে দ্রুত, সহজ, connected ও information-based করেছে। যোগাযোগ, শিক্ষা, চিকিৎসা, ব্যবসা, কর্মসংস্থান, প্রশাসন, গবেষণা, কৃষি, বিনোদন, সংবাদমাধ্যম ও সামাজিক সম্পর্ক—প্রায় সব ক্ষেত্রেই ICT-এর প্রভাব আছে। ICT শুধু একটি subject নয়; এটি আধুনিক সমাজ, economy ও service delivery-এর foundation.

\begin{rightimageblock}{\chaponeimg/ict_contribution_small.png}{ICT-এর প্রধান অবদান}
ICT-এর মাধ্যমে মানুষ দ্রুত তথ্য খুঁজতে পারে, যোগাযোগ করতে পারে, online service নিতে পারে, digital payment করতে পারে, remote class বা meeting করতে পারে, দূরবর্তী চিকিৎসা নিতে পারে এবং global job market-এ কাজ করতে পারে। তাই ICT বিশ্বগ্রামের বাস্তব প্রয়োগকে সম্ভব করেছে।
\end{rightimageblock}

\subtopichead{ICT-এর high-yield অবদান}
\begin{compactpoints}
\item দ্রুত communication ও information sharing সম্ভব করেছে।
\item Internet-এর মাধ্যমে knowledge, data ও digital resource access সহজ করেছে।
\item e-mail, messaging, audio call, video call ও social communication চালু করেছে।
\item e-learning, online class, e-book ও digital library জনপ্রিয় করেছে।
\item telemedicine, electronic health record ও remote health service উন্নত করেছে।
\item e-commerce, online banking, mobile banking ও digital payment বৃদ্ধি করেছে।
\item freelancing, outsourcing, remote work ও digital entrepreneurship তৈরি করেছে।
\item e-governance, citizen portal, online certificate ও digital public service সহজ করেছে।
\end{compactpoints}

\subsection{যোগাযোগে ICT-এর অবদান}

Communication হলো তথ্য, ধারণা, message, audio, video বা document এক ব্যক্তি থেকে অন্য ব্যক্তির কাছে পৌঁছানোর প্রক্রিয়া। ICT যোগাযোগকে দ্রুত, কম খরচের, real-time, multimedia-based এবং global করেছে। আগে চিঠি বা physical meeting-এর উপর বেশি নির্ভর করতে হতো; এখন e-mail, instant messaging, video conference, social media ও cloud document দিয়ে একই কাজ দ্রুত করা যায়।

\begin{rightimageblock}{\chaponeimg/global_village_communication_tools.png}{যোগাযোগের digital মাধ্যম}
ই-মেইল formal communication-এর জন্য, instant messaging দ্রুত informal communication-এর জন্য, video conferencing real-time meeting-এর জন্য, social media mass communication ও awareness-এর জন্য এবং cloud document collaborative work-এর জন্য ব্যবহৃত হয়।
\end{rightimageblock}

\subtopichead{যোগাযোগে ICT-এর সুবিধা}
\begin{compactpoints}
\item কয়েক সেকেন্ডে message, file, image, audio ও video পাঠানো যায়।
\item ভিন্ন দেশে থাকা মানুষ audio/video call করতে পারে।
\item online meeting, online class, interview ও training পরিচালনা করা যায়।
\item emergency notice, disaster alert ও public awareness দ্রুত ছড়ানো যায়।
\item team project-এ cloud document ব্যবহার করে একসঙ্গে কাজ করা যায়।
\item communication-এর record সংরক্ষণ করা যায়, যেমন e-mail history বা meeting recording।
\end{compactpoints}

\subsection{টেলিকমিউনিকেশন}

টেলিকমিউনিকেশন বিশ্বগ্রামের communication backbone. Telephone, mobile phone, radio, television, satellite communication, internet communication—সবই telecommunication system-এর অংশ। ICT-enabled telecommunication মানুষকে দূরবর্তী যোগাযোগ, broadcasting, emergency communication, online meeting, mobile internet ও digital service ব্যবহারের সুযোগ দেয়।

\hline

\subsection{ইন্টারনেট}

\definition{ইন্টারনেট}{বিশ্বব্যাপী সংযুক্ত অসংখ্য computer network-এর সমন্বয়ে গঠিত বৃহৎ network system-কে Internet বলা হয়।}

Internet বিশ্বগ্রামের সবচেয়ে গুরুত্বপূর্ণ infrastructure. এটি information access, communication, education, business, entertainment, research, government service ও social interaction-এর common platform হিসেবে কাজ করে। Internet-এর মাধ্যমে user website browsing, e-mail, online class, online banking, e-commerce, telemedicine, social media, cloud storage, online news, digital library এবং research database ব্যবহার করতে পারে।

\subtopichead{Internet-এর ব্যবহার}
\begin{compactpoints}
\item information search, online research ও digital library access।
\item e-mail, instant messaging, audio/video call ও social media communication।
\item online class, LMS, e-book, webinar ও online assessment।
\item online banking, mobile banking, digital payment ও e-commerce।
\item cloud storage, file sharing ও collaborative document editing।
\item online admission, job application, result, tax, passport ও government service।
\item entertainment, news, online media, streaming ও public awareness।
\end{compactpoints}

\remember{Internet ও World Wide Web এক নয়। Internet হলো global network infrastructure; Web হলো Internet ব্যবহার করে website ও webpage access করার একটি service।}

\subsection{ই-মেইল}

\definition{ই-মেইল}{Internet ব্যবহার করে electronic message, document, image বা file এক ব্যক্তি বা প্রতিষ্ঠান থেকে অন্য ব্যক্তি বা প্রতিষ্ঠানের কাছে পাঠানোর পদ্ধতিকে ই-মেইল বলা হয়।}

ই-মেইল formal communication-এর অন্যতম গুরুত্বপূর্ণ মাধ্যম। স্কুল-কলেজের notice, assignment submission, job application, office order, business proposal, report sharing, meeting invitation, official document transfer—এসব কাজে e-mail ব্যবহার হয়। E-mail-এর advantage হলো speed, low cost, attachment support, multiple recipient, record keeping এবং formal proof.

\subtopichead{ই-মেইলের প্রধান অংশ}
\begin{compactpoints}
\item \term{To}: প্রধান recipient-এর e-mail address।
\item \term{CC}: যাদের copy পাঠানো হবে।
\item \term{BCC}: যাদের address অন্য recipient দেখতে পাবে না।
\item \term{Subject}: message-এর সংক্ষিপ্ত বিষয়।
\item \term{Body}: মূল message।
\item \term{Attachment}: PDF, image, document, spreadsheet বা file।
\end{compactpoints}

\subtopichead{ই-মেইলের সুবিধা}
\begin{compactpoints}
\item দ্রুত ও কম খরচে message পাঠানো যায়।
\item document, image, PDF, spreadsheet attachment হিসেবে পাঠানো যায়।
\item একই message একাধিক recipient-কে পাঠানো যায়।
\item formal communication ও official notice-এর জন্য উপযোগী।
\item message record বা evidence হিসেবে সংরক্ষণ করা যায়।
\item দূরবর্তী institution, teacher, office বা client-এর সঙ্গে যোগাযোগ সহজ হয়।
\end{compactpoints}

\subsection{টেলিকনফারেন্সিং}

\definition{টেলিকনফারেন্সিং}{ভিন্ন স্থানে থাকা একাধিক ব্যক্তি telephone, audio, video বা data communication technology ব্যবহার করে একই সময়ে সভা, আলোচনা, প্রশিক্ষণ বা ক্লাসে অংশগ্রহণ করলে তাকে টেলিকনফারেন্সিং বলা হয়।}

Teleconferencing একটি broad concept. এতে telephone conference, audio conference, video conference, web conference, data conference—সব অন্তর্ভুক্ত হতে পারে। এর মাধ্যমে participants একই physical room-এ না থেকেও meeting, training, interview, official discussion বা class করতে পারে।

\subtopichead{টেলিকনফারেন্সিং-এর সুবিধা}
\begin{compactpoints}
\item দূরবর্তী ব্যক্তিরা একই সময়ে আলোচনা করতে পারে।
\item ভ্রমণ খরচ, সময় ও physical arrangement কমে।
\item emergency decision দ্রুত নেওয়া যায়।
\item branch office, school, college, hospital বা government office একসঙ্গে যুক্ত হতে পারে।
\item online training, teacher meeting, business meeting ও administrative coordination সহজ হয়।
\end{compactpoints}

\subtopichead{ভিডিও কনফারেন্সিং-এর প্রয়োজনীয় উপকরণ}

\subsection{শিক্ষায় ICT-এর অবদান}

ICT শিক্ষা ব্যবস্থাকে classroom-এর বাইরে নিয়ে গেছে। এখন শিক্ষার্থী শুধু printed book-এর উপর নির্ভর করে না; সে online class, recorded lecture, e-book, digital library, LMS, online quiz, simulation, virtual lab, educational website, video lecture ও discussion forum ব্যবহার করতে পারে। শিক্ষক assignment, attendance, feedback ও assessment digitalভাবে পরিচালনা করতে পারেন।

ICT শিক্ষায় flexibility তৈরি করে। দূরবর্তী শিক্ষার্থীও online class করতে পারে, recorded lecture দেখে revision করতে পারে, e-book পড়তে পারে, digital library থেকে reference নিতে পারে এবং LMS-এ assignment জমা দিতে পারে।

\subtopichead{শিক্ষাক্ষেত্রে ICT-এর সুবিধা}

\item recorded class বারবার দেখে দুর্বল অংশ revise করা যায়।
\item e-book, digital library ও online article থেকে অতিরিক্ত resource পাওয়া যায়।
\item online quiz, assignment submission ও feedback দ্রুত হয়।
\item LMS class management, attendance, result ও communication সহজ করে।

\item global course, webinar, online certification ও skill learning-এর সুযোগ তৈরি হয়।
\item দুর্যোগ বা মহামারির সময় শিক্ষা চালু রাখা যায়।
\end{compactpoints}

\subsection{ই-লার্নিং}

\definition{ই-লার্নিং}{Internet, computer, mobile device ও digital platform ব্যবহার করে শিক্ষা গ্রহণ, শিক্ষা প্রদান, assessment এবং learning resource ব্যবহারের পদ্ধতিকে ই-লার্নিং বলা হয়।}

ই-লার্নিংয়ের মধ্যে live online class, recorded video, LMS, online quiz, e-book, discussion forum, digital assignment, virtual lab, simulation, online exam ও feedback system অন্তর্ভুক্ত হতে পারে। এটি formal education, skill development, professional training এবং self-learning—সব ক্ষেত্রেই ব্যবহৃত হয়।

\subtopichead{ই-লার্নিংয়ের ধরন}
\begin{compactpoints}
\item \term{Synchronous learning}: teacher ও learner একই সময়ে live class বা meeting-এ থাকে।
\item \term{Asynchronous learning}: learner নিজের সুবিধামতো recorded lecture, e-book বা module পড়ে।
\item \term{Blended learning}: classroom learning এবং online learning একসঙ্গে ব্যবহার করা হয়।
\item \term{Mobile learning}: smartphone বা tablet ব্যবহার করে learning resource access করা হয়।
\end{compactpoints}

\remember{Online class হলো e-learning-এর একটি অংশ। E-learning আরও বড় ধারণা; এর মধ্যে e-book, LMS, quiz, discussion forum, recorded lesson, simulation ও virtual lab অন্তর্ভুক্ত হতে পারে।}

\subsection{ই-বুক}

\definition{ই-বুক}{যে বই digital format-এ computer, smartphone, tablet বা e-book reader-এ পড়া যায়, তাকে ই-বুক বলা হয়।}

ই-বুক printed book-এর digital form হলেও এটি অনেক সময় search, bookmark, highlight, hyperlink, multimedia, font size change ও note-taking সুবিধা দেয়। শিক্ষার্থী PDF, EPUB, online library, educational app বা website থেকে e-book পড়তে পারে।

\subtopichead{ই-বুকের সুবিধা}
\begin{compactpoints}
\item অনেক বই কম storage-এ সংরক্ষণ করা যায়।
\item keyword দিয়ে দ্রুত search করা যায়।
\item smartphone/tablet-এ সহজে বহন করা যায়।
\item font size, brightness, bookmark ও highlight সুবিধা থাকে।
\item online library থেকে দ্রুত download বা access করা যায়।
\item paperless হওয়ায় পরিবেশবান্ধব হতে পারে।
\item দূরবর্তী শিক্ষার্থীও বই access করতে পারে।
\end{compactpoints}

\subsection{টেলিমেডিসিন}

\definition{টেলিমেডিসিন}{তথ্য ও যোগাযোগ প্রযুক্তি ব্যবহার করে দূরবর্তী রোগীকে diagnosis support, treatment suggestion, prescription, follow-up, health monitoring বা clinical consultation দেওয়ার পদ্ধতিকে টেলিমেডিসিন বলা হয়।}

Telemedicine ব্যবস্থায় patient ও doctor একই স্থানে না থেকেও communication technology ব্যবহার করে যুক্ত হন। Patient report, medical image, prescription history, symptom description ও video call ব্যবহার করে চিকিৎসা পরামর্শ পাওয়া যায়। Rural area, disaster situation, specialist shortage বা travel problem থাকলে telemedicine অত্যন্ত গুরুত্বপূর্ণ।

\subtopichead{টেলিমেডিসিনের সুবিধা}
\begin{compactpoints}
\item দূরবর্তী এলাকার রোগী specialist doctor-এর পরামর্শ পায়।
\item travel cost, waiting time ও physical crowd কমে।
\item জরুরি অবস্থায় দ্রুত preliminary advice পাওয়া যায়।
\item chronic disease follow-up সহজ হয়।
\item doctor-to-doctor consultation সহজ হয়।
\item rural health service ও community clinic support উন্নত করা যায়।
\item health awareness ও preventive care দ্রুত ছড়ানো যায়।
\end{compactpoints}

\subtopichead{টেলিমেডিসিনের সীমাবদ্ধতা}
\begin{compactpoints}
\item physical examination সবসময় সম্ভব নয়।
\item internet connection ও device না থাকলে service নেওয়া কঠিন।
\item report বা image quality খারাপ হলে diagnosis support দুর্বল হতে পারে।
\item privacy ও medical data security নিশ্চিত করা জরুরি।
\item emergency surgery বা critical care-এর ক্ষেত্রে direct hospital service দরকার।
\end{compactpoints}

\subsection{কর্মসংস্থানে ICT-এর অবদান}

ICT skill-based job market তৈরি করেছে। এখন কাজের বাজার শুধু স্থানীয় নয়; global marketplace-এর সঙ্গেও যুক্ত। একজন দক্ষ ব্যক্তি web development, graphics design, data entry, content writing, digital marketing, video editing, software development, app development, UI/UX design, online tutoring, translation, virtual assistance ইত্যাদি কাজ online-এ করতে পারে।

\definition{Outsourcing}{কোনো ব্যক্তি বা প্রতিষ্ঠান নিজের কাজ বাইরের ব্যক্তি বা প্রতিষ্ঠানের মাধ্যমে করালে তাকে outsourcing বলা হয়।}

\definition{Freelancing}{স্বাধীনভাবে নির্দিষ্ট project বা কাজের বিনিময়ে online/offline আয় করার পদ্ধতিকে freelancing বলা হয়।}

\subtopichead{কর্মসংস্থানে ICT-এর সুযোগ}
\begin{compactpoints}
\item freelancing marketplace-এ project-based কাজ করা যায়।
\item international client-এর সঙ্গে কাজের সুযোগ তৈরি হয়।
\item remote job ও work-from-home ব্যবস্থা তৈরি হয়েছে।
\item online portfolio, LinkedIn, GitHub, personal website দিয়ে দক্ষতা দেখানো যায়।
\item digital marketing, content creation, video editing ও online tutoring নতুন job sector তৈরি করেছে।
\item rural youth, women ও physically challenged ব্যক্তিদের কাজের সুযোগ বাড়তে পারে।
\item outsourcing-এর মাধ্যমে প্রতিষ্ঠান দক্ষ worker থেকে কম খরচে কাজ নিতে পারে।
\end{compactpoints}

\remember{Outsourcing হলো কাজ বাইরের ব্যক্তি/প্রতিষ্ঠানের মাধ্যমে করানো; freelancing হলো স্বাধীনভাবে project-based কাজ করা। একজন freelancer outsourcing কাজ করতে পারে, কিন্তু দুটি শব্দ একই নয়।}

\subsection{Common Mistake Zone}

\smallhead{১. উপাদান ও অবদান এক মনে করা}
বিশ্বগ্রামের উপাদান হলো system-এর basic parts—Hardware, Software, Connectivity, Data এবং Capacity। ICT-এর অবদান হলো এই system ব্যবহারের ফলে শিক্ষা, চিকিৎসা, ব্যবসা, যোগাযোগ, কর্মসংস্থান ইত্যাদিতে পাওয়া সুবিধা।

\smallhead{২. Internet-কে ICT-এর সমার্থক ভাবা}
Internet ICT-এর একটি গুরুত্বপূর্ণ অংশ; কিন্তু ICT-এর মধ্যে computer, mobile, software, network, communication tools, database, digital platform এবং user skill—সবই থাকে।

\smallhead{৩. Video conferencing লিখে শুধু app-এর নাম দেওয়া}
Video conferencing-এর উত্তরে camera, microphone, speaker, internet connection, real-time audio-video communication এবং distance reduction—এসব লিখতে হবে।

\smallhead{৪. E-learning ও online class এক মনে করা}
Online class e-learning-এর একটি অংশ। E-learning-এর মধ্যে e-book, LMS, quiz, discussion forum, recorded lecture, virtual lab ও simulation অন্তর্ভুক্ত হতে পারে।

\subsection{১ মিনিটে রিভিশন}

\begin{compactpoints}
\item বিশ্বগ্রামের উপাদান: Hardware, Software, Connectivity, Data/Information, Capacity/Skill।
\item Hardware physical device দেয়; Software digital কাজ চালায়।
\item Connectivity মানুষ, device, institution ও service-কে network-এর মাধ্যমে যুক্ত করে।
\item Data হলো digital resource; security, backup ও privacy জরুরি।
\item Capacity/Skill ছাড়া device ও internet থাকলেও মানুষ ICT সুবিধা পুরোপুরি পায় না।
\item ICT যোগাযোগে e-mail, messaging, teleconference ও video conference সহজ করে।
\item Internet বিশ্বগ্রামের প্রধান infrastructure।
\item E-learning education sector-এ ICT-এর বড় অবদান।
\item Telemedicine healthcare sector-এ ICT-এর বাস্তব প্রয়োগ।
\item E-commerce business-কে online market ও digital payment-এর সঙ্গে যুক্ত করে।
\item ICT freelancing, outsourcing, remote work ও digital entrepreneurship তৈরি করে।
\item E-governance citizen service দ্রুত ও transparent করতে সাহায্য করে।
\end{compactpoints}
