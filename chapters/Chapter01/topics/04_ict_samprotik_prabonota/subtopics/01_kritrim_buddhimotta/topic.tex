\subsection{কৃত্রিম বুদ্ধিমত্তার ধারণা}

মানুষ অভিজ্ঞতা থেকে শেখে, সমস্যা বুঝে সিদ্ধান্ত নেয়, ভাষা ব্যবহার করে যোগাযোগ করে এবং নতুন পরিস্থিতির সঙ্গে নিজেকে মানিয়ে নেয়। কম্পিউটার বা যন্ত্রকে যখন এমনভাবে তৈরি করা হয় যে সেটি data বিশ্লেষণ করে শেখা, যুক্তি প্রয়োগ করা, সিদ্ধান্ত দেওয়া, ভাষা বোঝা, ছবি চিনতে পারা বা সমস্যা সমাধান করতে পারে, তখন সেটিকে কৃত্রিম বুদ্ধিমত্তা বলা হয়।

কৃত্রিম বুদ্ধিমত্তা বা \term{Artificial Intelligence (AI)} হলো computer science-এর এমন একটি শাখা, যেখানে computer system বা machine-কে intelligent কাজ করার ক্ষমতা দেওয়া হয়। যেমন—chatbot মানুষের প্রশ্নের উত্তর দেয়, mobile face unlock মুখ চিনতে পারে, Google Maps route suggest করে, YouTube/Netflix video recommend করে, bank fraud detection system সন্দেহজনক transaction শনাক্ত করে এবং doctor decision support system রোগ নির্ণয়ে সহায়তা করে।

\definition{কৃত্রিম বুদ্ধিমত্তা}{কৃত্রিম বুদ্ধিমত্তা বা Artificial Intelligence হলো কম্পিউটার বিজ্ঞানভিত্তিক এমন প্রযুক্তি, যার মাধ্যমে যন্ত্রকে মানুষের মতো শেখা, যুক্তি প্রয়োগ, সমস্যা সমাধান, ভাষা বোঝা, pattern শনাক্তকরণ এবং সিদ্ধান্ত গ্রহণের ক্ষমতা দেওয়া হয়।}

\definition{সহজ সংজ্ঞা}{যে প্রযুক্তির মাধ্যমে computer বা machine data, rule বা model ব্যবহার করে মানুষের মতো intelligent কাজ করতে পারে, তাকে কৃত্রিম বুদ্ধিমত্তা বা AI বলে।}

\midfigure[0.76\textwidth]{\chaponeimg/ai_basic_concept_model.png}{কৃত্রিম বুদ্ধিমত্তার মৌলিক ধারণা}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Data, Algorithm/Model, Learning, Decision এবং Action—এই ধারাটি দেখানো হবে। AI system প্রথমে data গ্রহণ করে, তারপর algorithm বা model ব্যবহার করে pattern শেখে, নতুন input বিশ্লেষণ করে সিদ্ধান্ত নেয় এবং সেই সিদ্ধান্ত অনুযায়ী output বা action দেয়।

\subsection{AI মানে কী নয়}

\begin{compactpoints}
\item AI মানেই robot নয়। অনেক AI system mobile app, website, server বা software model হিসেবে কাজ করে।
\item AI মানেই magic নয়। এটি data, algorithm, model এবং training-এর উপর নির্ভর করে।
\item AI সবসময় সঠিক নয়। ভুল data, biased data বা ভুল model হলে AI ভুল সিদ্ধান্ত দিতে পারে।
\item AI মানুষের সম্পূর্ণ বিকল্প নয়। অনেক ক্ষেত্রে AI decision support দেয়, final decision মানুষের হতে পারে।
\end{compactpoints}

\subsection{AI-এর প্রধান বৈশিষ্ট্য}

AI system সাধারণ computer program-এর মতো শুধু fixed instruction follow করে না; এটি data, rule, model এবং feedback ব্যবহার করে intelligent কাজ করতে পারে। AI-এর কিছু বৈশিষ্ট্য নিচে দেওয়া হলো।

\midfigure[0.74\textwidth]{\chaponeimg/ai_features_mindmap.png}{AI-এর প্রধান বৈশিষ্ট্য}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে AI-এর প্রধান বৈশিষ্ট্য—Learning, Reasoning, Problem Solving, NLP, Vision, Prediction এবং Automation—mind map আকারে দেখানো হবে। এগুলো AI system-এর intelligent task বোঝাতে সাহায্য করবে।

\begin{compactpoints}
\item \term{শেখার ক্ষমতা}: AI data থেকে pattern শেখে এবং নতুন input পেলে সেই শেখা ব্যবহার করে।
\item \term{যুক্তি প্রয়োগ}: rule, probability বা model ব্যবহার করে সিদ্ধান্তে পৌঁছাতে পারে।
\item \term{সমস্যা সমাধান}: complex problem বিশ্লেষণ করে সম্ভাব্য solution দিতে পারে।
\item \term{ভাষা বোঝা}: NLP-এর মাধ্যমে মানুষের ভাষা process করতে পারে।
\item \term{দৃষ্টি বা perception}: image, video, face, object, handwriting বা medical image চিনতে পারে।
\item \term{Prediction}: পূর্বের data দেখে ভবিষ্যৎ trend বা সম্ভাব্য ফলাফল অনুমান করতে পারে।
\item \term{Automation}: repetitive বা routine কাজ স্বয়ংক্রিয়ভাবে করতে পারে।
\item \term{Adaptation}: নতুন data বা feedback পেলে performance উন্নত করতে পারে।
\item \term{Decision Support}: doctor, banker, teacher, farmer, businessman বা manager-কে সিদ্ধান্তে সহায়তা করে।
\end{compactpoints}

\subsection{AI কীভাবে কাজ করে}

AI সাধারণত data-driven পদ্ধতিতে কাজ করে। প্রথমে data সংগ্রহ করা হয়, তারপর data পরিষ্কার ও প্রক্রিয়াজাত করা হয়, algorithm/model সেই data থেকে pattern শেখে, এরপর নতুন input পেলে prediction বা decision দেয়। Feedback পেলে model আরও improve করা যায়।

\midfigure[0.78\textwidth]{\chaponeimg/ai_working_process.png}{AI system-এর কাজের ধাপ}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Data Collection → Data Processing → Training → Model → Prediction/Decision → Feedback—এই ধারাটি দেখানো হবে। এতে বোঝা যাবে AI শুধু command follow করে না; বরং data থেকে pattern শিখে decision দেয়।

\subtopichead{AI কাজ করার ধাপ}
\begin{compactenum}
\item \term{Data Collection}: text, image, voice, video, sensor, transaction বা user behavior data সংগ্রহ করা হয়।
\item \term{Data Processing}: data clean, sort, label, normalize বা format করা হয়।
\item \term{Training/Learning}: algorithm processed data থেকে pattern শেখে।
\item \term{Model Creation}: শেখা pattern model-এর ভেতরে সংরক্ষিত থাকে।
\item \term{Prediction/Decision}: নতুন input পেলে model prediction, recommendation বা decision দেয়।
\item \term{Feedback}: ভুল output সংশোধন করে model improve করা যায়।
\end{compactenum}

\exampleline{একটি spam detection AI অনেক e-mail দেখে শেখে কোন ধরনের e-mail spam হতে পারে। পরে নতুন e-mail এলে model সেটি spam কি না prediction দেয়।}

\subsection{AI, Machine Learning, Deep Learning ও Generative AI-এর সম্পর্ক}

AI, Machine Learning, Deep Learning ও Generative AI সম্পর্কিত হলেও এক নয়। AI হলো সবচেয়ে বড় ক্ষেত্র। Machine Learning হলো AI-এর একটি পদ্ধতি। Deep Learning হলো Machine Learning-এর advanced অংশ, যেখানে neural network ব্যবহৃত হয়। Generative AI হলো এমন AI, যা training data থেকে শেখা pattern ব্যবহার করে নতুন content তৈরি করতে পারে।

\midfigure[0.76\textwidth]{\chaponeimg/ai_ml_dl_genai_relation.png}{AI, ML, DL ও Generative AI-এর সম্পর্ক}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে nested relation দেখানো হবে: AI-এর ভিতরে Machine Learning, Machine Learning-এর ভিতরে Deep Learning এবং Deep Learning/foundation model-এর মাধ্যমে Generative AI. এর মাধ্যমে শিক্ষার্থী বুঝবে, ML বা DL আলাদা subject হলেও AI-এর অংশ।

\begin{compacttable}
\begin{tabular}{|p{0.22\textwidth}|p{0.46\textwidth}|p{0.22\textwidth}|}
\hline
\textbf{ধারণা} & \textbf{ব্যাখ্যা} & \textbf{উদাহরণ} \\
\hline
AI & যন্ত্রকে intelligent কাজ করানোর বিস্তৃত ক্ষেত্র & chatbot, expert system \\
\hline
Machine Learning & data থেকে pattern শেখার পদ্ধতি & spam detection, prediction \\
\hline
Deep Learning & neural network ব্যবহার করে complex pattern শেখা & image recognition \\
\hline
Generative AI & prompt অনুযায়ী নতুন text, image, audio, video বা code তৈরি করা & AI writing/image/code tool \\
\hline
\end{tabular}
\end{compacttable}

\remember{সব Machine Learning AI-এর অংশ, কিন্তু সব AI Machine Learning নয়। Expert System rule-based AI হতে পারে, যেখানে ML ব্যবহার নাও থাকতে পারে।}

\subsection{AI system-এ Training ও Inference}

AI system বুঝতে হলে দুটি গুরুত্বপূর্ণ ধাপ বুঝতে হবে: \term{Training} এবং \term{Inference}। Training হলো AI model-কে data দিয়ে শেখানোর ধাপ। Inference হলো শেখা model ব্যবহার করে নতুন input-এর উত্তর, prediction বা decision দেওয়ার ধাপ।

\midfigure[0.78\textwidth]{\chaponeimg/ai_training_vs_inference.png}{AI Training ও Inference}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Training Data → Learning Algorithm → Trained Model → New Input → Output/Decision দেখানো হবে। Training ধাপে model data থেকে pattern শেখে। Inference ধাপে সেই trained model নতুন input বিশ্লেষণ করে output দেয়।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Training Data}: model শেখার জন্য ব্যবহার করা example, label, text, image বা record।
\item \term{Learning Algorithm}: data থেকে pattern শেখার mathematical পদ্ধতি।
\item \term{Trained Model}: training শেষে তৈরি model, যেখানে শেখা pattern সংরক্ষিত থাকে।
\item \term{New Input}: ব্যবহারকারীর নতুন প্রশ্ন, image, voice, transaction বা sensor data।
\item \term{Output/Decision}: answer, prediction, recommendation, warning বা automated action।
\end{compactpoints}

\begin{compacttable}
\begin{tabular}{|p{0.22\textwidth}|p{0.38\textwidth}|p{0.28\textwidth}|}
\hline
\textbf{ধাপ} & \textbf{কাজ} & \textbf{উদাহরণ} \\
\hline
Training & data দিয়ে model শেখানো & হাজার ছবি দিয়ে face recognition শেখানো \\
\hline
Validation/Testing & model কতটা ভালো কাজ করছে তা যাচাই & নতুন ছবি দিয়ে accuracy check \\
\hline
Inference & trained model দিয়ে নতুন input-এর output দেওয়া & camera-তে মুখ দেখে unlock করা \\
\hline
Feedback & ভুল হলে data/model improve করা & ভুল prediction correction করা \\
\hline
\end{tabular}
\end{compacttable}

\remember{Training মানে AI শেখে; Inference মানে শেখা AI নতুন প্রশ্ন/input-এর উত্তর দেয়।}

\subsection{Machine Learning}

\definition{Machine Learning}{Machine Learning হলো AI-এর একটি পদ্ধতি, যেখানে computer বা machine-কে প্রতিটি rule আলাদা করে না লিখে data থেকে pattern শেখানো হয় এবং সেই pattern ব্যবহার করে নতুন data সম্পর্কে prediction বা decision দেওয়া হয়।}

Traditional programming-এ programmer rule লিখে দেয়, তারপর computer input নিয়ে output দেয়। কিন্তু Machine Learning-এ input data ও expected output বা label ব্যবহার করে model নিজে pattern শেখে। এরপর নতুন input পেলে model শেখা pattern ব্যবহার করে output দেয়।

\midfigure[0.78\textwidth]{\chaponeimg/ai_machine_learning_workflow.png}{Machine Learning কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Dataset → Feature Extraction → Training Algorithm → ML Model → Prediction → Feedback দেখানো হবে। Dataset থেকে feature নেওয়া হয়, algorithm model train করে, trained model নতুন input দেখে prediction দেয়।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Dataset}: model শেখার জন্য raw data; যেমন e-mail, image, transaction, health record।
\item \term{Feature Extraction}: data থেকে গুরুত্বপূর্ণ বৈশিষ্ট্য বের করা; যেমন শব্দ, রং, shape, transaction pattern।
\item \term{Training Algorithm}: selected feature ব্যবহার করে pattern শেখে।
\item \term{ML Model}: শেখা pattern ধরে রাখে এবং নতুন data-তে apply করে।
\item \term{Prediction}: নতুন input দেখে class, score, warning বা recommendation দেয়।
\item \term{Feedback}: ভুল prediction সংশোধন করে model উন্নত করার সুযোগ দেয়।
\end{compactpoints}

\subtopichead{Machine Learning কাজ করার ধাপ}
\begin{compactenum}
\item \term{Data Collection}: problem অনুযায়ী image, text, transaction, sensor বা user behavior data সংগ্রহ করা হয়।
\item \term{Data Cleaning}: ভুল, duplicate, missing বা irrelevant data ঠিক করা হয়।
\item \term{Feature Selection}: model শেখার জন্য গুরুত্বপূর্ণ বৈশিষ্ট্য নির্বাচন করা হয়।
\item \term{Training}: algorithm data থেকে pattern শেখে।
\item \term{Model Evaluation}: accuracy, precision, recall ইত্যাদি দিয়ে performance যাচাই করা হয়।
\item \term{Prediction}: নতুন data দেখে model output দেয়।
\item \term{Feedback}: ভুল prediction হলে model improve করা হয়।
\end{compactenum}

\subtopichead{Machine Learning-এর ধরন}
\begin{compacttable}
\begin{tabular}{|p{0.25\textwidth}|p{0.42\textwidth}|p{0.25\textwidth}|}
\hline
\textbf{ধরন} & \textbf{ব্যাখ্যা} & \textbf{উদাহরণ} \\
\hline
Supervised Learning & labelled data থেকে শেখে & disease prediction, spam detection \\
\hline
Unsupervised Learning & label ছাড়া data থেকে pattern/group খুঁজে & customer segmentation \\
\hline
Reinforcement Learning & reward/punishment থেকে শেখে & game AI, robot control \\
\hline
\end{tabular}
\end{compacttable}

\exampleline{E-mail spam filter অনেক spam ও non-spam e-mail দেখে শেখে। পরে নতুন e-mail এলে সেটি spam কি না prediction দেয়।}

\subsection{Deep Learning}

\definition{Deep Learning}{Deep Learning হলো Machine Learning-এর একটি advanced শাখা, যেখানে artificial neural network-এর বহু layer ব্যবহার করে complex data থেকে pattern শেখা হয়।}

Deep Learning মানুষের brain-এর neuron ধারণা থেকে inspired, তবে এটি human brain-এর exact copy নয়। Deep Learning model image, speech, text, video এবং complex pattern recognition-এ খুব কার্যকর। Face recognition, voice assistant, language model, medical image analysis, self-driving car এবং generative AI-তে deep learning বেশি ব্যবহৃত হয়।

\midfigure[0.78\textwidth]{\chaponeimg/ai_deep_learning_workflow.png}{Deep Learning কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Input Layer → Hidden Layers → Feature Learning → Output Layer দেখানো হবে। Input layer data গ্রহণ করে, hidden layer ধাপে ধাপে complex feature শেখে এবং output layer final class, text, score বা decision দেয়।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Input Layer}: raw input যেমন image pixel, word token বা audio signal গ্রহণ করে।
\item \term{Hidden Layers}: বহু layer data থেকে simple থেকে complex feature শেখে।
\item \term{Weights}: neuron connection-এর strength; training-এর সময় এগুলো adjust হয়।
\item \term{Feature Learning}: model নিজে important pattern শিখতে পারে।
\item \term{Output Layer}: final prediction, label, text বা decision দেয়।
\end{compactpoints}

\subtopichead{Deep Learning কাজ করার ধাপ}
\begin{compactenum}
\item বড় dataset সংগ্রহ করা হয়।
\item data neural network-এর input layer-এ দেওয়া হয়।
\item hidden layer data থেকে feature শেখে।
\item training-এর সময় error কমাতে weight update করা হয়।
\item trained model নতুন input দেখে prediction দেয়।
\end{compactenum}

\subsection{NLP কীভাবে কাজ করে}

Natural Language Processing বা NLP মানুষের ভাষা computer-এর বোঝার উপযোগী করে। মানুষের ভাষা অস্পষ্ট, context-based এবং grammar-dependent হতে পারে। তাই NLP system text বা speech input নিয়ে tokenization, language understanding, intent detection, model processing এবং response generation করে।

\midfigure[0.78\textwidth]{\chaponeimg/ai_nlp_working_process.png}{NLP কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Text/Speech Input → Tokenization → Language Understanding → Intent/Meaning → Model/Knowledge → Response দেখানো হবে।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Text/Speech Input}: user question, command, message বা spoken language।
\item \term{Tokenization}: sentence-কে word/subword/token-এ ভাগ করা।
\item \term{Language Understanding}: grammar, meaning, context ও intent বিশ্লেষণ করা।
\item \term{Model/Knowledge}: language model বা knowledge base input process করে।
\item \term{Response}: answer, translation, summary, correction বা command output।
\end{compactpoints}

\subtopichead{NLP কাজ করার ধাপ}
\begin{compactenum}
\item \term{Input}: user text বা speech দেয়।
\item \term{Speech-to-Text}: speech হলে আগে text-এ রূপান্তর করা হয়।
\item \term{Tokenization}: বাক্যকে word/subword/token-এ ভাগ করা হয়।
\item \term{Language Understanding}: grammar, meaning, context ও intent বিশ্লেষণ করা হয়।
\item \term{Model Processing}: model বা knowledge base input process করে।
\item \term{Response Generation}: text, translation, answer, summary বা command output দেয়।
\end{compactenum}

\subsection{Large Language Model বা LLM}

\definition{Large Language Model}{Large Language Model বা LLM হলো বড় আকারের deep learning language model, যা বিপুল text data থেকে language pattern শেখে এবং user prompt অনুযায়ী text generate, question answer, summary, translation, reasoning বা coding task করতে পারে।}

LLM সাধারণত Transformer architecture ব্যবহার করে। এটি text-কে token-এ ভাগ করে, context বুঝে এবং probability অনুযায়ী পরবর্তী token predict করে response তৈরি করে। LLM মানুষের মতো চিন্তা করে না; এটি শেখা pattern ও context ব্যবহার করে সবচেয়ে সম্ভাব্য output তৈরি করে।

\midfigure[0.78\textwidth]{\chaponeimg/ai_llm_working_process.png}{LLM কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Prompt → Tokenization → Transformer Layers → Context Understanding → Next Token Prediction → Response দেখানো হবে। এতে বোঝানো হবে, LLM prompt থেকে context বুঝে ধাপে ধাপে response তৈরি করে।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Prompt}: user-এর question, instruction বা task description।
\item \term{Token}: text-এর ছোট অংশ, যা model process করে।
\item \term{Embedding}: token-এর numerical representation।
\item \term{Transformer Layers}: attention mechanism দিয়ে context ও token relationship বিশ্লেষণ করে।
\item \term{Next-token Prediction}: সম্ভাব্য পরবর্তী token অনুমান করে।
\item \term{Response}: অনেক token মিলিয়ে generated answer তৈরি হয়।
\end{compactpoints}

\subtopichead{LLM কাজ করার ধাপ}
\begin{compactenum}
\item \term{Prompt}: user প্রশ্ন বা instruction দেয়।
\item \term{Tokenization}: text ছোট token-এ ভাগ হয়।
\item \term{Embedding}: token numerical vector-এ রূপান্তরিত হয়।
\item \term{Transformer Processing}: attention mechanism context ও token সম্পর্ক বিশ্লেষণ করে।
\item \term{Next Token Prediction}: model সম্ভাব্য পরবর্তী token predict করে।
\item \term{Response Generation}: অনেক token মিলিয়ে final answer তৈরি হয়।
\item \term{Post-processing/Safety}: কিছু system harmful বা unsafe output filter করে।
\end{compactenum}

\warningline{LLM কখনো ভুল তথ্য আত্মবিশ্বাসের সঙ্গে দিতে পারে, যাকে hallucination বলা হয়। তাই গুরুত্বপূর্ণ তথ্য source দিয়ে যাচাই করতে হবে।}

\subsection{Computer Vision কীভাবে কাজ করে}

Computer Vision image বা video থেকে object, face, text, scene বা pattern চিনতে সাহায্য করে। Computer নিজে image মানুষের মতো দেখে না; image pixel value বা numerical data হিসেবে process করে। Deep learning model image-এর edge, shape, texture, object part এবং final object class শিখতে পারে।

\midfigure[0.78\textwidth]{\chaponeimg/ai_computer_vision_working_process.png}{Computer Vision কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে Image/Video Input → Preprocessing → Feature Detection → Object Recognition → Decision/Action দেখানো হবে।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{Image/Video Input}: camera, image file, CCTV বা medical scan থেকে input আসে।
\item \term{Preprocessing}: image resize, noise reduction, brightness/contrast adjustment করা হয়।
\item \term{Feature Detection}: edge, color, texture, shape বা pattern detect করা হয়।
\item \term{Object Recognition}: trained model object, face, text বা disease pattern শনাক্ত করে।
\item \term{Decision/Action}: face unlock, traffic alert, medical warning বা crop disease advice দেয়।
\end{compactpoints}

\exampleline{Mobile face unlock-এ camera মুখের image নেয়, model facial features শনাক্ত করে এবং registered face-এর সঙ্গে match হলে phone unlock করে।}

\subsection{Generative AI কীভাবে কাজ করে}

Generative AI এমন AI, যা prompt অনুযায়ী নতুন text, image, audio, video, design বা code তৈরি করতে পারে। এটি training data থেকে pattern শেখে এবং user prompt অনুযায়ী সেই pattern ব্যবহার করে নতুন output generate করে।

\midfigure[0.78\textwidth]{\chaponeimg/ai_generative_ai_working_process.png}{Generative AI কীভাবে কাজ করে}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে User Prompt → Foundation Model → Content Generation → Output → Human Review/Refinement দেখানো হবে। এতে বোঝা যাবে, Generative AI prompt বুঝে নতুন content তৈরি করে, কিন্তু output যাচাই ও refine করা মানুষের দায়িত্ব।

\subtopichead{চিত্রের component ব্যাখ্যা}
\begin{compactpoints}
\item \term{User Prompt}: user কী তৈরি করতে চায় তা instruction হিসেবে দেয়।
\item \term{Foundation Model}: বড় training data থেকে শেখা model prompt process করে।
\item \term{Content Generation}: text, image, audio, video বা code তৈরি হয়।
\item \term{Output}: generated answer, design, script, code বা media পাওয়া যায়।
\item \term{Human Review}: ভুল, bias, copyright বা harmful content আছে কি না যাচাই করা হয়।
\item \term{Refinement}: user feedback দিয়ে output উন্নত করা হয়।
\end{compactpoints}

\subtopichead{Generative AI-এর ব্যবহার}
\begin{compactpoints}
\item essay, summary, report, caption, script লেখা।
\item poster, image, logo concept বা illustration তৈরি।
\item coding, debugging ও documentation।
\item voiceover, subtitle, translation ও content localization।
\item education material, quiz, lesson plan তৈরি।
\end{compactpoints}

\subtopichead{Generative AI-এর ঝুঁকি}
\begin{compactpoints}
\item ভুল তথ্য বা hallucination।
\item deepfake ও misinformation।
\item copyright/IP issue।
\item academic dishonesty।
\item bias বা harmful content।

\subsection{Expert System}

\definition{Expert System}{যে AI-ভিত্তিক computer system কোনো নির্দিষ্ট বিষয়ের বিশেষজ্ঞ জ্ঞান ব্যবহার করে সমস্যা বিশ্লেষণ করে সিদ্ধান্ত বা পরামর্শ দিতে পারে, তাকে Expert System বলা হয়।}

Expert System-এ মানুষের বিশেষজ্ঞ জ্ঞান knowledge base-এ সংরক্ষণ করা হয়। Inference engine সেই knowledge এবং user-এর দেওয়া তথ্য বিশ্লেষণ করে সিদ্ধান্ত বা advice দেয়। চিকিৎসা, কৃষি, fault detection, banking, legal advisory, tax advisory ইত্যাদিতে expert system ব্যবহৃত হতে পারে।

\midfigure[0.76\textwidth]{\chaponeimg/ai_expert_system_model.png}{Expert System-এর গঠন}

\subtopichead{চিত্র ব্যাখ্যা}
চিত্রে User → User Interface → Inference Engine → Knowledge Base → Advice/Decision—এই flow দেখানো হবে। User problem input দেয়, inference engine knowledge base থেকে rule/knowledge ব্যবহার করে advice দেয়।

\subtopichead{Expert System-এর component}

\subsection{Common Mistake Zone}

\smallhead{১. AI মানেই robot নয়}
Robot physical machine হতে পারে; AI software/model/algorithm হিসেবেও কাজ করতে পারে। Chatbot, recommendation system ও fraud detection system robot নয়, কিন্তু AI ব্যবহার করে।

\smallhead{২. AI, ML, DL এক নয়}
AI সবচেয়ে বড় field; ML AI-এর subset; DL ML-এর subset। সব AI system deep learning ব্যবহার করে না।

\smallhead{৩. AI সবসময় সঠিক নয়}
AI ভুল data, biased data বা incomplete data থেকে ভুল সিদ্ধান্ত দিতে পারে। তাই human oversight জরুরি।

\smallhead{৪. Generative AI মানেই সত্য তথ্য নয়}
Generative AI text বা image তৈরি করতে পারে, কিন্তু কখনো confidentভাবে ভুল তথ্যও দিতে পারে। তাই source verification দরকার।

\boardanswer

\boardanswer

\boardanswer

\boardanswer
