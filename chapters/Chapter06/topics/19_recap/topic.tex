\subsection{MCQ-তে ভুল এড়ানোর তথ্য}
SQL = Structured Query Language; SELECT রেকর্ড নির্বাচন করে।

\textbf{কী ও ডেটা টাইপ:} প্রাইমারি কী একাধিক ফিল্ডের হতে পারে; সব কী AutoNumber নয়। ফরেন কী-তে ডুপ্লিকেট হতে পারে; সব ফরেন কী অবশ্যই NULL হবে—এ কথাও ভুল। Date/Time তারিখের জন্য, Currency অর্থের জন্য, Text পরিচিতি/মোবাইলের জন্য উপযোগী।

\textbf{কুয়েরি ও ইনডেক্স:} WHERE শর্ত দেয়, ORDER BY সাজায়; ইনডেক্স ফলের ক্রম নিশ্চিত করে না। COUNT(*) সারি গোনে; COUNT(field) NULL বাদ দেয়। DELETE রেকর্ড বাদ দেয়; DROP TABLE টেবিল বাদ দেয়।

\textbf{পুনরাবৃত্তি ও অনন্যতা:} একই মান দুবার দেখা মানেই নকশা ভুল নয়; কোন ফিল্ড বা সমন্বয় অনন্য হওয়া দরকার সেটি দেখো।

Student(StudentID, Name) ও Result(ResultID, StudentID, Marks) থেকে বেশি নম্বর পাওয়া শিক্ষার্থীর নাম দেখাতে কী কী ধারণা লাগবে? \textbf{ইঙ্গিত:} কী, 1:N, JOIN, WHERE, ORDER BY।
