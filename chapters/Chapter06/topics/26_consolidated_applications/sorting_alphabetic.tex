\par\smallskip\noindent\begin{minipage}{\linewidth}
\chSixExample{৮.১}{নাম A থেকে Z সাজাও।}
\noindent\begin{minipage}[c]{0.57\linewidth}
\begin{verbatim}
SELECT Roll,Name FROM Student
ORDER BY Name ASC;
\end{verbatim}
\smallskip Name-এর বর্ণক্রম প্রথম অগ্রাধিকার। ASC না লিখলেও ORDER BY-এর সাধারণ ঊর্ধ্বক্রম কার্যকর হয়। DESC দিলে এই ভিন্ন নামগুলোর ক্রম উল্টে যাবে।
