\section{নেটওয়ার্ক টপোলজি}

\begin{learningbox}
এই টপিক শেষে শিক্ষার্থী network topology-এর ধারণা, physical ও logical topology-এর পার্থক্য, Bus, Star, Ring, Mesh, Tree ও Hybrid topology-এর বৈশিষ্ট্য, সুবিধা-অসুবিধা এবং ব্যবহারক্ষেত্র ব্যাখ্যা করতে পারবে।
\end{learningbox}

\begin{definitionbox}{Network Topology}
নেটওয়ার্কে computer, server, switch, router ইত্যাদি node কীভাবে একে অপরের সাথে সংযুক্ত থাকে এবং data কোন পথে চলাচল করে, সেই বিন্যাসকে network topology বলা হয়।
\end{definitionbox}

সহজভাবে, topology হলো network-এর layout বা connection pattern। একই সংখ্যক computer দিয়ে ভিন্ন ভিন্ন topology তৈরি করলে network-এর cost, speed, reliability, fault finding এবং future expansion আলাদা হতে পারে।

\hline

\hline

\subsection{Bus Topology}

\definition{Bus Topology}{যে topology-তে সব node একটি common communication line বা backbone cable-এর সাথে যুক্ত থাকে, তাকে Bus topology বলা হয়।}

Bus topology-তে data main cable দিয়ে travel করে। কোনো node data পাঠালে signal backbone cable দিয়ে যায় এবং destination node সেটি গ্রহণ করে। ছোট বা temporary network বোঝাতে এই topology সহজ, কিন্তু backbone cable নষ্ট হলে পুরো network প্রভাবিত হতে পারে।

\begin{rightimageblock}{chapters/Chapter02/images/bus_topology_diagram.png}{Bus topology}
\subtopichead{বৈশিষ্ট্য}
\begin{compactpoints}
\item একটি common backbone cable থাকে।
\item cable কম লাগে, তাই cost কম হতে পারে।
\item node বেশি হলে traffic ও collision বাড়তে পারে।
\item fault finding তুলনামূলক কঠিন।
\item backbone cable failure হলে পুরো network বন্ধ হতে পারে।
\end{compactpoints}
\end{rightimageblock}

\subsection{Star Topology}

\definition{Star Topology}{যে topology-তে সব node একটি central device যেমন switch বা hub-এর সাথে আলাদাভাবে connected থাকে, তাকে Star topology বলা হয়।}

Star topology আধুনিক LAN-এ সবচেয়ে বেশি ব্যবহৃত topology-এর একটি। এখানে প্রতিটি computer আলাদা cable দিয়ে switch বা hub-এর সাথে যুক্ত থাকে। কোনো একটি node-এর cable নষ্ট হলে সাধারণত শুধু সেই node affected হয়; তবে central device নষ্ট হলে পুরো network বন্ধ হতে পারে।

\begin{rightimageblock}{chapters/Chapter02/images/star_topology_diagram.png}{Star topology}
\subtopichead{বৈশিষ্ট্য}
\begin{compactpoints}
\item central device থাকে।
\item management ও troubleshooting সহজ।
\item নতুন node add করা সহজ।
\item cable bus topology-এর চেয়ে বেশি লাগতে পারে।
\item switch ব্যবহারে performance ভালো হয়।
\end{compactpoints}
\end{rightimageblock}

\subsection{Ring Topology}

\definition{Ring Topology}{যে topology-তে প্রতিটি node পাশের দুইটি node-এর সাথে connected থাকে এবং সব node মিলে closed loop তৈরি করে, তাকে Ring topology বলা হয়।}

Ring topology-তে data সাধারণত নির্দিষ্ট direction-এ node থেকে node-এ যায়। একটি node data receive করে দেখে সেটি তার জন্য কি না; না হলে পরবর্তী node-এ forward করে।

\begin{compactpoints}
\item ordered data flow থাকে।
\item collision কম হতে পারে।
\item node বা link failure হলে network প্রভাবিত হতে পারে।
\item নতুন node add করা তুলনামূলক কঠিন।
\end{compactpoints}

\smallimage[0.48\textwidth]{chapters/Chapter02/images/ring_topology_diagram.png}{Ring topology}

\subsection{Mesh Topology}

\definition{Mesh Topology}{যে topology-তে প্রতিটি node অন্য node-গুলোর সাথে সরাসরি বা একাধিক path দ্বারা connected থাকে, তাকে Mesh topology বলা হয়।}

Mesh topology reliability-এর জন্য গুরুত্বপূর্ণ। কোনো একটি path নষ্ট হলেও alternative path দিয়ে communication চলতে পারে। তাই critical network, backbone বা high availability system-এ mesh concept ব্যবহার করা হয়।

\begin{compacttable}
\begin{tabular}{|p{0.28\textwidth}|p{0.29\textwidth}|p{0.29\textwidth}|}
\hline
\textbf{ধরন} & \textbf{ধারণা} & \textbf{ব্যবহার} \\
\hline
Full Mesh & প্রতিটি node অন্য সব node-এর সাথে connected & খুব high reliability দরকার হলে \\
\hline
Partial Mesh & প্রয়োজনীয় node-গুলোর মধ্যে multiple path থাকে & practical large network \\
\hline
\end{tabular}
\end{compacttable}

\remember{Mesh topology reliable হলেও cable, device port, configuration ও maintenance cost বেশি।}

\subsection{Tree Topology}

\definition{Tree Topology}{Star topology-এর মতো বিভিন্ন group যখন hierarchical বা parent-child structure-এ যুক্ত হয়, তখন তাকে Tree topology বলা হয়।}

Tree topology বড় office, campus বা institution network organize করতে সুবিধাজনক। এখানে root বা backbone অংশ থাকে, যার সাথে বিভিন্ন branch network যুক্ত হয়।

\begin{compactpoints}
\item hierarchical structure থাকে।
\item বড় network section অনুযায়ী organize করা যায়।
\item expansion তুলনামূলক সহজ।
\item backbone/root failure হলে বড় অংশ affected হতে পারে।
\end{compactpoints}

\subsection{Hybrid Topology}

\definition{Hybrid Topology}{দুই বা ততোধিক topology মিলিয়ে যে practical network design তৈরি হয়, তাকে Hybrid topology বলা হয়।}

বাস্তব বড় network-এ প্রায়ই pure topology ব্যবহার করা হয় না। যেমন একটি campus network-এ department-wise Star topology থাকতে পারে, আর department-গুলো backbone-এর সাথে Tree বা Mesh structure-এ যুক্ত থাকতে পারে।

\begin{imagefirstblock}[0.74\textwidth]{chapters/Chapter02/images/hybrid_topology_diagram.png}{Hybrid topology}
Hybrid topology-তে network designer প্রয়োজন অনুযায়ী একাধিক topology combine করে। যেমন একটি school বা college campus-এ প্রতিটি lab-এ Star topology, building-to-building backbone-এ Tree topology এবং important server connection-এ Mesh-like redundant path থাকতে পারে। ফলে network একই সঙ্গে manageable, expandable এবং তুলনামূলক reliable হয়।
\end{imagefirstblock}

\subtopichead{Hybrid topology-এর বৈশিষ্ট্য}
\begin{compactpoints}
\item এটি fixed single pattern নয়; প্রয়োজন অনুযায়ী Bus, Star, Ring, Mesh বা Tree topology mix করা যায়।
\item বড় organization, campus, bank, ISP বা data center network-এ practical design হিসেবে বেশি দেখা যায়।
\item network-এর এক অংশ নষ্ট হলেও অন্য অংশ অনেক ক্ষেত্রে চলতে পারে, যদি redundant path থাকে।
\item design, installation এবং troubleshooting pure topology-এর তুলনায় complex হতে পারে।
\item ভবিষ্যতে নতুন department, floor, lab বা branch add করা তুলনামূলক flexible।
\end{compactpoints}

\begin{compacttable}
\begin{tabular}{|p{0.28\textwidth}|p{0.30\textwidth}|p{0.30\textwidth}|}
\hline
\textbf{উদাহরণ} & \textbf{মিশ্রণ} & \textbf{কারণ} \\
\hline
School/college lab network & Star + Tree & প্রতিটি lab switch-based, lab-গুলো backbone-এর সাথে hierarchical \\
\hline
Bank branch network & Star + Mesh & branch LAN সহজ, main server বা data center link reliable \\
\hline
ISP/campus backbone & Tree + Mesh & বড় area organize করা যায়, important route-এ alternative path থাকে \\
\hline
\end{tabular}
\end{compacttable}

\important{Hybrid topology বাস্তব network design-এ সবচেয়ে practical, কারণ এটি প্রয়োজন অনুযায়ী বিভিন্ন topology-এর সুবিধা একত্র করে।}

\subsection{Common Mistake}

\warningline{LAN, MAN, WAN হলো area অনুযায়ী network type; Bus, Star, Ring, Mesh, Tree, Hybrid হলো topology বা connection layout।}

\warningline{Star topology-তে একটি node নষ্ট হলে পুরো network বন্ধ হয় না, কিন্তু central switch/hub নষ্ট হলে পুরো network প্রভাবিত হতে পারে।}
