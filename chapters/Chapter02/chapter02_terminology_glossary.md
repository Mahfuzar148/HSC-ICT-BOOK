# Chapter 2 — কারিগরি পরিভাষার সম্পাদকীয় নীতি

৮ অক্টোবর ২০২৬-এর লেখকনির্দেশ অনুযায়ী। শব্দের প্রসঙ্গ ও প্রযুক্তিগত অর্থ যাচাই করে ব্যবহার করতে হবে; এই তালিকা নির্বিচারে প্রতিস্থাপনের নিয়ম নয়। বাংলা ব্যাখ্যার সঙ্গে প্রয়োজনীয় ইংরেজি পরীক্ষোপযোগী পরিচয় থাকবে। সূত্র, একক, মান, কোড, পরিচয়সূচক এবং পূর্ণরূপ অপরিবর্তিত থাকবে।

| English | বাংলা প্রয়োগ | যে পার্থক্য বা ভুল অনুবাদ এড়াতে হবে |
|---|---|---|
| Character | ক্যারেক্টার; প্রসঙ্গ বুঝে অক্ষর/প্রতীক | ডেটার একককে ‘চরিত্র’ বলা যাবে না; একটি ক্যারেক্টার সবসময় এক বাইট নয় |
| String | স্ট্রিং | ‘দড়ি’ নয় |
| Symbol | সিম্বল / সংকেত-প্রতীক | ক্যারেক্টার ও বিটের সমার্থক নয় |
| Bit / Byte | বিট / বাইট | একক ও বড়-ছোট অক্ষরের পরিচয় অক্ষুণ্ণ থাকবে |
| Data / Information | ডেটা / তথ্য | কাঁচা ডেটা এবং অর্থপূর্ণ তথ্যের পার্থক্য থাকবে |
| Message | বার্তা | বিষয়বস্তু; সংকেতের ভৌত রূপ নয় |
| Signal | সংকেত / সিগন্যাল | ডেটা বহনের রূপ; ডেটা নিজে নয় |
| Sender | প্রেরক | বার্তার উৎস; Transmitter-এর ভূমিকার সঙ্গে অকারণে এক করা যাবে না |
| Transmitter | প্রেরণযন্ত্র | মাধ্যমে পাঠানোর উপযোগী সংকেত তৈরি করে |
| Receiver | প্রাপক / গ্রহণযন্ত্র | পাঁচ-উপাদানের মডেলে প্রাপক; সংকেত প্রবাহে গ্রহণযন্ত্র |
| Destination | গন্তব্য | ডেটা ব্যবহারের প্রান্ত; গ্রহণযন্ত্রের সঙ্গে ভূমিকা আলাদা হতে পারে |
| Medium / Channel | মাধ্যম / চ্যানেল | নির্দিষ্ট প্রসঙ্গে পথের পরিচয় বজায় রাখতে হবে |
| Protocol | প্রোটোকল | শুধু একটি যন্ত্র বা সফটওয়্যার নয়; বিন্যাস, অর্থ/করণীয় ও সময়ের নিয়ম |
| Syntax / Semantics / Timing | বিন্যাস / অর্থ ও করণীয় / সময়সংক্রান্ত নিয়ম | তিনটি ইংরেজি নাম পরীক্ষার পরিচয় হিসেবে থাকবে |
| Frame / Packet / Block | ফ্রেম / প্যাকেট / ব্লক | একে অপরের জায়গায় নির্বিচারে বসানো যাবে না |
| Buffer | বাফার; সাময়িক ডেটা সংরক্ষণ | বড় ব্লক না বানালেও যন্ত্রে বাফার থাকতে পারে |
| Clock | ক্লক; বিটের সময়ের সমন্বয়ের প্রসঙ্গে | দেওয়ালঘড়ির অর্থে ব্যবহার নয় |
| Start / Stop / Parity Bit | স্টার্ট / স্টপ / প্যারিটি বিট | ফ্রেমের সীমানা, মূল ডেটা এবং ত্রুটি শনাক্তকরণ আলাদা |
| Header / Trailer | হেডার / ট্রেইলার | Start/Stop Bit-এর সমার্থক নয় |
| Overhead | ওভারহেড / বাড়তি নিয়ন্ত্রণতথ্য | সব প্রসঙ্গে শুধু একটি নির্দিষ্ট বিট নয় |
| Bandwidth | ব্যান্ডউইথ | Hz-এ ফ্রিকোয়েন্সির প্রস্থ; bps-এ ডেটা বহনের প্রচলিত ব্যবহার আলাদা |
| Capacity | বহনক্ষমতা | সব ভৌত প্রসঙ্গে Bandwidth-এর সমার্থক নয় |
| Data Rate / Throughput | ডেটা হার / থ্রুপুট | ঘোষিত বা প্রেরিত হার এবং সফলভাবে পাওয়া হার আলাদা |
| Baud | বড (Baud) | সিম্বলের হার; সবসময় বিট হার নয় |
| Latency / Jitter | বিলম্ব বা ল্যাটেন্সি / জিটার | মোট বিলম্ব এবং বিলম্বের ওঠানামা আলাদা |
| Attenuation / Distortion / Noise | সংকেত ক্ষয় / বিকৃতি / নয়েজ | তিনটি সমস্যার কারণ ও ফল এক নয় |
| EMI / Crosstalk | বিদ্যুৎচৌম্বক বিঘ্ন / ক্রসটক | পাশের জোড়ার প্রভাব এবং বাইরের বিদ্যুৎচৌম্বক প্রভাব আলাদা |
| Guided / Unguided | তারযুক্ত / তারবিহীন মাধ্যম | শ্রেণির পরিচিত ইংরেজি নামও থাকবে |
| Core / Cladding / Coating / Jacket | কোর / ক্ল্যাডিং / সুরক্ষা আবরণ / জ্যাকেট | ব্যাস ও দায়িত্ব আলাদা; গঠনের ইংরেজি নাম রাখা যায় |
| Shield / Shielding | ধাতব সুরক্ষা আবরণ / সুরক্ষা আবরণ থাকা | অন্তরক স্তরের সমার্থক নয় |
| Mode (fiber) | আলোক মোড | সরল রশ্মি বা যোগাযোগের Duplex Mode-এর সমার্থক নয় |
| Refractive Index | প্রতিসরণাঙ্ক | মোডের সংখ্যা এবং প্রতিসরণাঙ্কের বিন্যাস আলাদা |
| Grounding | গ্রাউন্ডিং | সাধারণ ‘ভূমি’ নয়; বৈদ্যুতিক সংযোগের প্রসঙ্গ |
| Frequency / Wavelength | ফ্রিকোয়েন্সি / তরঙ্গদৈর্ঘ্য | একক ও অর্থ পৃথক |
| Antenna / Transceiver | অ্যান্টেনা / ট্রান্সসিভার | প্রেরণ ও গ্রহণের যন্ত্রগত পরিচয় থাকবে |
| Infrared | অবলোহিত রশ্মি (Infrared) | দৃশ্যমান লাল আলো নয় |
| Relay / Transponder | পুনঃপ্রেরণকেন্দ্র বা রিলে / ট্রান্সপন্ডার | উপগ্রহের যন্ত্র এবং কেন্দ্রের দায়িত্ব আলাদা |
| Cell / Base Station | সেল / বেস স্টেশন | সেবা-এলাকা ও যন্ত্র এক নয় |
| Handoff / Roaming | হ্যান্ডঅফ / রোমিং | সংযোগ স্থানান্তর এবং সহযোগী নেটওয়ার্কের সেবা আলাদা |
| Network / Networking | নেটওয়ার্ক / নেটওয়ার্কিং | গঠিত ব্যবস্থা এবং তৈরি/পরিচালনার প্রক্রিয়া আলাদা |
| Node / Link / Port | নোড / লিংক বা সংযোগ / পোর্ট | নোড সংখ্যা, সংযোগ সংখ্যা ও সংযোগের প্রান্তের হিসাব আলাদা |
| Server / Client | সার্ভার / ক্লায়েন্ট | যন্ত্রের নামের পাশাপাশি সেবা দেওয়া/নেওয়ার ভূমিকা |
| NIC / MAC Address / IP Address | NIC / MAC Address / IP Address | অপরিচিত বাংলা নাম বানানো যাবে না; ভূমিকা ও বিট দৈর্ঘ্য আলাদা |
| Switch / Router / Bridge | সুইচ / রাউটার / ব্রিজ | ফ্রেম ও MAC-ভিত্তিক কাজ বনাম IP প্যাকেটের পথ |
| Gateway | গেটওয়ে | Default Gateway-এর ভূমিকা মানেই Protocol Translation নয় |
| Modem / ONT | মডেম / ONT | Modulation/Demodulation এবং Optical Link শেষ করার কাজ আলাদা |
| Repeater / Amplifier | রিপিটার / অ্যাম্প্লিফায়ার | সংকেত পুনর্গঠন এবং সংকেতের সঙ্গে নয়েজ বর্ধন পৃথক |
| Firewall / Access Point | ফায়ারওয়াল / অ্যাকসেস পয়েন্ট | নিরাপত্তানীতিতে বাছাই এবং বেতার সংযোগ পৃথক |
| Topology | টপোলজি | সংযোগের বিন্যাস; এলাকার শ্রেণি বা সেবার আর্কিটেকচার নয় |
| Physical / Logical Topology | ভৌত / যৌক্তিক টপোলজি | বাস্তব সংযোগ এবং ডেটা চলার নিয়ম আলাদা |
| Cloud Computing / Storage | ক্লাউড কম্পিউটিং / ক্লাউড স্টোরেজ | শুধু দূরে ফাইল রাখাই সব Cloud বৈশিষ্ট্যের প্রমাণ নয় |
| Service / Deployment Model | সেবা মডেল / স্থাপনা বা ব্যবহারের মডেল | কী সেবা বনাম কার জন্য কীভাবে অবকাঠামো ব্যবহৃত হয় |
| Resource / Infrastructure | রিসোর্স / অবকাঠামো | প্রয়োজনে ‘কম্পিউটিং সম্পদ’; সম্পদের ধরন পরিষ্কার থাকতে হবে |
| Sync / Backup / Restore | সিঙ্ক / ব্যাকআপ / পুনরুদ্ধার | পরিবর্তন ছড়ানো, উদ্ধারযোগ্য কপি ও কপি থেকে ফেরানো পৃথক |
| Encryption / Authentication | এনক্রিপশন / পরিচয় যাচাই | গোপন সংকেতায়ন এবং পরিচয় যাচাই আলাদা; হারানো ফাইল ফেরানোর ব্যবস্থা নয় |

Wi-Fi, WiMAX, Bluetooth, IEEE, TCP/IP, USB, UART, GSM, LTE, NR, UTP, STP, PAN, LAN, CAN, MAN, WAN, IaaS, PaaS, SaaS এবং সংশ্লিষ্ট মান/সংস্করণের বানান অপরিবর্তিত রাখতে হবে। পূর্ণরূপের প্রশ্নে ইংরেজি অপশন থাকবে। অন্যান্য প্রশ্নের ভাষা বদলালে একই উত্তর সঠিক থাকে কি না যাচাই করতে হবে।

## পৃষ্ঠা ১৬–১০৭-এর প্রসঙ্গ অনুযায়ী অতিরিক্ত যাচাই

| পরিভাষা | বর্তমান বাংলা প্রয়োগ | প্রসঙ্গ ও শর্ত |
|---|---|---|
| Guided / Unguided | নির্দেশিত / অনির্দেশিত মাধ্যম | তারযুক্ত ও তারবিহীন উভয় ক্ষেত্রেই সংকেতের ভৌত পথ থাকে |
| Core / Cladding | কোর / ক্ল্যাডিং | প্রথমটি আলোকপথ; দ্বিতীয়টির কম প্রতিসরণাঙ্ক আলো কোরে রাখতে সাহায্য করে |
| Refractive Index | প্রতিসরণাঙ্ক | সাধারণ ‘ইনডেক্স’ বা সূচি নয়; প্রতিফলনের আপতন কোণের শর্তও প্রয়োজন |
| Shield / Shielding | সুরক্ষা আবরণ / আবরণ দিয়ে সুরক্ষা | বিঘ্ন কমানোর উপায়; সব ধরনের অননুমোদিত প্রবেশ ঠেকানোর নিশ্চয়তা নয় |
| Line-of-sight | সরাসরি দৃষ্টিপথ | যোগাযোগের কার্যকর সরাসরি পথ; শুধু চোখে টাওয়ার দেখা যথেষ্ট পরিকল্পনা নয় |
| Link Budget | সংকেতের শক্তির হিসাব | প্রেরণশক্তি, ক্ষয়, অ্যান্টেনা ও গ্রহণক্ষমতার হিসাব; অর্থের বাজেট নয় |
| Interoperability | যন্ত্রের পারস্পরিক সামঞ্জস্য | একই ব্যবস্থা/মানের উপযোগী যন্ত্র একসঙ্গে কাজ করা |
| PHY Rate | ভৌত স্তরের ডেটা হার | পুরো ইন্টারনেট ডাউনলোডের প্রকৃত হার নয় |
| Spatial Stream | স্থানিক সংকেতপ্রবাহ | একাধিক অ্যান্টেনায় পৃথক ডেটাপ্রবাহ; সব পরিবেশে একই সুবিধা নয় |
| Central / Peripheral | কেন্দ্রীয় / সহায়ক যন্ত্র | Classic Bluetooth পিকোনেটের ভূমিকা; ঐতিহাসিক Master/Slave পরিচয় পৃথক করে রাখা হয়েছে |
| Parked Device | পুরোনো Classic-এর অপেক্ষমাণ যন্ত্র | সক্রিয় যন্ত্রের সংখ্যার সমান নয়; BLE-তে একই পুরোনো নিয়ম প্রয়োগ করা যাবে না |
| Sensor / Passive Tag | সেন্সর / নিষ্ক্রিয় ট্যাগ | সেন্সর পরিমাপ করে; ট্যাগ পাঠযোগ্য পরিচয়/তথ্য বহন করে; ট্যাগে নিজস্ব ব্যাটারি নাও থাকতে পারে |
| Inductive Coupling | তড়িৎচৌম্বক আবেশে সংযোগ | NFC-এর খুব কাছের যোগাযোগ; সাধারণ দীর্ঘপথের রেডিও সংযোগ নয় |
| Frequency Reuse | ফ্রিকোয়েন্সি পুনর্ব্যবহার | পর্যাপ্ত ব্যবধান ও বিঘ্ন নিয়ন্ত্রণের শর্তে অন্য সেলে আবার ব্যবহার |
| Frequency Hopping | ফ্রিকোয়েন্সি হপিং | নির্ধারিত ক্রমে ক্যারিয়ার বদল; Handoff-এর সমার্থক নয় |
| Time Slot | সময়ের ভাগ | TDMA-তে ছোট অংশ বরাদ্দ; কথোপকথন হাফ-ডুপ্লেক্স হওয়ার প্রমাণ নয় |
| Carrier | বাহক সংকেত / ক্যারিয়ার | Modulation-এ ডেটা অনুযায়ী বৈশিষ্ট্য বদলায়; পরিবহনকারী মানুষের অর্থে নয় |
| Source / Destination MAC | উৎস / গন্তব্যের MAC Address | শেখার ঠিকানা ও forwarding সিদ্ধান্তের ঠিকানা আলাদা |
| Flood | সংশ্লিষ্ট অন্য পোর্টে ছড়িয়ে দেওয়া | Unknown destination-এ আগত পোর্ট বাদ; সংশ্লিষ্ট LAN/VLAN ও forwarding state প্রযোজ্য |
| Default Gateway / Protocol Gateway | ডিফল্ট গেটওয়ে / প্রোটোকল গেটওয়ে | স্থানীয় নেটওয়ার্ক ছাড়ার পরবর্তী যন্ত্র বনাম প্রয়োজনীয় প্রোটোকল রূপান্তর |
| NAT / PAT / DHCP | প্রচলিত সংক্ষিপ্ত নাম অপরিবর্তিত | ঠিকানা রূপান্তর, পোর্টের সাহায্যে সংযোগ আলাদা রাখা এবং কনফিগারেশন বরাদ্দ আলাদা কাজ |
| Hop | পথের একটি সংযোগ অতিক্রমের ধাপ | নোড বা কম্পিউটারের মোট সংখ্যা নয়; ব্যবহৃত মডেলের শর্ত দেখতে হয় |
| Vertex / Edge | শীর্ষবিন্দু / সংযোগরেখা | Tree-এর গাণিতিক হিসাবে যন্ত্র ও সংযোগ; Intermediate Device-ও নোড |
| Port Endpoint | পোর্টপ্রান্ত | একই দ্বিমুখী লিংকের দুটি প্রান্ত গণনা হয়; লিংক দুবার নয় |
| Acyclic / Redundancy | চক্রবিহীন / বাড়তি বিকল্প সংযোগ | চক্রহীন Tree-এর সূত্রে অতিরিক্ত redundant link বসানো যায় না |
| Resource Pooling | সম্পদ একত্র করে ভাগাভাগি | সেবাদাতার সম্পদ বিভিন্ন গ্রাহকের জন্য বরাদ্দ; ডেটা সবার কাছে উন্মুক্ত নয় |
| Measured Service / Pay-as-you-go | ব্যবহার মাপা / ব্যবহার অনুযায়ী মূল্য | ব্যবহার মাপার বৈশিষ্ট্য এবং বাণিজ্যিক মূল্যনীতি এক নয় |
| Shared Responsibility | ভাগ করা দায়িত্ব | সেবাদাতার সঙ্গে ব্যবহারকারীর অ্যাকাউন্ট, ডেটা ও অনুমতির দায়িত্বও থাকে |
| Vendor Lock-in | সেবাদাতা বদলানোর নির্ভরতা ও জটিলতা | সব ক্লাউডে একই খরচ/জটিলতা নয়; সফটওয়্যার ও ডেটা স্থানান্তরের শর্ত বিবেচ্য |
| CuaS | মূল পাণ্ডুলিপির প্রচলিত অপ্রধান নাম | NIST-এর চতুর্থ service model নয়; মূল তিনটি IaaS/PaaS/SaaS |

Wi-Fi-এর আনুষ্ঠানিক পূর্ণরূপ নেই। শেষের MCQ ১৭-তে মানের পরিবার IEEE 802.11 শনাক্ত করতে বলা হয়েছে; Wireless Fidelity-এর ঐতিহাসিক পাঠ্য-পরিচয় মূল ব্যাখ্যায় রাখা হয়েছে। সূত্র ও সংখ্যার অন্য কোনো মান এই ভাষা-পর্বে নীরবে বদলানো হয়নি।
